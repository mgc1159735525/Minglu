# 术语表

这个术语表用于统一策划、程序、美术和测试之间的说法。

## 核心循环

| 术语 | 含义 |
| --- | --- |
| 学院养成 | 玩家每周选择课程、休息、社交、活动和剧情的主要成长循环。 |
| 战棋 | 六边形回合制战斗。包含移动、攻击、反击、地形、目标和敌方 AI。 |
| 战略地图 | 省份、军团、道路、行军、进攻和回合推进的地图层。 |
| 剧情串联 | 剧情解释玩法结果，并引导玩家回到养成、情报或战棋。 |
| 任务闸门 | 用任务、等级、好感、情报或战斗结果限制剧情推进。 |

## 角色和成长

| 术语 | 含义 |
| --- | --- |
| 主角 | 玩家角色。默认姓名为夏邑，玩家可在创角时自定义。 |
| 出身 | 创角阶段选择的家世背景，影响初始经验、立场、好感和天赋池。 |
| 往事 | 创角阶段的少年经历选择，用于形成性格倾向。 |
| 特性 | 创角或成长中获得的标签，带来战斗、社交、养成加成。 |
| 天赋 | 创角阶段选择的长期加成，通常比普通特性更强。 |
| 课程等级 | 步兵、骑兵、炮兵、管理、后勤、训练等属性的等级表现。 |
| 经验进度条 | 等级下方显示的成长进度，用于告诉玩家还差多少升级。 |
| 好感 | 同窗和关键角色对主角的关系数值。 |
| 立场 | 玩家在政治、派系或价值轴上的倾向。 |

## 剧情和任务

| 术语 | 含义 |
| --- | --- |
| 主线事件 | 推动核心章节的剧情事件，通常有触发条件。 |
| 支线事件 | 角色、派系或日常相关剧情，通常由好感、任务或主线进度解锁。 |
| 日常碎片 | 学院生活中的短事件，用于解释养成行为和世界变化。 |
| 剧情选项 | 玩家在剧情中做出的选择。选项文本必须完整。 |
| 暗中效果 | 选项改变属性、好感或立场，但不在选项按钮上显示数值。 |
| 剧情目录 | 玩家查看当前主线和可触发支线的入口。 |
| 剧情未触发 | 条件不足时的提示弹窗，告诉玩家差什么玩法目标。 |

## 战棋

| 术语 | 含义 |
| --- | --- |
| 战棋工坊 | 游戏内关卡设计和测试工具。用于快速编辑地图、单位、目标和触发器。 |
| 地形刷 | 在战棋工坊中给格子设置平原、森林、山地、河流、城镇等地形的工具。 |
| 单位刷 | 在战棋工坊中放置蓝方或红方单位的工具。 |
| 据点 | 关键目标格。占据或抵达它可作为胜利条件。 |
| 战争目标 | 一场战斗的胜利条件，例如占据据点、抵达据点、击溃敌军。 |
| 抵达剧情 | 指定单位抵达某格后触发的战场剧情。 |
| 击败剧情 | 指定敌人被击溃后触发的战场剧情。 |
| AI 风格 | 敌军行动权重，例如激进、防守、机动、游击、攻坚。 |
| 补给 | 战略和战斗中的资源压力，短缺会影响输出或防御。 |

## 表格和资源

| 术语 | 含义 |
| --- | --- |
| 导表 | 把工程运行时配置导出为 CSV 和 Excel 总表。 |
| 回写 | 把 CSV 写回运行时 JSON，让游戏读取新配置。 |
| CSV 源 | `DataTables/csv` 中的表格文件，是策划主要编辑对象。 |
| 总表 | `DataTables/MingLu_GameTables.xlsx`，用于总览和对外检查。 |
| 运行时 JSON | Unity 实际读取的 `MingLuGameConfig.json` 和 `MingLuStoryData.json`。 |
| 资源路径 | `Assets/Resources` 下不带扩展名的加载路径。 |
| Manifest | 美术资源索引，用于记录资源 ID、路径和用途。 |

## 常见字段

| 字段 | 含义 |
| --- | --- |
| `id` | 稳定唯一标识。不要随便改旧 ID。 |
| `name` | 显示名称。 |
| `description` | 描述文本。 |
| `unlockKind` | 解锁条件类型。 |
| `unlockTarget` | 解锁条件目标。 |
| `unlockValue` | 解锁阈值。 |
| `targetKind` | 任务完成目标类型。 |
| `targetValue` | 任务完成阈值。 |
| `battleAttack` | 战斗攻击加成。 |
| `battleHp` | 战斗兵力加成。 |
| `battleMove` | 战斗移动加成。 |
| `socialBonus` | 社交好感收益加成。 |
| `cultivationPercent` | 养成进度百分比加成。 |
| `staminaSave` | 体力消耗减免。 |
