# 明路功能策划案（工程执行版）

来源：`MingLu_Manual_Source.docx`

## 1. 总体循环
- 目标：让玩家经历“入学养成 -> 明确立场 -> 战争阶段 -> 结局分支”。
- 玩家操作：新游戏创建角色，学院中每周选择课程，周末选择休息/自习/邀约/活动，毕业后进入战略与战棋。
- 工程落点：`MingLuGame.cs` 保持运行时 UI 原型；所有新系统先做轻量可玩版本。
- UI 原则：主界面只显示 3 类信息：当前状态、关键成长、下一步按钮。详细信息放进按钮弹窗。

## 2. 创建角色与特性
- 目标：玩家开局确定自己的成长方向。
- 规则：选 1-3 个特性，分别影响战斗、社交、养成。
- UI：创角页使用两列特性卡片，下方仅汇总总加成。
- 已落点：`ShowCharacterCreate`、`TraitCatalog`。

## 3. 学院养成
- 目标：用每周选择体现“能力、心情、体力、社交”的取舍。
- 规则：六门课程提供成长进度；心情影响学习收益；体力过低影响心情。周末提供休息、自习、邀约、活动。
- UI：学院主界面显示角色摘要、六门 Lv 与进度条；活动、报纸、人际、剧情作为小按钮入口。
- 本轮落点：补充校历、校考、假期、活动入口。

## 4. 人际关系
- 目标：让同窗关系影响剧情与战场，而不是只做数值收藏。
- 规则：好感分为冷漠、熟人、朋友、亲密、莫逆；高好感解锁词条与战斗协助倾向，低好感形成敌对行为倾向。
- UI：主界面只列名字、好感段位、朋友圈；详细介绍放入角色档案。
- 本轮落点：关系段位、朋友圈、解锁提示。

## 5. 立场系统
- 目标：玩家通过剧情与活动逐步形成政治身份。
- 规则：四条轴：民族（皇汉/共治）、阶级（君主/民主）、治国（独裁/共和）、地域（统一/分裂）。绝对值表示狂热程度。
- UI：学院摘要只显示四条短标签；完整解释放入立场弹窗。
- 本轮落点：新增四轴数值和时事讲座选择。

## 6. 报纸与文章
- 目标：低成本展示世界观与局势，让玩家自己理解立场偏向。
- 规则：按校历逐步解锁报纸；不同报纸带有主观立场。
- UI：报纸弹窗只显示 3 条文章，点击一条读短文。
- 本轮落点：新闻目录与文章详情弹窗。

## 7. 假期、校考与活动
- 目标：打断纯刷课节奏，给阶段性反馈。
- 规则：校考根据六门等级、随机笔试、状态给分；奖励战功/金库/心情。假期触发休整和剧情提示。活动按周末选择触发。
- UI：校考和假期只用日志与小弹窗，不把成绩表堆在主界面。
- 本轮落点：考试结算、活动弹窗。

## 8. 战略、军衔与军令
- 目标：让战争阶段有“上级目标、战功、军衔、指挥权”的成长。
- 规则：战功决定军衔；军衔决定可指挥单位上限。每个战略回合给一条简短军令，完成战斗给战功。
- UI：战略侧栏只显示当前军衔、军令、选中省份/军团。
- 本轮落点：军衔计算、军令弹窗、战功奖励提示。

## 9. 战棋关卡
- 目标：将说明书中的关卡数据、地图数据、角色数据落成可玩的六边形战斗。
- 规则：有当前阵营、回合、胜败条件、中央据点；地图有地形、移动消耗和抗性；攻击前显示确认信息；伤害受士气、血量、地形、兵种克制影响。
- UI：地图上只显示地形短字、移动/攻击高亮；选中单位侧栏显示兵力、士气、攻击、移动。攻击详情用确认弹窗。
- 本轮落点：攻击确认、士气、血量系数、地形抗性、反击预估。

## 10. 后续迭代
- 将剧情资源的支线条件接入关系段位。
- 增加教师、朋友圈和专属技能。
- 扩充战棋地图剧本：回合触发援军、撤退、坚守任务。
- 做正式美术 UI 后，将运行时 UI 拆成 prefab。
