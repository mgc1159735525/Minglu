# 战斗AI风格设计

战斗AI按军团的 `aiProfile` 字段选择行为风格。配置位于 `ai_profiles` 表，程序会在敌方回合根据这些权重决定目标、移动落点、是否后撤、是否守点、是否攻击和是否待命。

## 决策流程

1. 选择行动顺序：进攻倾向、侧翼倾向、兵种射程和当前血量共同影响先手。
2. 选择目标：考虑距离、预计伤害、能否击溃、集火权重、兵种克制、目标地形减伤、目标是否防御、反击风险。
3. 判断撤退：低血量且谨慎/规避反击高于进攻时，会优先寻找更远、更安全或地形更好的格子。
4. 选择落点：使用完整移动力，从所有可达格中评分，不再只走相邻一格。
5. 执行动作：可攻击则攻击；否则按风格推进、固守据点/高防地形，或待命观察。

## 风格表

| id | 名称 | 行为定位 |
| --- | --- | --- |
| balanced | 均衡型 | 通用模板，攻守与地形权重平均。 |
| aggressive | 激进型 | 主动接敌，重视击溃和追击，低撤退、低反击规避。 |
| tactical | 智将型 | 重视集火、克制、反击风险和较好地形，优先打可收割目标。 |
| defensive | 防守型 | 重视据点和地形，低血量更容易后撤，常在据点/山林固守。 |
| mobile | 机动型 | 使用完整移动力寻找侧翼和更好的攻击角度，优先威胁后排。 |
| siege | 攻坚型 | 强烈靠近并争夺据点，远程单位倾向保持较远射程压制。 |
| skirmish | 游击型 | 保持距离、规避反击，低血量更容易拉开。 |
| berserker | 狂热型 | 高进攻和收割，几乎不顾反击与地形，倾向持续压上。 |

## 可调字段

| 字段 | 含义 |
| --- | --- |
| aggression | 进攻倾向。越高越愿意贴近、攻击和收割。 |
| caution | 谨慎倾向。越高越重视生存、后撤和避免坏交换。 |
| focusFire | 集火倾向。越高越偏向攻击残血或已被集火的目标。 |
| retreatHpPercent | 血量低于该百分比时开始考虑撤退。 |
| terrainPreference | 地形倾向。越高越偏好高防地形。 |
| objectiveBias | 据点倾向。越高越偏好占据、靠近或防守中央据点。 |
| guardBias | 防御倾向。越高越容易在据点/高防地形固守。 |
| flankBias | 侧翼倾向。越高越偏好威胁后排、残血或孤立目标。 |
| rangedSpacing | 远程保持距离。远程单位会尝试维持该格数内的射击距离。 |
| finishBias | 收割倾向。越高越优先击溃能被带走的目标。 |
| avoidCounter | 规避反击。越高越不愿意打会被重创反击的目标。 |
