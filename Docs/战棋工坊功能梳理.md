# 战棋工坊功能梳理

## 第一版目标

给游戏内准备一个可直接进入的战棋关卡设计与测试入口。它服务于快速调关，不影响正式战略地图、正式军团、正式战绩。

## 已做功能

| 功能 | 说明 |
| --- | --- |
| 入口按钮 | 战略地图底部增加“工坊”，设置菜单也可进入“战棋工坊”。 |
| 地形刷子 | 可在棋盘格上切换并落下平原、树林、山地、河流、城镇等地形。 |
| 单位刷子 | 可选择兵种后放置蓝方或红方单位。 |
| 据点刷子 | 可移动中央据点位置，测试守点与抢点节奏。 |
| 擦除 | 有单位时先删除单位，无单位时把地形还原为平原。 |
| 地图属性 | 可调整地图行列、关卡名称、作者、说明、回合限制、天气和敌方 AI。 |
| 区域触发器 | 抵达剧情、击败剧情支持区域触发，可配合画笔尺寸制作伏击圈和关键区域。 |
| 触发动作 | 触发剧情时可刷援军、调整士气、直接判定胜利或失败。 |
| 导出 JSON | 可把当前关卡导出到 `Assets/Resources/Data/BattleLevels`，方便 Git 共享。 |
| 保存草稿 | 关卡草稿独立保存到本机 PlayerPrefs，不写入正式存档。 |
| 载入草稿 | 重新载入上次保存的工坊关卡。 |
| 重置 | 恢复默认演习关卡，方便重新开始设计。 |
| 开始测试 | 用当前设计生成临时战斗，直接进入战棋引擎测试。 |
| 隔离结算 | 工坊测试胜负不增加正式战斗次数、胜场、败场、战功或战略地图变化。 |

## 暂不做

| 功能 | 原因 |
| --- | --- |
| 多关卡列表 | 第一版先做单草稿闭环，避免 UI 过重。 |
| 回合脚本事件 | 当前已有抵达和击败触发；回合开始、血量阈值、资源条件后续再加。 |
| 导出为正式关卡表 | 当前支持 JSON 共享；稳定后再接入 DataTables 和正式任务链。 |

## 后续扩展建议

1. 增加“关卡ID、推荐等级、推荐战力、奖励预览”。
2. 增加“回合开始、单位血量、资源变化、禁用兵种”等脚本条件。
3. 增加“导出到 battle_level_presets.csv”的正式关卡表。
4. 增加“从正式关卡表载入到工坊”的反向编辑。
