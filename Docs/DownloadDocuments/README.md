# 下载目录文档包

`Downloads_Documents_Sanitized_2026-07-31.zip` 收录本地下载目录中的用户文档，并按以下类型分类：

- `Word/`
- `Spreadsheets/`
- `PDF/`
- `Markdown/`
- `Web/`

归档共包含 167 份文档。为避免公开个人信息或收录无效文件，已排除：

- 3 份带姓名的学历、学籍和学位验证材料；
- 文件名或内容可识别为个人简历、履历、Resume 或 CV 的文件；
- Office 临时锁文件（`~$*`）；
- `.NET SDK` 目录内的许可证和组件说明文件。

`manifest.csv` 记录每个归档文件的相对路径、字节数和 SHA-256 校验值。
