# 明路设计资料归档

本目录收录从本地 `Downloads.rar` 中筛选出的明路项目资料。原压缩包包含大量与项目无关的软件安装包、SDK、录屏、第三方素材及个人文件，因此不纳入版本库。

## 目录

- `SystemDesign/`：兵种、技能、AI、补给、成就、存档、情报、UI、任务和战斗等系统设计。
- `Narrative/`：剧情大纲、扩充事件结构、好感度事件树，以及剧情与养成串联设计。
- `DataSnapshots/`：早期项目数据快照，仅供追溯，不作为当前运行时配置。
- `../../../DataTables/LegacySources/MingLu/`：早期角色与剧情 Excel 原始表，仅供历史参考。

当前游戏使用的正式配置仍以 `DataTables/MingLu_GameTables.xlsx`、`DataTables/csv/` 和 `Assets/Resources/` 下的导出数据为准。
