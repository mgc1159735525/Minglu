# 明路 - 好感度事件树

## 一、好感度系统概述

### 1.1 好感度等级与战斗效果

| 好感值 | 等级名称 | 战斗AI效果 |
|--------|---------|-----------|
| 90~100 | 莫逆之交 | 友军主动保护（7格内）；敌军低于40%停攻 |
| 75~89 | 亲密 | 友军保护（7格内）；敌军低于20%停攻 |
| 50~74 | 朋友 | 友军保护（5格内）；敌军低于10%停攻 |
| 10~49 | 熟人 | 无特殊效果 |
| -30~9 | 冷漠 | 无特殊效果 |
| -70~-31 | 敌对 | 敌军主动追击（4格内） |
| -90~-71 | 仇视 | 敌军主动追击（5格内） |
| -100~-91 | 死敌 | 敌军主动追击（6格内） |

### 1.2 好感度初始值规则

- 同学NPC初始好感：**10**（熟人）
- 同派系非同学NPC初始好感：**5**
- 对立派系非同学NPC初始好感：**0**
- 重要NPC初始好感：**0**
- 主角母亲初始好感：**30**（亲密）

### 1.3 好感度上限（校园期间）

- 同学NPC校园期间上限：**90**（毕业后可突破至100）
- 非同学NPC上限：**80**
- 特殊剧情可突破上限+10

## 二、好感度变化来源与数值

### 2.1 邀约系统（周末互动）

| 邀约类型 | 好感变化 | 触发条件 | 说明 |
|---------|---------|---------|------|
| 共同训练 | +5~8 | 好感≥10 | 校场切磋、体能训练 |
| 一起用膳 | +3~5 | 好感≥10 | 食堂或外出就餐 |
| 散步闲谈 | +5~10 | 好感≥20 | 校园内散步聊天 |
| 外出游玩 | +8~15 | 好感≥30，周末 | 离开校园的活动 |
| 深夜长谈 | +10~15 | 好感≥50 | 夜间寝室/庭院对话 |
| 秘密会面 | +12~18 | 好感≥70 | 涉及立场的关键对话 |

### 2.2 校园活动

| 活动类型 | 好感变化 | 周期 | 说明 |
|---------|---------|------|------|
| 课堂讨论 | +3~5 | 每周 | 与同班角色互动 |
| 演习对抗 | +5~10 | 每月 | 编队作战配合 |
| 节日庆典 | +5~8 | 每季 | 中秋/春节/丰收祭等 |
| 学术辩论 | +3~8 | 不定期 | 自由派/法治派主导 |
| 狩猎活动 | +8~12 | 每半年 | 印第安学生主导 |
| 武试大比 | +5~10 | 每半年 | 全校比武 |

### 2.3 闲逛偶遇

- 校园内闲逛时有 **20%** 概率遇到角色
- 偶遇基础好感：+2~5
- 特殊地点触发特殊偶遇（图书馆遇林素心、靶场遇张弓等）
- 好感≥70的角色偶遇概率提升至 **35%**

### 2.4 礼物与帮助

| 行为类型 | 好感变化 | 说明 |
|---------|---------|------|
| 普通礼物 | +5~10 | 食品、日用品 |
| 喜好礼物 | +10~25 | 角色偏好的特定物品 |
| 剧情帮助 | +15~25 | 在专属任务中帮助角色 |
| 危机救助 | +20~30 | 战场或政治危机中保护 |

### 2.5 战场行为

| 行为 | 好感变化 | 说明 |
|------|---------|------|
| 战场保护 | +10~15 | 主动为其挡攻击/治疗 |
| 配合作战 | +5~10 | 完成战术配合 |
| 见死不救 | -15~-25 | 故意不援助 |
| 背叛行为 | -25~-40 | 攻击友军/出卖情报 |
| 击杀其仇敌 | +15~20 | 为其报仇 |

### 2.6 剧情选择

- 关键选项好感变化：**±5~20**
- 派系倾向选择：同派+10，对立派-10
- 道德选择：正义选项+5~10，自私选项-5~-15
- 恋爱选择：影响对象+15~25，三角关系相关角色-10~-20
