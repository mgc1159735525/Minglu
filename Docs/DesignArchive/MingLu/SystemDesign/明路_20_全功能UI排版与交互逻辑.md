## 1. 总体设计原则

### 1.1 双模式UI风格定位

《明路》的游戏体验分为两大阶段，UI风格随阶段切换：

| 维度 | 养成期（军校三年） | 战争期（内战主线） |
|------|-------------------|-------------------|
| **整体氛围** | 古风文雅，学院气息 | 军事严肃，战场紧迫感 |
| **底色** | 宣纸白 #F5F0E1 | 牛皮纸深 #1E1B16 |
| **主色调** | 郑明金 #C8A45C + 墨黑 #2B2B2B | 暗金 #9A7B3A + 朱砂红 #B8382E |
| **边框风格** | 毛笔书写感细线框 + 朱砂印章装饰 | 铜质铆钉边角 + 军事地图等高线纹理 |
| **字体** | 正文楷体，标题行楷 | 正文黑体简化，标题魏碑 |
| **按钮风格** | 卷轴式按钮，hover泛金光 | 金属铭牌按钮，按压有金属声 |
| **动画节奏** | 缓慢优雅，水墨晕染展开 | 干脆利落，快速翻页/展开 |
| **背景音效** | 古琴/笛子环境音 | 鼓点/号角/远处的炮声 |

**模式切换过渡**：从养成期进入战争期时，界面经历3秒过渡动画——宣纸底色逐渐烧焦卷曲，露出下方的羊皮纸军事地图，朱砂印章变为铜质铆钉。

### 1.2 全局HUD元素

常驻屏幕的信息元素分为「永久常驻」和「条件常驻」两类：

**永久常驻（任何模式下始终可见）**：
- 顶部状态栏：金钱、粮食、士气、当前日期时间、天气图标、季节标识
- 底部操作栏：上下文相关的操作按钮（随当前界面变化）
- 菜单按钮：左上角汉堡菜单图标，点击打开系统菜单

**条件常驻（特定模式下出现）**：
- 战争期：小地图（右下角）、补给状态指示、回合计数器
- 养成期：行动点数、当前时段（早/午/晚/夜）、心情值
- 战斗模式：选中的单位信息面板、攻击预览、战斗日志

### 1.3 导航架构

采用「底部Tab + 地图点击 + 侧边栏」三层导航：

```
第一层：底部Tab栏（主要功能切换）
┌─────────────────────────────────────────────────────────────┐
│ [地图] [编队] [角色] [技能] [任务] [外交] [情报] [设置]      │
└─────────────────────────────────────────────────────────────┘
说明：
- 养成期隐藏「情报」Tab（尚未解锁）
- 战争期隐藏部分养成期专属Tab
- Tab超过8个时，多余的收入「更多」折叠菜单

第二层：地图点击（空间导航）
- 在大地图上点击城市/据点 → 弹出该地点的功能面板
- 点击己方单位 → 弹出单位操作面板
- 点击敌方单位（已侦察） → 弹出敌方信息面板

第三层：侧边栏（次要功能）
- 从屏幕左边缘右滑 → 呼出快捷信息侧边栏
- 内容：当前任务追踪、通知列表、快捷存档按钮
```

### 1.4 响应式布局说明

| 设备 | 分辨率 | 布局策略 |
|------|--------|---------|
| PC标准 | 1920×1080+ | 全屏布局，左侧信息面板+中央主区域+右侧快捷面板 |
| PC宽屏 | 2560×1440+ | 同上，UI元素等比放大，留白更多 |
| 平板横屏 | 1024×768~2048×1536 | 折叠左侧面板为可展开抽屉，底部Tab保留 |
| 平板竖屏 | 768×1024~1536×2048 | 上下布局，顶部状态栏+中央主区域+底部操作栏，Tab收入汉堡菜单 |

### 1.5 色彩编码规范

全局统一色彩语义，所有界面遵循：

| 语义 | 色值 | 使用场景 |
|------|------|---------|
| 友好/己方 | #2E5C8A（靛蓝） | 己方单位、正面数值变化、友好势力 |
| 敌对/危险 | #B8382E（朱红） | 敌方单位、负面数值变化、敌对势力、HP警告 |
| 中立/未知 | #6B7B8D（青灰） | 中立势力、未侦察区域、无变化数值 |
| 警告/注意 | #D4883A（橙色） | 资源不足、补给紧张、即将触发的负面事件 |
| 重要/稀有 | #C8A45C（金色） | 传说级物品、关键任务目标、重要NPC标识 |
| 成功/达成 | #4A8C5C（绿色） | 任务完成、升级成功、条件满足 |
| 禁用/锁定 | #A0998A（灰色） | 不可用按钮、未解锁内容、前置条件未满足 |

**交互逻辑**：

- 搜索按钮 → 弹出搜索框，支持按名称/类型/特殊能力模糊搜索
- 长按卡片 → 直接进入编队管理并预选该兵种

## 附录D：交互设计原则备忘

### D.1 核心交互原则

1. **3秒规则**：任何操作从点击到看到反馈，不超过3秒
2. **可逆性**：除战斗执行和剧情关键选择外，所有操作可撤销
3. **信息前置**：在执行操作前，必须让玩家看到所有后果预览
4. **渐进披露**：不一次性展示所有信息，按重要性分层显示
5. **一致性**：相同操作在不同界面中行为一致（如左键选中、右键取消）

### D.2 移动端特殊交互

| 操作 | 移动端映射 | 说明 |
|------|-----------|------|
| 左键点击 | 单指点击 | 选中/确认 |
| 右键点击 | 双指点击 | 取消/返回 |
| 拖拽 | 单指长按后拖拽 | 编队拖拽、地图拖动 |
| 悬停(hover) | 长按0.5秒 | 显示tooltip信息 |
| 滚轮缩放 | 双指捏合/张开 | 地图缩放 |
| ESC | 从屏幕顶部下滑 | 打开暂停菜单 |

### D.3 无障碍设计

- 所有文字最小14px，重要信息16px+
- 颜色不作为唯一信息载体（同时使用图标/文字/形状）
- 所有按钮有文字标签（不仅靠图标）
- 色盲模式：提供红绿色盲友好的替代配色方案
- 支持手柄/键盘完全操作（PC端）
