# 明路 - 技能系统设计

---

## 一、技能体系概述

### 1.1 技能分类

| 分类 | 说明 | 数量 |
|------|------|------|
| **将领主动技能** | 由将领手动释放，消耗行动点或冷却回合 | 16个 |
| **将领被动技能** | 永久生效或满足条件自动触发 | 12个 |
| **部队主动技能** | 特定兵种可用的战术技能 | 12个 |
| **地形互动技能** | 工兵类技能，改变地形或设置障碍 | 6个 |
| **光环/指挥技能** | 影响周围友军范围的指挥能力 | 6个 |
| **角色专属技能** | 特定角色独有，无法被他人学习 | 28个 |
| **总计** | | **80个** |

### 1.2 技能稀有度

| 稀有度 | 颜色 | 获取条件 | 说明 |
|--------|------|----------|------|
| **普通** | 白色 | 所有将领可学 | 基础技能，无特殊前置条件 |
| **精锐** | 蓝色 | 需要对应兵种适性≥3星 | 进阶战术技能，需要专业训练 |
| **传说** | 金色 | 专属角色独有 / 特定剧情解锁 | 独一无二或极难获得的强力技能 |

### 1.3 技能获取方式

| 获取途径 | 说明 | 示例 |
|----------|------|------|
| **学科修炼** | 6学科星级达到要求后解锁 | 步兵适性3星 → 解锁"线列齐射" |
| **战斗经验** | 累计达成特定战斗条件 | 累计造成10000伤害 → 解锁"百战余生" |
| **好感度/剧情** | 与特定角色好感度达标或完成剧情线 | 与郑怀远好感度≥75 → 解锁"东征遗志" |
| **角色专属** | 特定角色自带，不可转移 | 仅冯铁山可拥有"铁壁边防" |
| **军衔晋升** | 达到特定军衔自动解锁 | 晋升上校 → 解锁"指挥光环" |

### 1.4 技能与伤害公式的关系

技能效果嵌入既有伤害公式：
```
攻击输出 = (面板输出×我方兵种血量系数 + 我方士气等级×我方编队系数×我方兵种血量系数 
         - 敌方士气等级×敌方编队系数×敌方兵种血量系数 
         + 将领对应兵种星数×5×将领血量系数 
         - 2×对方等级) 
         × 兵种克制系数 × (1 - 减伤百分比值) × 技能加成减免
```

- **技能加成**：乘算在最终输出的"技能加成减免"因子上（如1.25 = 增加25%伤害）
- **减伤技能**：加算在"减伤百分比值"因子上（如0.15 = 减少15%受到伤害）
- **士气技能**：临时修改"我方/敌方士气等级"数值
- **地形技能**：修改地形的抗性数值
