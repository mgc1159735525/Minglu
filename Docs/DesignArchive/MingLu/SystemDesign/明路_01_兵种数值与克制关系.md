# 明路 - 兵种数值与克制关系

## 一、兵种总览

明路军事体系基于1760年代燧发枪与前装滑膛炮时代背景，分为四大兵种体系：

| 体系代码 | 体系名称 | 定位 | 包含兵种 |
|---------|---------|------|---------|
| gun | 步兵 | 战线核心，数量取胜 | 民兵、线列步兵、来复枪兵 |
| guns | 精锐步兵 | 精英突击，质量碾压 | 精锐轻步兵、近卫军、禁军、火枪骑兵 |
| cold | 骑兵 | 机动打击，侧翼包抄 | 轻骑兵、枪骑兵、重骑兵、骠骑兵 |
| cannon | 炮兵 | 远程火力，攻城拔寨 | 霹雳炮、轻火炮、重火炮、加农炮、榴弹炮、围城炮 |

### 克制核心逻辑

- **步兵方阵 → 克制骑兵**：刺刀方阵令骑兵冲锋损失惨重
- **骑兵 → 克制炮兵**：高速机动绕侧，炮兵无法转移炮口
- **炮兵 → 克制步兵**：线列密集队形是活靶子
- **来复枪/散兵 → 克制骑兵**：精准射击可在骑兵接近前造成大量杀伤
- **重骑兵 → 克制步兵**：铁蹄碾压线列方阵

> 核心三角：**步克骑、骑克炮、炮克步**，但精锐兵种可打破克制链。
