# 明路 - 任务系统设计文档

> 架空1760年美洲 · 郑明王朝 · 任务即命运的织网
> 版本：v1.0 | 关联文档：共享上下文、好感度事件树、多结局条件、成就系统、情报与间谍系统、天气与时间系统

---

## 一、系统概述

### 1.1 设计理念

任务系统是《明路》的核心驱动引擎。在三年养成（156周）→ 内战的完整游戏周期中，任务承担着三重使命：

**叙事使命**：将1760年代美洲郑明王朝的架空历史转化为玩家可触达、可参与、可改变的具体事件。每一个任务都是一段微型故事，推动角色成长与世界观展开。

**策略使命**：任务构成养成阶段的"时间竞争"核心矛盾。每周只有有限的行动点数，选择做什么任务、放弃什么任务，直接决定了主角的学科等级、好感度走向、立场偏移和派系声望——进而决定内战的开局条件与最终结局。

**情感使命**：任务是与85个角色建立情感连接的桥梁。通过角色支线任务，玩家不只是"刷好感度"，而是真正走进每个角色的故事、理解他们的信仰与挣扎。这些情感积累将在内战阶段产生巨大的叙事张力——当昔日的挚友成为战场上的敌人，任务中建立的每一段记忆都会被点燃。

**养成阶段（第1-156周）**：
- 每周划分为"早/午/晚/夜"四个时段，玩家在每个时段可执行1个行动
- 任务消耗特定时段（如"晨练"需占用早晨，"深夜长谈"需占用夜间）
- 主线任务按学期节点推进，不可跳过
- 支线/日常/探索任务自由安排，构成"时间管理"的策略核心

**战争阶段（第157周起）**：
- 任务转化为"战役任务"和"战略决策"
- 养成阶段的任务完成度直接影响战争期的可用资源、盟友数量和战略选项
- 战争任务具有不可逆性——选择攻击A地点意味着放弃B地点

### 1.3 与已有系统的联动关系

| 已有系统 | 联动方式 | 设计要点 |
|---------|---------|---------|
| **好感度系统** | 任务中共同行动的角色获得好感加成；任务选择影响好感走向 | 角色支线任务是好感度提升的主要渠道，单个任务可+5~25好感 |
| **立场轴系统** | 任务中的关键选项会推动四大立场轴偏移 | 每个任务提供2-4个选项，分别对应不同立场偏移方向 |
| **成就系统** | 任务完成触发成就解锁；部分成就需要特定任务组合 | 69个成就中约40%与任务直接相关 |
| **情报与间谍系统** | 部分任务需要消耗情报点数或需要先完成侦察 | 间谍网络可通过特定任务建立，为后续任务提供信息优势 |
| **天气与时间系统** | 任务在四时段中分布；部分任务只在特定天气触发 | 雨天触发"漏雨夜话"、雪天触发"冬日围炉"等时令任务 |
| **六学科养成** | 任务奖励包含学科EXP；高学科等级解锁高级任务 | 学科等级既是任务的前置条件，也是任务的产出目标 |
| **军衔系统** | 特定任务完成后触发军衔晋升；军衔解锁新任务 | 战争期军衔直接决定可接受的战役任务等级 |
| **派系系统** | 派系任务是派系支持率的主要变动来源 | 派系支持率影响内战阶段可动员的兵力和资源 |
| **心情系统** | 任务会影响心情值；心情值影响任务中的学科EXP获取效率 | 连续执行高强度任务降低心情，休闲任务恢复心情 |

## 二、任务分类体系

《明路》任务系统共设10种任务类型，每种类型承担不同的游戏功能。

### 2.1 主线任务

**定义**：跟随剧情推进的核心任务线，不可跳过、不可错过。主线任务是游戏的骨架，贯穿学院期（序章~第六章）和战争期（第七章）。

**设计原则**：
- 每个学期至少1条主线任务链，含2-4个连续任务节点
- 主线任务通常占据每周1-2个时段，不影响玩家自由安排其余时段
- 主线任务中包含关键抉择点，直接影响四大立场轴和结局走向
- 主线任务不可重复、不可放弃，一旦触发必须完成才能推进时间

**任务示例**：

#### 主线-01「东渡遗梦」
- **触发条件**：游戏开始自动触发
- **时段**：无限制（强制演出）
- **目标**：观看开场独白 → 在马车上回忆父亲的东渡故事 → 选择抵达新京的方式（正门/侧门/翻墙）
- **奖励**：无直接数值奖励；选择方式影响第一周初始偶遇角色
  - 正门：遇到赵伯衡（返乡团），初始好感+5
  - 侧门：遇到周文远（骑墙派），初始好感+5
  - 翻墙：遇到苏明诚（自由派），初始好感+5
- **分支走向**：三条路线在后续"入学登记"任务中汇合，但初期偶遇角色差异影响第一周的行动倾向

#### 主线-02「第一堂课」
- **触发条件**：主线-01完成后，第1周周一自动触发
- **时段**：上午（强制）
- **目标**：参加方孝先教官的战术导论课 → 课堂回答3个问题（基于玩家初始知识，答错不影响主线推进但影响教官初始印象）
- **奖励**：步兵适性+5exp，训练+3exp
- **分支走向**：
  - 回答"步兵为王"：方孝先初始印象+5，干城派同学初始好感+2
  - 回答"骑兵突击"：骑兵适性额外+3exp
  - 回答"炮兵决胜"：炮兵适性额外+3exp
  - 回答"三兵种协同"：管理+5exp，方孝先评价"此子有将才"

#### 主线-03「食堂风波」
- **触发条件**：第2周自动触发（对应EV008）
- **时段**：午间
- **目标**：目睹高年级学生刁难伊尔德·云石 → 做出选择
- **奖励**：根据选择不同
- **分支走向**（关键抉择点，权重极高）：
  - **挺身而出**：伊尔德好感+15，返乡团同学好感-5~10，民族立场·共治+3，训练+5exp
  - **巧妙化解**：伊尔德好感+8，陈敬之好感+3，民族立场·共治+1，管理+5exp
  - **冷漠旁观**：伊尔德好感-10，陈敬之好感+5，民族立场·皇汉+2
  - **参与刁难**：伊尔德好感-25，印第安乡党全员好感-10，民族立场·皇汉+5，陈敬之好感+10（解锁E11暗线前置）

#### 主线-04「课堂辩论·民族之道」
- **触发条件**：第5周自动触发（对应EV015）
- **时段**：上午（强制）
- **目标**：参与课堂上的民族政策大讨论
- **奖励**：管理+8exp，对应立场偏移
- **分支走向**：
  - **"多族共治"：民族立场·共治+5，自由派/印第安乡党全员好感+3
  - **"求同存异"：民族立场·无变动，管理+5exp额外奖励
  - **"汉人优先"：民族立场·皇汉+5，返乡团全员好感+3，自由派/印第安乡党好感-5

#### 主线-05「夏季大演习」
- **触发条件**：第13周（一年级第一学期末），需步兵适性≥1星
- **时段**：全天（占据一整天4个时段）
- **目标**：参加分阵营对抗演习 → 选择战术方案 → 完成六边形战棋战斗（教学关卡）
- **奖励**：根据战斗表现，步兵/骑兵/炮兵适性+10~20exp，训练+10exp
- **分支走向**：
  - **突击先锋**：战斗中获得骑兵增援，武力相关属性加成
  - **侧翼包抄**：战斗中获得地形优势，智略相关属性加成
  - **稳扎稳打**：战斗中获得后勤补给加成，管理相关属性加成
  - 战斗中是否"遭遇不明武装"（对应EV033）取决于此前情报系统进度

#### 主线-06「万寿节庆典」
- **触发条件**：第20周，一年级第二学期
- **时段**：全天
- **目标**：参加皇帝寿辰大典 → 在庆典上选择站队 → 观看阅兵和烟花
- **奖励**：全派系声望+5，心情+20
- **分支走向**：
  - **调停纷争**：人望相关加成+5，所有派系声望+3（对应E1/E4路线）
  - **公开站队某派系**：该派系声望+15，对立派系声望-10
  - **保持中立**：法治派声望+5（法治派欣赏中立态度）

#### 主线-07「吴存道遇刺」
- **触发条件**：第78周（三年级第一学期），法治派相关任务完成度≥3
- **时段**：晚间
- **目标**：得知法治派精神领袖吴存道遇刺 → 追悼或保持距离 → 调查真相
- **奖励**：根据选择，解锁不同后续任务链
- **分支走向**：
  - **参加追悼**：法治派全员好感+10，可接手吴存道遗志相关任务
  - **保持距离**：法治派好感-5，但避免卷入政治漩涡
  - **借机打击**：法治派好感-20，但对立派系好感+10（E1禁止选项）

#### 主线-08「毕业考核」
- **触发条件**：第130周（三年级第二学期末）
- **时段**：全天×3天（占据3天12个时段）
- **目标**：综合军事考核——包含笔试（管理/后勤）、实操（三兵种适性）、战术推演（训练）
- **奖励**：根据综合成绩授予初始军衔（士/少尉/中尉/上尉），成绩影响战争期起点
- **分支走向**：
  - 考核中是否帮助落难同学（对应EV053）：帮助则自身成绩略降但人望+10，不帮则成绩略高但失去E4关键选项

#### 主线-09「刺杀！毕业后」
- **触发条件**：第132周，毕业考核完成后
- **时段**：夜间
- **目标**：遭遇暗杀 → 武力和智略检定 → 生或死
- **奖励**：存活获得"劫后余生"称号，线索指向幕后黑手
- **分支走向**：
  - 武力检定成功：击杀刺客，获得刺客携带的密信
  - 智略检定成功：识破陷阱逃脱，获得线索
  - 两项均失败：E6·横死/战死（刺杀分支）

#### 主线-10「命运的十字路口」
- **触发条件**：第135周，刺杀事件调查完成后
- **时段**：晚间
- **目标**：选择加入的阵营（对应EV058）
- **奖励**：锁定阵营路线，获得阵营初始资源包
- **分支走向**：5个派系+1个"自立"选项（需极端条件），直接决定战争期的阵营归属

### 2.2 角色支线任务

**定义**：85个角色中可攻略/可交互角色的专属任务链。每个可攻略角色拥有3-9个连续任务节点，对应好感度事件树中的关键节点。

**设计原则**：
- 角色支线任务是好感度提升的核心渠道
- 每个角色的支线任务有独立的叙事弧线，从相识到深交到命运交织
- 同学NPC的支线任务在学院期可完成，非同学NPC可能需要战争期才能解锁后续
- 角色支线任务通常要求好感度达到特定阈值才能触发下一节点

**任务示例**（5个不同角色的代表性支线）：

#### 角色支线-赵伯衡「将门之后」
- **触发条件**：好感≥20，第3周后
- **节点1「晨练之约」**（好感≥20）：清晨与赵伯衡对练，学习"断云十三式"基础。步兵适性+5exp。
- **节点2「铁甲之下」**（好感≥30）：帮赵伯衡处理母亲来信引发的情绪危机。立场·地域统一+1。
- **节点3「夜雨长谈」**（好感≥50）：暴雨夜宿舍避水，互相袒露心声。解锁"深夜长谈"邀约模式。
- **节点4「校场之危」**（好感≥60）：演习中救助失控的赵伯衡。骑兵适性+5exp。
- **节点5「母命难违」**（好感≥70）：帮赵伯衡处理赵夫人的来信，决定他的去留。立场·阶级君主+1。
- **节点6「血战同行」**（好感≥80，战争期）：战前夜赵伯衡赠送家传剑穗。获得物品"赵家剑穗"，战场协同+5%。
- **节点7「东望之约」**（好感≥90，战争期）：大战间隙登东望楼看日出。解锁莫逆之交，互相保护范围+2格。

#### 角色支线-林素心「书海知音」
- **触发条件**：好感≥10，在图书馆闲逛偶遇
- **节点1「书海偶遇」**：图书馆初遇，林素心指出主角拿错书。
- **节点2「辩书之会」**（好感≥25）：参加林素心组织的读书会。管理+5exp。
- **节点3「墨迹心事」**（好感≥35）：发现林素心流泪，默默递茶。解锁"关心"互动。
- **节点4「月下论道」**（好感≥50）：月下庭院长谈。立场·治国共和+1。
- **节点5「禁书风波」**（好感≥60）：帮林素心转移被查禁的书籍。获得物品"启蒙译本"。
- **节点6「纸上千山」**（好感≥70）：林素心赠送研读笔记。全学科+3exp。
- **节点7「风雨同行」**（好感≥80）：为林素心辩护免遭停学。立场·阶级民主+1。
- **节点8「藏书阁之约」**（好感≥90）：大战前夕，林素心交出藏书阁私钥。获得"藏书阁之钥"。

#### 角色支线-伊尔德·云石「两族之桥」
- **触发条件**：好感≥10，食堂风波中帮助伊尔德或选择巧妙化解
- **节点1「猎场引路」**（好感≥20）：伊尔德邀请主角尝试印第安传统狩猎方式。骑兵适性+3exp。
- **节点2「篝火故事」**（好感≥35）：伊尔德讲述部落传说与家族使命。民族立场·共治+2。
- **节点3「部落访问」**（好感≥50，对应EV028）：随伊尔德回乡访问印第安部落。关键抉择点。
- **节点4「双血之盟」**（好感≥65）：伊尔德以部落仪式与主角结为"异族兄弟"。获得特殊称号"双族之友"。
- **节点5「风暴中的选择」**（好感≥80，战争期）：伊尔德的部落面临站队抉择，请求主角支持。
- **节点6「鹰与龙」**（好感≥90，战争期）：伊尔德成为主角在印第安军团中的核心盟友。解锁印第安特殊兵种。

#### 角色支线-陈敬之「宿敌之路」
- **触发条件**：好感≤10（初始为竞争对手关系），第4周后
- **节点1「课堂之争」**：在课堂中与陈敬之的第一次正面学术交锋。
- **节点2「陈敬之的挑战」**（好感变化后触发，对应EV045）：收到公开比试邀请。
- **节点3「冰面之下」**（好感≥20）：发现陈敬之的傲慢背后是家族压力。法治派好感+5。
- **节点4「暗巷遇袭」**（好感≥35）：与陈敬之同时遭遇不明袭击者，被迫合作。
- **节点5「分道与重逢」**（好感≥50，战争期）：战场上的故人重逢（对应EV063），关键抉择。
- **隐藏节点6「法家传人」**（好感≥80，二周目解锁）：陈敬之在战后的真正命运。

#### 角色支线-苏明诚「烈火之志」
- **触发条件**：好感≥10，第二章后
- **节点1「报纸风波」**：与苏明诚在报刊室讨论争议文章。
- **节点2「平民之怒」**（好感≥30）：苏明诚讲述平民出身在军校的屈辱经历。
- **节点3「地下读书会」**（好感≥50）：参加苏明诚组织的秘密读书会。管理+8exp。
- **节点4「激进与理性」**（好感≥65）：苏明诚的激进计划暴露，主角需要选择是否帮助他。
- **节点5「理想主义的代价」**（好感≥80，战争期）：苏明诚在战争中做出极端选择，主角面临阻止或支持的抉择。

### 2.3 派系任务

**定义**：5大派系各自的任务线，完成派系任务提升该派系支持率，影响内战时可动员的资源和兵力。

**设计原则**：
- 每个派系有独立的任务链，通常包含5-8个任务节点
- 派系任务之间有互斥关系——深入一个派系的任务链可能导致对立派系任务链关闭
- 派系任务通常涉及派系声望变化，当派系声望达到阈值时解锁高级任务
- 派系任务是理解各派系立场和政治诉求的主要途径

**任务示例**：

#### 派系任务-返乡团「东望不灭」
- **触发条件**：返乡团声望≥20，赵伯衡好感≥30
- **节点1「前辈之约」**：赵伯衡引介，参加返乡团前辈的私人聚会。返乡团声望+10。
- **节点2「光复之论」**：参与返乡团内部的战略讨论——是先打西班牙还是先统一大陆？返乡团声望+8，立场·民族皇汉+2。
- **节点3「老兵故事」**：拜访退役老将顾老太爷，听他讲述当年东渡的血泪史。立场·地域统一+2。
- **节点4「密信传递」**：帮返乡团传递一封密信给朝中大臣。情报点数+5，返乡团声望+12。
- **节点5「誓师之约」**（返乡团声望≥60）：正式被邀请参加返乡团的秘密誓师仪式。解锁返乡团专属兵种加成。

#### 派系任务-干城派「铁血边疆」
- **触发条件**：干城派声望≥20，步兵适性≥2星
- **节点1「前线来信」**：阅读干城派截获的前线战报，了解边疆冲突实况。干城派声望+8。
- **节点2「排斥航海」**：参加干城派内部的军事讨论，他们主张大陆军主义。立场·地域统一+3。
- **节点3「实战观摩」**：随干城派军官到边境观摩实战。步兵适性+10exp，训练+8exp。
- **节点4「兵制改良」**：为干城派提出兵制改良建议（需要管理≥2星）。干城派声望+15。
- **节点5「铁血宣言」**（干城派声望≥60）：在干城派集会上发表演说，获得"铁血新星"称号。

#### 派系任务-印第安乡党「红土之歌」
- **触发条件**：印第安乡党声望≥20，伊尔德好感≥30
- **节点1「部落使节」**：作为联络人与印第安部落使节会面。民族立场·共治+3。
- **节点2「草药之术」**：学习印第安传统医药知识。获得物品"部落药草包"（战斗中可恢复少量HP）。
- **节点3「狩猎仪式」**：参加部落年度狩猎仪式。骑兵适性+8exp。
- **节点4「自治之争」**：旁听印第安乡党内部保守派与激进派的争论，选择支持哪一方。影响后续任务走向。
- **节点5「红土誓约」**（声望≥60）：在部落圣地参加誓约仪式，获得印第安特殊兵种"鹰战士"的指挥权。

#### 派系任务-自由派「鼎新之光」
- **触发条件**：自由派声望≥20，管理≥2星或林素心好感≥30
- **节点1「启蒙之书」**：在图书馆找到自由派秘密传阅的启蒙著作译本。自由派声望+8。
- **节点2「议会之辩」**：参加自由派组织的模拟议会辩论。立场·治国共和+3，阶级民主+2。
- **节点3「印刷风云」**：帮自由派秘密印刷宣传册。自由派声望+12，有概率触发被学院追查事件。
- **节点4「改革蓝图」**：为自由派起草一份改革方案（需要管理≥3星）。立场·民主+3，共和+3。
- **节点5「鼎新宣言」**（声望≥60）：在自由派集会上宣读改革宣言。获得"鼎新之星"称号。

#### 派系任务-法治派「法度之衡」
- **触发条件**：法治派声望≥20，陈敬之好感≥20
- **节点1「法家讲堂」**：旁听吴存道教授的法家讲座。法治派声望+8。
- **节点2「判例研究」**：协助徐法官整理历史判例。管理+10exp。
- **节点3「军法演练」**：参与法治派主导的军法模拟审判。训练+8exp。
- **节点4「权与法」**：法治派内部讨论——扩大皇权还是限制皇权？选择影响后续走向。
- **节点5「法度传承」**（声望≥60，需吴存道存活）：继承吴存道遗志，获得"法度传人"称号和特殊道具"吴氏法典"。

### 2.4 日常任务

**定义**：每天可重复执行的活动类任务，是学科经验值和经验获取的基础来源。日常任务设计强调"有意义的重复"——每次执行都有微小变化和随机事件，避免枯燥。

**设计原则**：
- 日常任务消耗单个时段（早/午/晚/夜），不占据整天
- 每次执行获得的EXP量较低但稳定
- 部分日常任务有心情恢复效果
- 连续完成日常任务有"连续完成"加成（如连续7天晨练，第7天EXP翻倍）

**任务示例**：

#### 日常-01「晨练操枪」
- **触发条件**：每日清晨（早晨时段），在校场
- **目标**：进行步兵基础操练
- **奖励**：步兵适性+3exp，心情-2（训练辛苦）
- **随机事件**：10%概率偶遇同窗一起训练，好感+3；5%概率方孝先路过指导，步兵适性+5exp

#### 日常-02「马术练习」
- **触发条件**：每日清晨，在马厩
- **目标**：骑术训练
- **奖励**：骑兵适性+3exp，心情-1
- **随机事件**：15%概率遇到干城派骑兵教官指导，骑兵适性+5exp

#### 日常-03「炮台维护」
- **触发条件**：每日午后，在炮台
- **目标**：清洁和保养火炮
- **奖励**：炮兵适性+3exp，管理+1exp
- **随机事件**：8%概率发现火炮零件磨损，报告后获得后勤+5exp

#### 日常-04「图书馆自习」
- **触发条件**：每日晚间，在图书馆
- **目标**：自主阅读与学习
- **奖励**：管理+3exp，心情+1（安静学习的满足感）
- **随机事件**：20%概率遇到林素心，好感+3；5%概率发现稀有文献，获得特殊知识

#### 日常-05「食堂帮厨」
- **触发条件**：每日午间，在食堂
- **目标**：帮助厨房准备伙食
- **奖励**：后勤+3exp，心情+3（助人为乐）
- **随机事件**：10%概率在厨房听到八卦情报，情报点数+1

#### 日常-06「夜间巡逻」
- **触发条件**：每日夜间，在校园内
- **目标**：参与学生夜间巡逻
- **奖励**：训练+3exp，步兵适性+1exp
- **随机事件**：15%概率发现异常情况，触发小型探索事件

### 2.5 周常/月常任务

**定义**：周期性挑战任务，比日常任务难度更高、奖励更丰厚，通常涉及多人协作或竞争。

**任务示例**：

#### 周常-01「周末比武」
- **触发条件**：每周六下午
- **目标**：与随机同学进行1v1六边形战棋对战
- **奖励**：训练+8exp，根据胜负步兵/骑兵/炮兵适性+3~5exp
- **连胜机制**：连胜3场以上获得额外奖励"武试积分"，积分可在学期末兑换稀有物品

#### 周常-02「周末邀约」
- **触发条件**：每周日，可自由选择
- **目标**：邀请一名角色进行周末活动（共同训练/用膳/散步/外出游玩）
- **奖励**：根据邀约类型，好感+5~15
- **限制**：每周只能邀请1人，不同好感等级解锁不同邀约类型

#### 月常-01「月度考核」
- **触发条件**：每月最后一周的周三
- **目标**：参加学院月考（笔试+实操）
- **奖励**：根据排名，六学科各+5~15exp，排名前3额外获得"学院奖励金"
- **排名机制**：NPC同学也有成绩，与玩家竞争排名

#### 月常-02「狩猎活动」
- **触发条件**：每季度最后一个月
- **目标**：参加学院组织的狩猎活动（印第安学生主导）
- **奖励**：骑兵适性+10exp，印第安乡党声望+5，心情+10
- **特殊事件**：狩猎中可能遇到意外（野兽袭击/发现遗迹），触发探索任务

#### 月常-03「军事讲座」
- **触发条件**：每月第二个周三晚间
- **目标**：参加特邀嘉宾的军事讲座
- **奖励**：根据讲座内容，对应学科+5exp；不同讲座嘉宾来自不同派系，影响派系声望
- **随机事件**：讲座后的提问环节可以提升人望相关加成

### 2.6 探索任务

**定义**：发现隐藏地点、收集线索、揭开世界秘密的任务。探索任务不在任务列表中直接显示，需要玩家在闲逛中主动发现。

**设计原则**：
- 探索任务强调"发现"的惊喜感
- 与情报系统联动——部分探索任务需要先获得情报碎片
- 探索任务的奖励偏重于物品和信息，而非直接数值
- 部分探索任务与隐藏结局/隐藏任务关联

**任务示例**：

#### 探索-01「学院密室」
- **触发条件**：在图书馆闲逛时选择"翻看旧书架"，连续3次
- **目标**：发现图书馆地下密室的入口 → 探索密室 → 解读密室中的文献
- **奖励**：获得"郑明东渡密档"（历史文献），管理+10exp，解锁隐藏知识"东渡真相"
- **后续**：密档中提到的地名在战争期可触发额外事件

#### 探索-02「港口暗道」
- **触发条件**：第5周后，在港口区域闲逛3次以上
- **目标**：发现港口的一条隐秘走私通道 → 调查走私物品来源
- **奖励**：情报点数+10，获得物品"走私货物清单"
- **后续**：将清单交给不同派系获得不同奖励——返乡团（声望+15）/法治派（声望+12）/自由派（声望+10）

#### 探索-03「演武场遗迹」
- **触发条件**：夜间在演武场闲逛，需训练≥2星
- **目标**：发现演武场地下的古代训练场遗迹 → 解读壁画上的古代战阵
- **奖励**：训练+15exp，解锁特殊战术"古阵之法"（战斗中可用）
- **世界观关联**：壁画描绘的是郑成功时代的战术，与"返乡"主题呼应

#### 探索-04「市场秘闻」
- **触发条件**：在市场闲逛时与流浪商人交谈，连续5次
- **目标**：流浪商人透露一条通往城外秘密据点的路线 → 前往探索
- **奖励**：获得物品"独臂老海盗的藏宝图"（可兑换稀有装备）
- **后续**：独臂老海盗成为可交互NPC，提供特殊任务

#### 探索-05「月下祠堂」
- **触发条件**：月圆之夜（天气系统特定日期）在学院后山闲逛
- **目标**：发现一座隐蔽的祠堂 → 祭拜 → 解读祠堂碑文
- **奖励**：立场轴·民族+3（根据碑文内容），心情+15，获得"祠堂护符"（战斗中小幅提升士气）
- **世界观关联**：祠堂纪念的是郑明东渡时牺牲的先驱者

### 2.7 战斗挑战任务

**定义**：特殊的战斗关卡，包括演习、比武大会、特殊战役等。与普通战斗不同，挑战任务有独特的规则和奖励。

**任务示例**：

#### 战斗-01「校园比武大会」
- **触发条件**：第25周（第一学期末），六学科中任意≥2星
- **目标**：参加全校比武大会，通过3轮淘汰赛
- **奖励**：冠军获得"武试冠军"称号+全兵种适性+15exp；四强获得+10exp；参与+5exp
- **规则**：1v1六边形战棋，禁用火炮，限定步兵+骑兵

#### 战斗-02「模拟攻防战」
- **触发条件**：第40周，训练≥2星
- **目标**：参加学院组织的红蓝对抗演习（团队战）
- **奖励**：根据表现，训练+15exp，管理+10exp
- **规则**：5v5团队战，包含攻城/守城两种模式

#### 战斗-03「骑兵锦标赛」
- **触发条件**：第60周，骑兵适性≥3星
- **目标**：参加骑术竞技——包含速度赛、障碍赛和模拟冲锋
- **奖励**：骑兵适性+20exp，获得"骑士之证"（骑兵系装备加成+5%）
- **规则**：纯骑兵操作，考验走位和时机判断

#### 战斗-04「炮兵精准赛」
- **触发条件**：第70周，炮兵适性≥3星
- **目标**：在规定时间内用炮兵打击移动目标
- **奖励**：炮兵适性+20exp，获得"神炮手"称号
- **规则**：限时5回合，目标为移动中的编队

#### 战斗-05「夜袭演习」
- **触发条件**：第90周，训练≥3星，步兵适性≥3星
- **目标**：参加夜间突袭专项演习
- **奖励**：训练+20exp，步兵适性+10exp
- **规则**：利用夜战系统，在不被发现的情况下接近并消灭目标

### 2.8 收集任务

**定义**：收集特定物品、书籍、情报的任务。收集任务提供长期的探索动力。

**任务示例**：

#### 收集-01「百家典籍」
- **触发条件**：管理≥1星后，在图书馆触发
- **目标**：收集并阅读20本不同类别的书籍（兵法/历史/哲学/法律/地理/航海/医学/农学/商学/政治）
- **奖励**：每读完一类+5exp对应学科；集齐20本获得"博学之士"称号+管理+30exp
- **获取方式**：图书馆借阅、市场购买、角色赠送、探索发现

#### 收集-02「五方旗帜」
- **触发条件**：与5个派系均有接触后触发
- **目标**：收集5大派系的内部纲领文件
- **奖励**：每获得一份，对应派系理解度+10%；集齐5份获得"知己知彼"称号+全学科+5exp
- **获取方式**：完成各派系任务链的特定节点

#### 收集-03「将星图谱」
- **触发条件**：战争期开始后触发
- **目标**：在战场上遭遇并记录所有敌方将领的战术特征
- **奖励**：每记录一位将领，对其战斗时获得"情报加成"+5%；全部记录获得"名将猎人"称号

#### 收集-04「药材图鉴」
- **触发条件**：从印第安乡党角色处获得线索
- **目标**：在探索中收集12种美洲特有药材
- **奖励**：每种药材可制作对应药剂（战斗恢复/心情恢复/属性临时加成）
- **获取方式**：探索任务、狩猎活动、市场购买

### 2.9 随机/突发事件

**定义**：基于条件触发的动态事件，不在任务列表中预先显示，增加游戏的不可预测性和重玩价值。

**设计原则**：
- 随机事件有触发条件（不是完全随机），但触发时机有随机成分
- 事件通常只出现一次，不重复
- 事件的影响可大可小，但都有叙事意义

**任务示例**：

#### 突发-01「雨夜来客」
- **触发条件**：雨天的夜间，心情≥50，在宿舍
- **概率**：30%
- **事件**：一个浑身湿透的陌生人敲响宿舍门，自称是迷路的外乡人。赵伯衡（若室友）主张拒之门外，但主角可以选择收留他。
- **分支**：
  - 收留：此人是西班牙密探（需情报系统验证），情报点数+15
  - 拒绝：无事发生，但心情-5
  - 报告学院：法治派声望+5，但此人逃脱

#### 突发-02「市场暴动」
- **触发条件**：在市场闲逛，自由派声望≥30
- **概率**：20%
- **事件**：市场中商人与原住民发生冲突，迅速升级为暴动。主角在现场，需要做出选择。
- **分支**：
  - 帮助商人：自由派声望-10，但获得商人感激（市场折扣永久+5%）
  - 帮助原住民：印第安乡党声望+10，自由派声望-5
  - 维持秩序：管理+10exp，训练+5exp，双方中立
  - 趁乱离开：无影响，但心情-5

#### 突发-03「深夜决斗」
- **触发条件**：夜间在演武场，训练≥2星
- **概率**：15%
- **事件**：撞见两名高年级学生私下决斗。他们要求主角做见证人。
- **分支**：
  - 做见证人：训练+5exp，与两人各+5好感
  - 阻止决斗：报告教官，两人被罚，两人各-10好感，但教官+5好感
  - 加入决斗：训练+8exp，但可能被教官发现受罚

#### 突发-04「瘟疫警报」
- **触发条件**：夏季，心情<40
- **概率**：10%
- **事件**：学院内爆发传染病，主角面临是否照顾病患的选择。
- **分支**：
  - 照顾病患：心情-10（劳累），但全角色好感+5（义举），后勤+10exp
  - 自我隔离：安全，但心情-5（内疚）
  - 帮助许医官配药（需后勤≥2星）：后勤+15exp，获得"防疫功臣"称号

#### 突发-05「父亲的来信」
- **触发条件**：寒假前2周，主角家族封地相关
- **概率**：必定触发（每学期末）
- **事件**：父亲来信，通报家中近况并询问主角的近况。
- **分支**：
  - 如实相告：父亲根据主角表现给予建议或资源
  - 报喜不报忧：心情+5（维护面子），但失去一次获得建议的机会
  - 请求回家：心情+10，但寒假时间缩短，少一周自由行动

### 2.10 隐藏任务

**定义**：不显示在任务列表中，需要满足特定隐藏条件才能触发的任务。隐藏任务是游戏深度和重玩价值的核心。

**设计原则**：
- 隐藏任务的触发条件通常涉及多个系统交叉
- 隐藏任务的奖励独特且不可替代
- 隐藏任务与世界观深度关联，揭示主线未提及的真相

**任务示例**：

#### 隐藏-01「东渡密约」
- **触发条件**：完成探索任务"学院密室" + 管理≥3星 + 阅读过"郑明东渡密档"
- **事件**：主角发现郑明东渡时与西班牙曾签订过一份秘密条约——条约内容是郑明以部分领土换取西班牙的军事援助。这份条约至今未被公开。
- **分支**：
  - 公开条约：所有派系震动，立场轴大幅变动，解锁全新政治路线
  - 交给返乡团：返乡团声望+20，但民族立场·皇汉+5（他们想利用此事鼓动排外）
  - 销毁证据：法治派声望-10（如果被发现），但避免政治风暴
  - 交给西班牙密探：spain_contact+1（解锁E11暗线）

#### 隐藏-02「海盗遗产」
- **触发条件**：获得"独臂老海盗的藏宝图" + 在港口区域探索3次
- **事件**：按藏宝图指引找到独臂老海盗的秘密基地，发现他竟是当年东渡舰队的老兵，藏有大量珍贵军事文献和财富。
- **分支**：
  - 接受遗产：获得大量金钱和稀有装备，但独臂老海盗的身份曝光引来追杀
  - 只取文献：获得特殊战术知识（解锁隐藏兵种技能）
  - 上交学院：训练+30exp，获得学院嘉奖

#### 隐藏-03「母亲的秘密」
- **触发条件**：母族好感≥60 + 管理≥3星 + 在第8周、第30周、第60周分别拜访母亲家族
- **事件**：发现母亲家族（沈家）并非普通商贾——他们是郑明王朝的暗中金融支柱，掌控着王朝三成以上的海外贸易。母亲嫁入主角家族并非出于爱情，而是两个家族的政治联姻。
- **分支**：
  - 接受现实：母族好感+10，获得"沈氏商路"使用权（战争期经济加成）
  - 质问母亲：母族好感-10，母亲好感-15，但解锁母亲年轻时的回忆剧情
  - 利用情报：如果同时spain_contact≥2，可将沈家商路信息传递给西班牙，spain_contact+1

## 三、任务触发机制

### 3.1 时间触发

**按周触发**：
- 主线任务通常在特定周数自动触发（如第1周入学、第13周演习、第20周万寿节）
- 时间触发的任务会在任务列表中以"即将到来"的方式预告（提前1周显示）
- 若玩家在触发周处于特殊状态（如心情≤10、正在执行其他强制任务），任务顺延至下一周

**按学期触发**：
- 每学期初自动触发"新学期"事件，更新任务列表
- 学期末触发考核和总结事件
- 寒暑假触发假日专属任务

**按日期触发**：
- 特定历史纪念日触发纪念活动任务
- 天气系统中的特殊天气触发时令任务（如暴风雪中的紧急集合）

### 3.2 条件触发

**属性阈值触发**：
| 条件类型 | 示例 | 说明 |
|---------|------|------|
| 学科等级 | 步兵适性≥2星 | 解锁高级步兵训练任务 |
| 好感度 | 赵伯衡好感≥50 | 解锁赵伯衡支线第3节点 |
| 立场值 | 民族立场·皇汉≤-30 | 解锁返乡团高级任务 |
| 派系声望 | 自由派声望≥40 | 解锁自由派进阶任务 |
| 军衔 | 军衔≥少尉 | 解锁战争期指挥类任务 |
| 心情值 | 心情≤20 | 触发"心情危机"随机事件 |
| 物品持有 | 持有"独臂老海盗的藏宝图" | 解锁海盗遗产隐藏任务 |

**复合条件触发**：
- 多个条件同时满足才会触发，如"好感≥50 且 管理≥3星 且 雨天"
- 复合条件任务通常是隐藏任务或高级角色支线

### 3.3 连锁触发

**任务链机制**：
```
任务A完成 → 解锁任务B → 任务B完成 → 解锁任务C → ...
```

**连锁规则**：
- 主线任务的连锁是线性的，A→B→C必须按顺序完成
- 角色支线任务的连锁是好感度+前置任务的双重锁定
- 派系任务的连锁可能分叉——完成A后可选择B1或B2，两条路线互斥
- 部分连锁有隐藏分支——完成A后如果同时满足特定隐藏条件，可以解锁B3

**连锁示例**：
```
「食堂风波」选择帮助伊尔德
  → 连锁「猎场引路」（伊尔德支线节点1）
    → 连锁「篝火故事」（伊尔德支线节点2）
      → 连锁「部落访问」（伊尔德支线节点3 + 主线EV028）
        → 分叉：
          → 「双血之盟」（好感≥65，友好路线）
          → 「部落冲突」（好感<65，但声望足够）
```

### 3.4 随机触发

**概率触发规则**：

| 事件类型 | 基础概率 | 修正因素 |
|---------|---------|---------|
| 闲逛偶遇角色 | 20% | 好感≥70的角色+15% |
| 随机突发事件 | 10-30% | 根据当前状态调整（如低心情增加"瘟疫"概率） |
| 天气相关事件 | 天气出现时50% | 特定天气事件只在对应天气下判定 |
| 探索发现 | 5-15% | 对应学科等级越高，发现概率越高 |

**伪随机保底**：
- 连续3周未触发任何随机事件时，第4周必定触发1个
- 确保每个学期至少有2-3个随机事件，维持游戏的活力感

### 3.5 互斥与冲突

**任务互斥规则**：

| 互斥类型 | 说明 | 示例 |
|---------|------|------|
| 派系互斥 | 深入A派系后，对立派系高级任务关闭 | 完成返乡团节点4后，自由派节点4/5关闭 |
| 立场互斥 | 选择A立场方向后，对立立场任务不可用 | 选择"汉人优先"后，"多族共治"相关任务关闭 |
| 时间互斥 | 同一时段只能执行1个任务 | 晨练和早课不能同时进行 |
| 角色互斥 | 某些角色的支线任务不可同时推进 | 同时追求林素心和另一位女性角色时，三角关系事件触发 |
| 结局互斥 | 部分任务直接锁定/排除特定结局 | 完成spain_contact阶段3后，E4/E5排除 |

**冲突处理**：
- 当玩家同时接受的任务存在冲突时，系统弹出提示："注意：此任务可能与当前任务[XXX]产生冲突"
- 玩家仍可选择接受，但需知晓后果
- 冲突任务被放弃后不可恢复

### 3.6 任务容量

**同时任务上限**：

| 阶段 | 主线任务 | 支线任务 | 日常/周常 | 探索任务 | 总上限 |
|------|---------|---------|----------|---------|--------|
| 学院期 | 1-2 | 3-5 | 不限 | 2-3 | 12 |
| 战争期 | 1-3 | 1-2 | 不限 | 1-2 | 8 |

- 达到上限后无法接受新任务，必须先完成或放弃现有任务
- 主线任务和派系任务不计入上限（它们是强制/半强制的）
- 日常任务不计入上限（因为它们是重复性的，不是"接受"而是"执行"）

## 八、隐藏任务与彩蛋

### 8.1 隐藏任务详细设计

#### 隐藏-01「东渡密约」（详见第三章）
- **世界观关联**：郑明东渡时与西班牙的秘密交易，是整个架空历史的暗线。这份条约的存在解释了为何西班牙在郑明东渡初期没有强力阻拦。
- **触发巧妙度**：需要同时完成探索任务+达到学科阈值+阅读特定文献，三条线索互不相关但汇聚于此。

#### 隐藏-02「海盗遗产」（详见第二章）
- **世界观关联**：独臂老海盗是郑明东渡舰队的老兵，他选择留在民间而非进入体制，象征着"东渡精神"的另一种可能——不是功名利禄，而是自由。
- **触发巧妙度**：需要在市场闲逛5次（低概率事件）+获得藏宝图+在港口探索3次。

#### 隐藏-03「母亲的秘密」（详见第二章）
- **世界观关联**：沈家作为郑明的金融暗柱，揭示了王朝光鲜表面下的利益网络。母亲的选择也映射了那个时代女性在政治联姻中的困境。
- **触发巧妙度**：需要在分散的3个时间点分别拜访母族（第8/30/60周），错过任何一个都无法触发。

#### 隐藏-04「失落的东渡旗帜」
- **触发条件**：完成所有5个派系的终章任务 + 全派系声望≥80
- **事件**：五大派系领袖同时认可主角的能力，联合赠送一面当年东渡时的原始军旗。这面旗帜是郑成功东渡时携带的唯一旗帜的复制品。
- **奖励**：获得"东渡旗帜"特殊物品——战争期全军士气+5%。解锁成就"五族归一"。
- **世界观关联**：五大派系虽然政见不同，但共同的东渡记忆是他们的精神纽带。这面旗帜象征着"分歧中的统一"。

#### 隐藏-05「方孝先的过去」
- **触发条件**：训练≥4星 + 方孝先好感≥60 + 在第40/70/100周分别与他对话
- **事件**：方孝先讲述他年轻时参加最后一次东征作战的经历——他亲眼目睹了战争的残酷，这也是他退役从教的原因。他一直在寻找一个能"用智慧而非蛮力结束纷争"的学生。
- **奖励**：训练+30exp，获得"方孝先推荐信"（战争期初始军衔+1级），解锁方孝先专属战斗技能"老将之智"。
- **世界观关联**：方孝先是"返乡团"中的温和派，他代表了经历过战争创伤后对和平的渴望。

#### 隐藏-06「图书馆幽灵」
- **触发条件**：在夜间（夜时段）在图书馆自习连续30次 + 管理≥4星
- **事件**：主角在深夜的图书馆中感觉到一股异样的氛围。第30次时，一本古籍自动翻开，露出夹在其中的信笺——是150年前一位女性学者的日记，记录了郑明东渡初期女性在学院中求学的艰难历程。
- **奖励**：管理+20exp，获得"先驱者日记"（可交给林素心，林素心好感+20），解锁称号"时光读者"。
- **世界观关联**：呼应林素心"女性受教育权"的支线主题，也呼应自由派"启蒙"的理念。

#### 隐藏-07「皇帝的密旨」
- **触发条件**：军衔≥上校 + 人望≥60 + 返乡团声望≥70 + 法治派声望≥50
- **事件**：主角被秘密召入皇宫，皇帝亲手交出一道密旨——内容是任命主角为"特使"，在内战中有权代表皇室进行秘密谈判。
- **奖励**：解锁"皇室特使"身份，在战争期可以与敌方进行和平谈判（增加E1/E4的可能性）。
- **世界观关联**：皇帝在五大派系的博弈中试图保持平衡，培养一个"中间人"是他的自保策略。

#### 隐藏-08「部落守护者」
- **触发条件**：完成伊尔德全部支线任务 + 印第安乡党声望≥80 + 在部落访问中选择" embrace"
- **事件**：伊尔德的部落授予主角"部落守护者"的最高荣誉——这是从未授予过外族人的称号。仪式在月圆之夜的圣地举行。
- **奖励**：解锁"部落守护者"称号+永久兵种加成"鹰战士攻击力+10%"。
- **世界观关联**：象征主角跨越文化隔阂，真正被原住民社群接纳。

#### 隐藏-09「商路之王」
- **触发条件**：完成"母亲的秘密" + 在市场与所有商人NPC交易过 + 后勤≥4星
- **事件**：主角利用沈家商路和自身后勤知识，建立起覆盖新京及周边的高效贸易网络。
- **奖励**：解锁"商路之王"称号+战争期每回合额外获得金钱收入+解锁E8经商结局的额外加成。
- **世界观关联**：1760年代的美洲贸易网络是各方势力争夺的核心资源之一。

#### 隐藏-10「轮回之眼」
- **触发条件**：二周目 + 在一周目达成任意3个结局 + 第1周选择"翻墙"入学
- **事件**：主角在入学时突然产生一阵强烈的既视感——仿佛这一切都经历过。一个神秘的声音在耳边低语："你看到了所有的路，但这一次，你能改变终点吗？"
- **奖励**：解锁"轮回之眼"称号+二周目专属提示系统（在关键抉择时显示"似曾相识"标记，暗示此选项的走向）+获得1个"历史碎片"（7块之一）。
- **世界观关联**：暗示这个世界可能存在某种循环——东渡、建国、内战，是否会不断重演？

#### 隐藏-11「真结局碎片」
- **触发条件**：二周目 + 在7个特定事件的★选项中选择
- **事件**：在二周目的特定对话中，主角会发现一些"不属于这个时代"的文字碎片——记载着郑明王朝的真正历史和未来。
- **奖励**：收集全部7块碎片后，解锁隐藏事件EV-TRUE，是E7和E8成为"真结局"的前置条件。
- **世界观关联**：真结局不是简单的"好结局"，而是"理解了一切之后的选择"——知道历史的循环，依然选择回归或传承。
