## 一、战斗系统概述

### 1.1 战斗在游戏中的定位

《明路》的游戏循环分为两大阶段：**养成期**（军校3年）和**战争期**（内战主线+支线战役）。战斗系统在两个阶段中扮演不同角色：

#### 养成期（军校阶段）

| 维度 | 说明 |
|------|------|
| **战斗频率** | 约每2-3周一次战斗关卡，3年共约36场 |
| **战斗规模** | 小规模，3-8个编队，1-2个兵种为主 |
| **战斗目的** | 教学引导、学科验证、角色初次登场 |
| **难度曲线** | 渐进式，前5场为纯教学（固定胜利），后31场逐步增加复杂度 |
| **特殊战斗** | 期末考试（大型模拟战）、毕业演习（多关连续战）、边境冲突（实战入门） |
| **养成联动** | 战斗表现影响学科经验值；选择出战将领影响好感度增长 |

#### 战争期（内战阶段）

| 维度 | 说明 |
|------|------|
| **战斗频率** | 约每1-2周一次战斗关卡，共约44场+ |
| **战斗规模** | 大规模，8-20+个编队，全兵种混战 |
| **战斗目的** | 推进剧情、争夺地盘、决定阵营走向 |
| **难度曲线** | 阶梯式，每个战役阶段有1-2个Boss级关卡 |
| **特殊战斗** | 攻城战、伏击战、夜袭战、多路线分支战 |
| **养成联动** | 战斗结果影响派系关系、领土控制、角色存活、结局走向 |

#### 战斗系统的核心体验目标

```
玩家应该在每一场战斗中感受到：
  ① "排兵布阵"的掌控感 —— 走位、地形、编队构成策略深度
  ② "将帅同心"的情感纽带 —— 将领不是数值容器，而是有血有肉的战友
  ③ "以少胜多"的智谋快感 —— 地形、克制、士气可以弥补数量劣势
  ④ "战争代价"的沉重感 —— 角色会受伤、会阵亡，每个决定都有分量
```

## 二、回合机制

### 2.1 回合制基本规则

《明路》采用**交替回合制**（Alternate Turn），即一方行动完毕后轮到另一方。这与欧陆战争6的机制一致。

#### 回合类型

| 回合类型 | 控制方 | 可执行操作 | 持续时间 |
|---------|--------|-----------|---------|
| **玩家回合** | 玩家 | 操控所有己方编队 | 无时限（现实时间），但有回合数限制 |
| **敌方回合** | AI | AI自动操控所有敌方编队 | 由AI决策速度决定（可跳过/加速） |
| **中立阶段** | 系统 | 环境效果结算 | 自动执行 |

#### 回合交替规则

```
第1回合: 先手方行动 → 后手方行动 → 中立阶段结算 → 回合结束
第2回合: 后手方行动 → 先手方行动 → 中立阶段结算 → 回合结束
...
```

> **注意**：不存在"双方同时行动"的情况。严格交替，先手方先执行所有编队的行动，然后后手方执行。

### 2.2 回合结构详解

每个回合分为三个阶段：

#### 阶段一：开始阶段（Start Phase）

按以下固定顺序结算：

```
开始阶段结算顺序：
  ① 天气变化判定 → 检查是否切换天气（概率表见天气系统）
  ② 时段切换判定 → 检查是否切换白天/黄昏/夜晚
  ③ 回合计数 → 当前回合数+1
  ④ 补给结算：
     a. 所有单位消耗补给（按行动类型：待机2/移动3/攻击5/移动+攻击6）
     b. 补给线连通判定
     c. 有补给线的单位回复补给
     d. 缺补状态更新
     e. 断补单位HP损耗/溃散判定
  ⑤ 士气结算：
     a. 自然变化（夜间-2/回合，其他+0）
     b. 被动技能触发（如"威压"：相邻敌军士气-5）
     c. 将领军衔光环（如"三军之气"：全军士气+2）
     d. 缺补士气惩罚（中度-3，严重-8，断补-15）
  ⑥ 持续效果结算：
     a. 压制射击效果（移动力-1持续1回合的过期）
     b. 震慑效果（士气-10的持续判定）
     c. 其他有持续时间的效果
  ⑦ 先手射击结算：
     a. 精锐轻步兵的"先手射击"（回合开始对射程内最近敌军50%伤害自由射击）
```

#### 阶段二：行动阶段（Action Phase）

当前行动方依次操控每个编队执行行动。

```
行动阶段流程：
  ├── 列出所有存活且可行动的己方编队
  ├── 玩家/AI 选择一个编队
  │   ├── 高亮显示可移动范围（六边形高亮）
  │   ├── 玩家/AI 选择目标格子 → 执行移动
  │   ├── 高亮显示可攻击范围
  │   ├── 玩家/AI 选择攻击目标/不攻击 → 执行攻击或跳过
  │   └── 该编队行动完毕 → 标记为"已行动"
  ├── 选择下一个编队 → 重复上述流程
  └── 所有编队行动完毕（或玩家主动结束） → 进入结束阶段
  
特殊规则：
  - 已行动的编队仍可执行"等待"指令（见2.5）
  - 编队行动顺序由玩家/AI自由决定
  - 炮兵"缓慢部署"：围城炮首回合无法攻击，整个编队行动阶段只能移动或待机
```

#### 阶段三：结束阶段（End Phase）

```
结束阶段结算顺序：
  ① 逃兵判定（严重缺补单位5%概率逃兵）
  ② 溃散判定（断补单位按持续回合查表判定）
  ③ HP自然恢复（有后勤将领的单位回复HP）
  ④ 控制区域(ZOC)更新
  ⑤ 战场事件判定（增援到达、剧情触发等）
  ⑥ 胜利/失败条件检查
  ⑦ 回合限制检查（是否超时）
  ⑧ 若未结束 → 切换到对方回合
```

### 2.3 先手权计算

#### 先手权决定规则

不同战斗类型的先手权规则不同：

| 战斗类型 | 先手权规则 | 说明 |
|---------|-----------|------|
| **常规战斗** | 攻方先手 | 发起进攻的一方先行动 |
| **防守战** | 守方先手 | 防守方占据阵地，先部署先行动 |
| **遭遇战** | 随机 | 50%概率任一方先手 |
| **伏击战** | 伏击方先手 | 伏击方获得先手优势 |
| **夜袭战** | 偷袭方先手 | 发起夜袭的一方先手 |
| **攻城战** | 攻方先手 | 攻城方先行动 |
| **模拟战/考试** | 随机或指定 | 由关卡配置决定 |

#### 先手权争夺机制

部分条件可以改变先手权：

| 条件 | 效果 | 说明 |
|------|------|------|
| 将领训练学科≥4星 | 先手概率+20% | 训练有素的部队反应更快 |
| 拥有轻骑兵且部署在前沿 | 先手概率+10% | 骑兵侦察提前发现敌军 |
| 占据高地（山丘/山地） | 先手概率+10% | 高地视野优势 |
| 天气为雾天 | 先手概率+15%（防守方） | 浓雾中防守方更容易设伏 |
| 补给充足（>80） | 先手概率+5% | 后勤充沛的部队更从容 |

> **先手概率计算公式**：`P(先手) = 基础概率 + Σ修正值`，上限95%，下限5%。遭遇战中基础概率=50%。

### 2.4 回合数限制

| 关卡类型 | 回合限制 | 超时后果 |
|---------|---------|---------|
| **教学关卡** | 无限制 | 无 |
| **常规战斗** | 由关卡配置，通常15-30回合 | 见难度系统 |
| **防守关卡** | 坚守N回合（N由关卡设定） | 未坚守够回合数=失败 |
| **追击关卡** | 通常20-25回合 | 目标逃脱=失败 |
| **BOSS关卡** | 通常30-50回合 | 超时敌方增强 |
| **期末考试** | 通常20-30回合 | 超时扣分 |

**超时惩罚（按难度）**：
- **休闲模式**：无惩罚，敌方不增强
- **普通模式**：超时后敌方每回合士气+2、攻击+3%
- **困难模式**：超时后敌方每回合士气+5、攻击+5%
- **噩梦模式**：超时直接判定失败

### 2.5 等待/防御指令

玩家可在编队行动阶段使用以下特殊指令：

#### 等待（Wait）

```
效果：该编队暂时结束行动，但可以在本回合其他编队行动后再行动一次。
使用场景：
  - 先让其他编队攻击，等敌军反击后再让该编队补刀
  - 等待友军打开缺口后突入
限制：
  - 每个编队每回合只能使用一次等待
  - 等待后仍受移动力限制（不能恢复已消耗的移动力）
  - 等待后的第二次行动中不能再使用等待
结算顺序：
  - 所有"等待"中的编队在本回合正常编队行动完毕后，按玩家选择顺序依次行动
  - 等待编队的行动视为"回合末尾行动"
```

#### 防御（Guard）

```
效果：该编队放弃本回合的移动和主动攻击，获得防御姿态加成。
防御姿态加成：
  - 减伤+15%（直到下回合该编队行动前）
  - 反击伤害+20%
  - 士气恢复+3
  - 若敌军进入相邻格：该编队获得"预备射击"（敌军攻击前先受一次自由射击，50%伤害）
使用场景：
  - 步兵驻守阵地等待骑兵冲锋
  - 炮兵架设阵地准备射击
  - 残血部队固守待援
限制：
  - 进入防御姿态后，本回合无法移动和主动攻击
  - 防御姿态持续到下回合该编队开始行动前自动解除
```

#### 待命（Hold）

```
效果：最简单指令，本回合不移动不攻击，仅消耗2点补给。
与防御的区别：
  - 待命无防御加成，但可在下回合第一优先级行动（相当于"预备"）
  - 防御有+15%减伤，待命无
使用场景：
  - 保留补给（仅消耗2而非移动3/攻击5）
  - 不改变当前站位
```

### 2.6 行动点系统

《明路》**不采用行动点（AP）系统**。

设计理由：
- 六边形战棋的传统乐趣在于"走格+攻击"的二元决策，AP系统增加操作复杂度但不增加策略深度
- 每个编队每回合固定"移动一次+攻击一次"的结构更清晰
- 与欧陆战争6的参考框架一致
- 通过"移动后攻击惩罚"（见第三章）来实现机动与火力的权衡，而非AP消耗

**替代机制**：
- 部分兵种"移动后攻击"有惩罚（如炮兵攻击-20%）
- 等待指令允许调整行动顺序
- 部分技能提供额外行动（如"急掠如风"击杀后额外移动）

### 3.2 地形移动消耗

每进入一个六边形格子消耗的移动力：

| 地形 | 步兵消耗 | 骑兵消耗 | 炮兵消耗 | 说明 |
|------|:-------:|:-------:|:-------:|------|
| **平原** | 1 | 1 | 1 | 标准地形 |
| **山丘** | 1 | 1 | 1 | 缓坡，对骑兵轻微影响（见3.3） |
| **山地** | 2 | 3 | 3 | 陡峭地形，严重限制机动 |
| **森林** | 1 | 2 | 3 | 密林阻碍骑兵和炮兵 |
| **沿河** | 2 | 3 | 3 | 渡河消耗巨大 |
| **村子** | 1 | 1 | 1 | 小型聚落 |
| **镇子** | 1 | 1 | 1 | 中型聚落 |
| **小城市** | 1 | 2 | 2 | 城墙限制骑兵/炮兵 |
| **大城市** | 1 | 2 | 2 | 大型城防 |
| **超大城市** | 1 | 2 | 2 | 巨型城防 |
| **栅栏** | 1 | 2 | 2 | 简易障碍物 |
| **掩体** | 1 | 1 | 1 | 工事，步兵友好 |
| **壕沟** | 1 | 3 | 3 | 反骑兵/反炮兵工事 |

**实际进入格子的移动力计算公式**：
```
实际消耗 = 基础地形消耗 × 季节修正 × 天气修正（取整，最低1）
```

**季节修正**（参见天气系统13文档）：
| 地形 | 春 | 夏 | 秋 | 冬 |
|------|---|---|---|---|
| 平原 | ×1.0 | ×1.0 | ×1.0 | ×1.2 |
| 山地 | ×2.0 | ×1.8 | ×2.0 | ×2.5 |
| 森林 | ×1.2 | ×1.0 | ×1.0 | ×1.5 |
| 沿河 | ×3.5(春汛) | ×2.5 | ×2.5 | 结冰×1.5 |

**天气修正**：
| 天气 | 所有地形额外消耗 | 说明 |
|------|:--------------:|------|
| 晴天 | +0 | 标准 |
| 多云 | +0 | 无影响 |
| 小雨 | +0 | 无直接影响 |
| 大雨 | +1（对所有地形） | 泥泞 |
| 雪 | +1 | 积雪 |
| 雾 | +0 | 无移动影响 |
| 暴风雪 | +2 | 极端恶劣 |

> **最低消耗规则**：任何情况下，进入一个格子的最低消耗为1移动力。

### 3.3 移动力详细计算示例

**示例1：线列步兵在雨天进入森林**
```
基础消耗：1（步兵进森林）
天气修正：大雨 +1
实际消耗：1 + 1 = 2
移动力3的线列步兵可进入森林的格子数：1格(消耗2)+无法再进入第2格森林(需2但只剩1)
→ 雨天步兵只能进入1格森林
```

**示例2：骠骑兵在晴天平原冲锋**
```
基础消耗：1（骑兵进平原）
无修正
实际消耗：1
移动力6 → 可直线移动6格平原
→ 触发枪骑兵"冲锋"（直线移动≥3格后攻击+30%）
```

**示例3：重火炮在冬季山地**
```
基础消耗：3（炮兵进山地）
季节修正：冬季×2.5 = 3×2.5 = 7.5 → 取整8
实际消耗：8
移动力1的重火炮完全无法进入冬季山地
```

### 3.4 控制区域（ZOC）机制

**ZOC定义**：每个作战单位对其相邻6格（六边形周围一圈）施加控制区域。

#### ZOC规则

```
ZOC基本规则：
  ① 每个存活单位对其相邻6格产生ZOC
  ② 敌方单位进入己方ZOC时：
     a. 必须停止移动（不能穿过ZOC继续前进）
     b. 若ZOC内有己方单位，进入者受到"机会攻击"（见3.5）
  ③ 己方ZOC不会阻碍己方单位移动
  ④ 以下情况无视ZOC：
     - 骠骑兵"双重打击"：攻击后可再移动2格，无视路径上的ZOC
     - 激进型AI"突破"：强行通过ZOC但受到机会攻击
     - 部分技能（如"行军无阻"）
```

#### ZOC与撤退

```
撤退经过ZOC的规则：
  - 撤退路线不能经过敌方ZOC（必须绕行）
  - 若所有撤退路线都被敌方ZOC覆盖 → 无法撤退 → 被包围
  - 被包围判定：单位相邻6格全部为敌方单位或敌方ZOC
```

### 3.5 机会攻击（Opportunity Fire）

当敌方单位进入己方ZOC时，己方单位可执行一次机会攻击：

```
机会攻击规则：
  触发条件：敌方单位进入己方单位相邻格
  攻击类型：仅限近战攻击（步兵/骑兵），炮兵不执行机会攻击
  伤害：正常攻击伤害的50%
  反击：触发机会攻击后，进攻方不能反击
  限制：每个单位每回合最多执行1次机会攻击
  优先顺序：玩家控制的单位由玩家选择是否执行；AI单位自动判断
```

### 3.6 移动后的状态变化

| 情况 | 效果 | 说明 |
|------|------|------|
| **移动后攻击（步兵）** | 无惩罚 | 步兵移动后正常攻击 |
| **移动后攻击（骑兵）** | 冲锋加成（直线≥3格+30%） | 骑兵的核心优势 |
| **移动后攻击（炮兵）** | 攻击力-20% | 炮兵移动后需重新架设 |
| **轻火炮移动后攻击** | 攻击力-20% | 轻火炮保留机动射击能力 |
| **重火炮及以上移动后攻击** | 攻击力-40% | 重型火炮重新架设困难 |
| **移动力耗尽后** | 无法继续移动 | 本回合剩余移动力=0 |
| **低血量移动惩罚** | 移动力-1 | HP<30%时移动力下降 |
| **缺补移动惩罚** | 轻度-1/中度-1/严重-2/断补-2 | 累积惩罚 |

### 3.7 撤退/脱离战斗

#### 主动撤退

```
主动撤退指令：
  触发：玩家手动选择"撤退"指令
  效果：该编队向己方部署区方向移动，移动力+2（撤退激励）
  限制：
    - 撤退中不能攻击
    - 撤退路线不能经过敌方ZOC
    - 撤退中的单位被敌方追击时受到伤害+25%
  用途：将残血部队撤到安全位置
```

#### 被迫撤退（溃退）

```
溃退触发条件：
  ① 士气崩溃（士气值降至0-19）
  ② 被包围且HP<50%
  ③ 将领阵亡且士气<40
  
溃退行为：
  - 该编队失去控制，自动向远离最近敌军的方向移动
  - 溃退移动力=基础移动力+1（恐慌奔逃）
  - 溃退中经过的格子不消耗移动力（直线逃跑）
  - 溃退经过敌方ZOC时受到伤害=正常伤害×75%
  - 溃退持续到：
    a. 到达己方部署区（安全脱离战场）
    b. 移动到友军将领相邻格（将领安抚，停止溃退，士气重置为25）
    c. 累计溃退3格后停止（精疲力竭），士气重置为15
    d. 溃退中被击杀
```

### 3.8 移动路径计算

#### 寻路算法要求

```
寻路基本规则：
  ① 使用A*算法或类似路径finding
  ② 路径代价 = 地形移动消耗之和
  ③ 避开敌方ZOC（除非必须经过）
  ④ 避开不可通行地形
  ⑤ 骑兵偏好平原（路径代价平原<森林<山地）
  ⑥ 炮兵偏好平坦地形（路径代价平原<山丘<其他）
  
编队特殊规则：
  - 三编队占2格空间：路径计算需考虑占用空间
  - 围城炮占2格：不能进入宽度<2格的通道
```

## 四、攻击系统

### 4.1 攻击流程详解

```
攻击完整流程：
  
  [玩家选择攻击目标]
      │
      ▼
  [前置检查]
  ├── 检查射程：目标是否在攻击范围内？
  ├── 检查视线(LOS)：攻击路径是否有遮挡？
  ├── 检查弹药/补给：补给值>0？（炮兵需额外检查）
  ├── 检查状态：单位是否能攻击？（非溃退/非防御姿态/非哑火）
  └── 检查特殊限制：围城炮首回合？炮兵移动惩罚？
      │
      ▼
  [伤害预计算]
  ├── 读取面板输出（取攻击力范围内的随机值或固定值）
  ├── 计算各加成项（士气、编队、将领星级、地形）
  ├── 计算克制系数（兵种矩阵+地形修正）
  ├── 计算减伤（防御方减伤来源汇总，上限75%）
  ├── 计算技能加成减免
  └── 应用伤害公式
      │
      ▼
  [命中判定]
  ├── 计算命中率（基础值+修正）
  ├── 随机骰点（0-100）
  └── 骰点 ≤ 命中率 → 命中；骰点 > 命中率 → 未命中
      │
      ▼ (命中)
  [暴击判定]
  ├── 计算暴击率
  ├── 随机骰点
  └── 暴击 → 伤害 ×暴击倍率
      │
      ▼
  [伤害结算]
  ├── 最终伤害 = max(1, 计算伤害)
  ├── 伤害封顶 = 目标最大HP × 2
  ├── 扣除防御方HP
  ├── 扣除防御方补给（攻击消耗）
  └── 更新防御方状态
      │
      ▼
  [后 effect 结算]
  ├── 士气变化（攻方/守方）
  ├── 反击判定（近战且守方存活且未溃退）
  ├── 溅射伤害（AOE类攻击）
  ├── 特殊效果触发（压制/震慑/溃退等）
  └── 判定守方是否阵亡
      │
      ▼
  [阵亡判定]
  ├── HP ≤ 0 → 阵亡
  │   ├── 将领处理（阵亡/重伤/生还）
  │   ├── 士气冲击（友军士气变化）
  │   ├── 技能触发（急掠如风等）
  │   └── 从战场移除
  └── HP > 0 → 存活，继续战斗
```

### 4.3 命中率计算

#### 基础命中率

```
基础命中率 = 80%（所有远程攻击）
基础命中率 = 95%（所有近战攻击，即射程1格）
```

#### 命中率修正表

| 修正因素 | 命中率变化 | 说明 |
|---------|:---------:|------|
| **攻击方状态** | | |
| 士气高昂（80-100） | +5% | 士气高涨射击更准 |
| 士气低落（20-49） | -10% | 士气低迷影响瞄准 |
| 士气崩溃（0-19） | -30% | 恐慌中无法瞄准 |
| HP<30% | -10% | 伤亡惨重影响战斗力 |
| **防御方状态** | | |
| 防御方驻守（未移动） | -5% | 驻守目标更难命中（有准备） |
| 防御方在掩体/壕沟 | -10% | 掩体遮挡 |
| 防御方在森林 | -5% | 树林遮挡 |
| 防御方在山地 | -5% | 地形遮挡 |
| 防御方在城市 | -10% | 建筑掩护 |
| 防御方HP<30% | +5% | 残血目标更容易命中 |
| **环境因素** | | |
| 雨天 | -5% | 雨幕影响 |
| 大雨 | -15% | 暴雨严重影响 |
| 雾天 | -15% | 浓雾遮挡 |
| 夜间（白天时段外） | -10% | 视野受限 |
| 黄昏 | -3% | 光线渐暗 |
| 暴风雪 | -25% | 极端恶劣 |
| **距离因素** | | |
| 每超出基础射程1格 | -5% | 远距离精度衰减 |
| **地形高低** | | |
| 从高地射击低地 | +5% | 俯视优势 |
| 从低地射击高地 | -5% | 仰射劣势 |
| **技能修正** | | |
| 散兵队形（来复枪兵在森林/山丘） | +10% | 精准射击加成 |
| 固定阵地（重火炮驻守≥2回合） | +10% | 充分准备 |
| 机动射击（轻火炮移动后） | -10% | 移动中精度降低 |

#### 命中率公式

```
最终命中率 = 基础命中率 + Σ(所有修正值)
最终命中率 = max(10%, min(99%, 最终命中率))  // 最低10%，最高99%

命中判定：
  random(0, 100) < 最终命中率 → 命中
  random(0, 100) >= 最终命中率 → 未命中（Miss）
```

#### 未命中处理

```
远程攻击未命中时：
  - 炮弹/子弹落空
  - 炮兵：消耗补给但不造成伤害
  - 若射程内有友军格子：
    - 白天：2%概率友军误伤（造成50%伤害）
    - 夜间：8%概率友军误伤（来复枪兵/精锐轻步兵降至4%）
  
近战攻击未命中时：
  - 刺刀/马刀挥空
  - 不消耗额外补给
  - 可以反击（攻击方近战未命中，防御方仍可反击）
```

### 4.4 伤害计算（完整公式拆解）

#### 核心伤害公式

```
攻击输出 = (面板输出 × 我方兵种血量系数 
         + 我方士气等级 × 我方编队系数 × 我方兵种血量系数 
         - 敌方士气等级 × 敌方编队系数 × 敌方兵种血量系数 
         + 将领对应兵种星数 × 5 × 将领血量系数 
         - 2 × 对方等级) 
         × 兵种克制系数 
         × (1 - 减伤百分比值) 
         × 技能加成减免
```

#### 变量精确定义

| 变量名 | 精确定义 | 取值范围 | 数据来源 |
|--------|---------|:-------:|---------|
| **面板输出** | 兵种攻击力，取攻击力范围内随机值 | 6-85 | 兵种表(01文档) |
| **我方兵种血量系数** | 攻击方编队的HP相关系数 | 1.0-3.0 | 编队HP/基准HP |
| **我方士气等级** | 攻击方士气数值 | 0-100 | 士气系统 |
| **我方编队系数** | 攻击方编队规模系数 | 5/6/7 | 单编5/双编6/三编7 |
| **敌方士气等级** | 防御方士气数值 | 0-100 | 士气系统 |
| **敌方编队系数** | 防御方编队规模系数 | 5/6/7 | 单编5/双编6/三编7 |
| **敌方兵种血量系数** | 防御方编队的HP相关系数 | 1.0-3.0 | 编队HP/基准HP |
| **将领对应兵种星数** | 攻击方将领对应兵科学科星级 | 0-5 | 将领属性 |
| **将领血量系数** | 将领等级/星级挂钩的加成 | 1.0-1.5 | 将领属性 |
| **对方等级** | 防御方部队等级 | 0-5 | 部队等级 |
| **兵种克制系数** | 攻→防克制矩阵值+地形修正 | 0.6-1.7 | 克制矩阵(01文档)+地形修正 |
| **减伤百分比值** | 防御方总减伤 | 0%-75% | 技能+地形+被动汇总 |
| **技能加成减免** | 技能乘算因子 | 0.5-2.0 | 技能系统(02文档) |

#### 血量系数精确定义

```
兵种血量系数 = 当前编队HP / 基准HP

基准HP定义（单编HP）：
  民兵: 50
  线列步兵: 65
  来复枪兵: 80
  精锐轻步兵: 95
  近卫军: 115
  禁军: 140
  火枪骑兵: 105
  轻骑兵: 55
  枪骑兵: 72
  重骑兵: 95
  骠骑兵: 85
  霹雳炮: 45
  轻火炮: 60
  重火炮: 78
  加农炮: 90
  榴弹炮: 105
  围城炮: 125

编队HP = 单编HP × 编队倍数
  单编: ×1 (系数1.0)
  双编: ×2 (系数2.0)  
  三编: ×3 (系数3.0)

注意：血量系数使用满HP值而非当前HP值，以保证公式稳定性。
当前HP用于判断阵亡和低血量惩罚。
```

#### 计算示例

**示例：双编来复枪兵（士气85）攻击三编轻骑兵（士气60）在森林**

```
攻方参数：
  面板输出 = 32（取中值，范围18-40）
  兵种血量系数 = 2.0（来复枪兵双编 = 80×2 = 160HP，系数=160/80=2.0）
  士气等级 = 85
  编队系数 = 6（双编）
  将领兵种星数 = 3（步兵适性3星）
  将领血量系数 = 1.0

守方参数：
  士气等级 = 60
  编队系数 = 7（三编）
  兵种血量系数 = 3.0（轻骑兵三编 = 55×3 = 165HP，系数=165/55=3.0）
  部队等级 = 1

克制系数 = 1.5（来复枪兵→轻骑兵）+ 0.2（森林地形步兵→骑兵修正）= 1.7
减伤 = 0%
技能加成 = 1.0

基础值 = 32×2.0 + 85×6×2.0 - 60×7×3.0 + 3×5×1.0 - 2×1
       = 64 + 1020 - 1260 + 15 - 2
       = -163

最终伤害 = -163 × 1.7 × 1.0 × 1.0 = -277.1

保底规则：最终伤害 = max(1, -277.1) = 1

分析：此场景中守方三编士气60的抵消项（60×7×3.0=1260）大于攻方士气项（85×6×2.0=1020），
      导致基础值为负。这说明三编高士气的骑兵在数量上压制了双编来复枪兵的士气和面板。
      但来复枪兵仍然有克制优势(1.7)和射程优势(2-4格)来弥补。
```

> **重要修正说明**：04_数值平衡公式中提到了三种修正方案（A整体缩放、B血量归一化、C分离公式）。**本文档以方案B为基础实现**，即血量系数使用`编队HP/基准HP`，最终伤害统一除以缩放因子50。修正后公式：

```
修正后攻击输出 = ((面板输出 × 我方兵种血量系数 
                + 我方士气等级 × 我方编队系数 × 我方兵种血量系数 
                - 敌方士气等级 × 敌方编队系数 × 敌方兵种血量系数 
                + 将领对应兵种星数 × 5 × 将领血量系数 
                - 2 × 对方等级) / 50)
                × 兵种克制系数 
                × (1 - 减伤百分比值) 
                × 技能加成减免

保底：最终伤害 = max(1, 计算结果)
封顶：最终伤害 = min(最终伤害, 目标当前HP × 2)  // 单次攻击不超过当前HP的2倍
```

**用修正公式重算上例**：
```
基础值 = (64 + 1020 - 1260 + 15 - 2) / 50 = -163 / 50 = -3.26
最终伤害 = max(1, -3.26 × 1.7 × 1.0 × 1.0) = max(1, -5.54) = 1
→ 至少造成1点伤害（保底）
```

**正面场景（来复枪兵伏击骑兵，双方单编）**：
```
攻方：来复枪兵单编，面板=32，血量系数=1.0，士气=85，编队=5，将领=3星，系数=1.0
守方：轻骑兵单编，士气=40（低落），编队=5，血量系数=1.0，等级=1
克制=1.7，减伤=0%，技能=1.8（伏击加成）

基础值 = (32×1.0 + 85×5×1.0 - 40×5×1.0 + 3×5×1.0 - 2×1) / 50
       = (32 + 425 - 200 + 15 - 2) / 50
       = 270 / 50
       = 5.4

最终伤害 = 5.4 × 1.7 × 1.0 × 1.8 = 16.5
守方HP = 55（轻骑兵单编）
伤害比 = 16.5 / 55 = 30%
→ 伏击条件下，来复枪兵单编一回合打掉轻骑兵单编约30%HP，需要约4次攻击击杀。合理。
```

### 4.6 闪避/格挡

#### 闪避

《明路》中闪避通过**命中率系统**实现（见4.3），不作为独立属性。地形掩体、驻守状态等通过降低敌方命中率来实现"闪避"效果。

#### 格挡（近战专属）

```
格挡定义：近战攻击时，防御方有概率"格挡"部分伤害。
基础格挡率 = 0%
格挡效果：减少受到的伤害25%（不减到0，最低受25%伤害）

格挡率修正：
  线列步兵驻守：+10%（刺刀方阵格挡冲锋）
  近卫军：+15%（铁壁被动）
  禁军：+20%（重甲+训练）
  重骑兵：+10%（胸甲防护）
  技能"铁壁防御"：+10%
  技能"铜墙铁壁"：+15%
  
最终格挡率 = max(0%, min(40%, Σ格挡修正))
格挡判定：random(0, 100) < 最终格挡率 → 触发格挡
```

### 4.7 反击机制

```
反击触发条件：
  ① 攻击方执行近战攻击（射程=1格）
  ② 防御方在攻击后仍然存活（HP>0）
  ③ 防御方未处于溃退/崩溃状态
  ④ 防御方本回合未执行过攻击（未行动过）
  
反击伤害 = 正常攻击伤害 × 50%

反击特殊规则：
  - 反击使用防御方的克制系数（而非攻击方的）
  - 反击不触发暴击（除非防御方有"反击必杀"技能）
  - 反击不消耗补给
  - 远程攻击（射程>1格）不触发反击
  - 炮兵不执行反击
  
反击示例：
  重骑兵冲锋线列步兵 → 造成50伤害 → 线列步兵存活（HP130→80）
  → 线列步兵反击 → 使用线列步兵对骑兵克制1.3 → 反击伤害30
  → 重骑兵受到30反击伤害
```

### 4.8 连击/追击

#### 连击

```
连击定义：一次行动阶段内对同一目标进行多次攻击。
基本规则：每个编队每回合只能攻击一次。

连击触发条件（技能/被动）：
  - 骠骑兵"双重打击"：攻击后未击杀可再移动2格（非真正连击，是移动+再攻击机会）
  - 技能"连珠炮"（炮兵）：攻击后30%概率立即再射一次（伤害-40%）
  - 技能"狂风骤雨"：击杀目标后可立即攻击相邻另一个目标（伤害-30%）
```

#### 追击

```
追击定义：对正在撤退/溃退的敌军进行追加攻击。
触发条件：
  - 目标正在执行撤退指令
  - 目标正在溃退
  - 目标HP<20%试图脱离

追击伤害 = 正常攻击伤害 × 1.25（+25%追击加成）

追击执行条件：
  - 追击方移动力足够追上目标
  - 追击方本回合尚未攻击
  - 轻骑兵"追击"被动：对撤退中敌军伤害额外+25%（总计+50%）
```

### 5.2 地形视线（LOS）计算

#### LOS基本规则

```
视线(Line of Sight)计算规则：
  ① 从攻击方中心格到目标格画一条直线
  ② 检查直线经过的所有中间格子
  ③ 如果中间有任何"遮挡地形"，视线被阻断
  
遮挡地形列表：
  完全遮挡（阻断LOS）：
    - 山地格（高度遮挡）
    - 大城市/超大城市的建筑格
    - 森林格（树冠遮挡，但可射击森林内部）
  
  部分遮挡（降低命中率但不阻断LOS）：
    - 山丘格（-5%命中率）
    - 小城市建筑格（-5%命中率）
    - 栅栏格（-3%命中率）
  
  不遮挡：
    - 平原、沿河、掩体、壕沟、村子、镇子
    
  特殊：
    - 榴弹炮"超越射击"：可越过友军单位射击（无视友军遮挡）
    - 高地射击低地：山地/山丘上的单位射击时，中间的低地遮挡物不阻断LOS
```

### 5.3 高地优势

```
高地优势规则：
  定义：攻击方所在格的海拔高于目标格
  
  海拔等级（低→高）：
    平原/沿河/聚落 < 山丘 < 山地
  
  高地→低地攻击加成：
    命中率 +5%
    射程 +1格
    骑兵冲锋加成保留（从山丘冲锋）
    
  低地→高地攻击惩罚：
    命中率 -5%
    移动进入高地格消耗额外+1
    
  同级海拔：
    无加成无惩罚
```

### 6.6 崩溃/溃逃机制

```
崩溃状态触发：
  当士气值降至0-19时，进入崩溃状态。

崩溃后行为（每回合结束时判定）：
  ① 溃退判定：
     溃退概率 = 基础概率 + 修正
     
     基础概率 = 30%/回合
     
     修正：
       近卫军/禁军：永不溃退（崩溃状态仍可控制，攻击力-30%但不会逃跑）
       民兵：+20%（总50%/回合）
       精锐兵种：-15%（总15%/回合）
       将领在相邻格：-15%
       周围3格内≥2支友军：-10%
       被包围：+20%
     
  ② 溃退执行：
     若判定溃退 → 该编队进入失控状态
     → 自动向远离最近敌军的方向移动
     → 移动力=基础移动力+1
     → 不能攻击、不能控制
     → 溃退路线上的敌方ZOC造成75%伤害
     → 溃退持续直到：
       a. 脱离战场（到达己方部署区边缘）→ 该编队从战场移除，将领生还
       b. 移动到友军将领相邻格 → 停止溃退，士气重置为25
       c. 溃退3格后 → 停止溃退，士气重置为15，但本回合仍不可控
       d. 溃退中被击杀 → 编队阵亡
       
  ③ 溃逃传染：
     当一支部队溃退时，相邻格友军进行士气检定：
       检定：random(0,100) < 当前士气值 → 通过，不传染
       检定失败 → 该友军士气-10
       若士气因此降至崩溃线 → 同样进入崩溃判定
```

### 7.1 单编/双编/三编的区别

| 属性 | 单编 | 双编 | 三编 |
|------|:----:|:----:|:----:|

| **战场占用** | 1格 | 1格 | 2格（连续） |
| **补给消耗系数** | ×0.8 | ×1.0 | ×1.3 |
| **招募费用** | 基础×1 | 基础×2 | 基础×3 |
| **招募条件** | 无前置 | 对应兵营等级+资源 | 高级兵营+更多资源 |

### 7.2 编队系数详解

编队系数在伤害公式中的作用：

```
攻击方编队系数 → 影响 "我方士气等级 × 我方编队系数 × 我方兵种血量系数" 项
防御方编队系数 → 影响 "敌方士气等级 × 敌方编队系数 × 敌方兵种血量系数" 项

编队系数越高：
  攻击方：士气攻击项越大 → 输出越高
  防御方：士气防御项越大 → 越能抵消攻击方士气优势

编队系数的边际效应：
  单编→双编：系数+1（+20%），HP×2（+100%）→ 防御收益大于攻击收益
  双编→三编：系数+1（+17%），HP×1.5（+50%）→ 攻防均衡

设计意图：
  单编 = 灵活、便宜、适合侦察/迂回/地形受限区域
  双编 = 标准作战编组，性价比最高
  三编 = 决战编组，最强但最贵、占用空间大
```

### 7.3 编队切换

```
战斗中编队切换规则：
  ❌ 战斗中不可切换编队规模
  → 编队规模在战前准备阶段确定，战斗中固定不变
  
  理由：
    ① 简化战斗操作（避免频繁切换增加复杂度）
    ② 编队规模影响HP/伤害/补给消耗，战斗中切换会导致数值混乱
    ③ 符合历史——编队规模是战前部署决策
    
  战斗间切换：
    ✅ 两场战斗之间可以调整编队规模
    → 消耗：调整需要1回合（大地图时间）+ 补给/资源消耗
    → 升级编队（单→双→三）：需要额外资源
    → 降级编队（三→双→单）：返还部分资源
```

### 7.4 编队对战斗的影响

| 影响维度 | 单编 | 双编 | 三编 |
|---------|:----:|:----:|:----:|
| 伤害公式中士气项 | ×5 | ×6 | ×7 |
| 承伤能力 | 最低 | 中等 | 最高 |
| 补给效率 | 最优(×0.8) | 标准(×1.0) | 最差(×1.3) |
| 地形适应性 | 最好（1格） | 好（1格） | 受限（2格连续） |
| ZOC覆盖 | 1格ZOC | 1格ZOC | 2格ZOC |
| 被包围难度 | 最容易被围 | 较容易 | 难（占2格） |
| 机动性 | 最灵活 | 标准 | 笨重 |
| 炮兵三编特殊 | — | — | 溅射范围+1格 |

### 7.5 编队规模与招募条件

| 编队规模 | 通用条件 | 额外条件 |
|---------|---------|---------|
| **单编** | 对应兵种招募建筑+基础资源 | 无 |
| **双编** | 兵营Lv1+（炮兵需工坊Lv1+） | 资源=单编×2，训练值达标 |
| **三编** | 兵营Lv2+（炮兵需工坊Lv2+） | 资源=单编×3，将领军衔≥少校 |

### 8.2 战争迷雾

```
战争迷雾规则：
  ① 未被任何己方单位视野覆盖的格子 → 被迷雾覆盖
  ② 迷雾中的单位：
     - 不可见（不显示在战场上）
     - 不可被攻击
     - 不可查看属性
  ③ 曾经被视野覆盖但当前不在视野内的格子 → "暗幕"状态
     - 显示地形（地形信息保留）
     - 不显示敌方单位（单位可能已移动）
     - 显示最后一次被观测到的敌方单位位置（灰色标记）
  ④ 当前在视野内的格子 → 完全可见
     - 显示所有信息（单位、属性、地形等）
```

### 8.3 隐蔽机制

```
隐蔽规则：
  某些地形和单位可以获得"隐蔽"状态：
  
  隐蔽地形条件：
    - 森林中的步兵单位：自动获得隐蔽
    - 山丘反斜面（相对于敌方观测者）：自动隐蔽
    - 夜间所有单位：视野外自动隐蔽
    
  隐蔽效果：
    - 隐蔽单位不会被敌方视野发现
    - 只有敌方单位进入隐蔽单位相邻2格时才能被发现
    - 隐蔽单位发动攻击时立即暴露（失去隐蔽）
    - 隐蔽单位攻击时获得伏击加成（攻击力+30%）
    
  反隐蔽：
    - 轻骑兵"侦察"被动：移动后视野+2格，可发现隐蔽单位
    - 技能"鹰眼"：视野+2格，发现隐蔽单位概率+30%
    - 技能"夜哨"：夜间视野不降低
    - 炮兵开火时的炮口闪光：照亮周围3格，持续1回合
```

### 8.4 侦察单位特性

```
侦察单位定义：专门用于探索视野、发现敌情的单位。

最佳侦察单位：
  ① 轻骑兵：移动力5 + 移动后视野+2 = 最强侦察兵
  ② 骠骑兵：移动力6 + 基础视野6 = 次强侦察兵
  ③ 精锐轻步兵：移动力4 + 森林不降视野 = 森林侦察专家
  
侦察策略：
  - 开局用轻骑兵快速探索地图
  - 侦察兵避免与敌军交战（HP低，战斗力弱）
  - 侦察兵发现敌军后，其他部队再跟进
  - 夜间侦察风险大（视野仅2-4格，容易遭伏击）
```

### 8.5 视野争夺

```
视野争夺是战斗前期的重要博弈：

先手侦察优势：
  - 先手方有更多时间部署侦察兵
  - 轻骑兵首回合可以深入敌方区域
  
信息差价值：
  - 知道敌方部署 → 可以针对性布阵
  - 不知道敌方部署 → 只能保守展开
  
视野控制策略：
  - 用轻骑兵控制侧翼视野
  - 用炮兵火力封锁关键通道（迫使敌方暴露）
  - 利用地形（山地/森林）建立观察哨
  - 夜间减少侦察（风险大），白天全力推进侦察
```

## 九、战斗结算

### 9.1 胜利条件

| 胜利类型 | 条件 | 典型关卡 |
|---------|------|---------|
| **歼灭战** | 消灭所有敌方作战单位 | 常规战斗、遭遇战 |
| **占领战** | 占领指定目标格（城市/据点）并坚守1回合 | 攻城战、据点争夺 |
| **坚守战** | 防守指定区域N回合不被占领 | 防守关卡 |
| **击败将领** | 击杀或击退敌方将领单位 | Boss关卡 |
| **护送战** | 将指定单位安全护送到目标格 | 护送关卡 |
| **回合存活** | 在敌方进攻下存活到指定回合数 | 突围/等待援军 |
| **得分战** | 在限定回合内累积最高击杀分数 | 期末考试 |

> 每个关卡可以组合多个胜利条件（如"歼灭所有敌军+占领城市"需同时满足）。

### 9.2 失败条件

| 失败类型 | 条件 | 说明 |
|---------|------|------|
| **全灭** | 己方所有作战单位被消灭 | 最直接的失败 |
| **将领阵亡** | 主角/指定必保将领阵亡 | 关键角色死亡=任务失败 |
| **失守** | 防守目标被敌方占领超过1回合 | 防守关卡特有 |
| **超时** | 超过回合限制且未达成胜利条件 | 视难度有惩罚或即败 |
| **溃败** | 己方≥60%的编队溃退 | 全军崩溃 |

### 9.3 平局条件

```
平局触发条件（满足任一）：
  ① 回合限制到达，双方均未达成胜利/失败条件
  ② 双方同时满足失败条件（极罕见）
  ③ 双方同意停战（特殊剧情关卡）
  
平局后果：
  - 战斗评价最高为B
  - 经验值×0.7
  - 不触发胜利专属剧情
  - 大地图上双方维持战前态势
```

### 9.4 战斗评价

| 评价 | 条件 | 奖励倍率 | 说明 |
|:----:|------|:-------:|------|
| **S** | 胜利 + 回合数≤限制×70% + 己方零阵亡 + 无编队溃退 | ×2.0 | 完美通关 |
| **A** | 胜利 + 回合数≤限制×90% + 己方阵亡≤20% | ×1.5 | 优秀通关 |
| **B** | 胜利 + 达成基本条件 | ×1.0 | 标准通关 |
| **C** | 胜利但超时/惨重损失/勉强达成 | ×0.7 | 惨胜 |

**评价计算公式**：

```python
def calc_battle_rating(battle_result):
    """计算战斗评价"""
    if not battle_result.is_victory:
        return None  # 失败无评价
    
    score = 100  # 基础分
    
    # 回合效率（30分权重）
    turn_ratio = battle_result.turns_used / battle_result.turn_limit
    if turn_ratio <= 0.7:
        score += 0  # 满分
    elif turn_ratio <= 0.9:
        score -= 10
    elif turn_ratio <= 1.0:
        score -= 20
    else:
        score -= 30  # 超时
    
    # 伤亡控制（40分权重）
    loss_ratio = battle_result.units_lost / battle_result.total_units
    if loss_ratio == 0:
        score += 0  # 满分
    elif loss_ratio <= 0.1:
        score -= 5
    elif loss_ratio <= 0.2:
        score -= 15
    elif loss_ratio <= 0.4:
        score -= 25
    else:
        score -= 40
    
    # 特殊加分
    if battle_result.general_killed:
        score += 10  # 击杀敌方将领
    if battle_result.city_captured_quickly:
        score += 5   # 快速占领
    
    # 特殊扣分
    if battle_result.any_unit_routed:
        score -= 10  # 有编队溃退
    if battle_result.friendly_fire > 3:
        score -= 5   # 友军误伤过多
    
    # 评价判定
    if score >= 90:
        return 'S'
    elif score >= 70:
        return 'A'
    elif score >= 50:
        return 'B'
    else:
        return 'C'
```

### 9.5 经验值分配

```
战斗经验值分配规则：

总经验池 = 基础经验 × 难度倍率 × 评价倍率

基础经验 = 10 × 敌方编队数 + 5 × 敌方平均等级 × 敌方编队数
难度倍率：休闲×0.5，普通×1.0，困难×1.5，噩梦×2.0
评价倍率：S×2.0，A×1.5，B×1.0，C×0.7

经验分配给各编队：
  每个参与战斗的己方编队获得等份经验
  
  单编队经验 = 总经验池 / 参战编队数
  
  额外奖励：
    击杀敌方编队的编队：额外+30%经验
    造成伤害最多的编队：额外+20%经验
    承受伤害最多的编队：额外+10%经验

经验分配给学科：
  步兵编队 → 步兵适性学科获得经验
  骑兵编队 → 骑兵适性学科获得经验
  炮兵编队 → 炮兵适性学科获得经验
  所有编队 → 训练学科获得少量经验（指挥经验）
  后勤相关战斗（补给线维护） → 后勤学科获得经验
  管理相关战斗（多编队协同） → 管理学科获得经验
  
  学科经验 = 编队经验 × 0.3
```

### 9.7 角色伤亡处理

```
角色伤亡判定：

当编队被消灭时，该编队附着的将领进入伤亡判定：

将领状态判定：
  random(0, 100) 根据以下概率判定：
  
  | 将领状态 | 概率 | 后果 |
  |---------|:----:|------|
  | 生还（轻伤） | 60% | 休息N场战斗后恢复，属性不降 |
  | 生还（重伤） | 20% | 休息N×2场战斗，某项属性临时-1 |
  | 被俘 | 10% | 需要救援任务或外交交换 |
  | 阵亡 | 10% | 永久死亡，从游戏中移除 |

修正：
  禁军/近卫军编队：将领生还概率+15%（精锐护卫）
  将领HP<30%时编队被灭：阵亡概率+20%
  友军邻近（3格内≥1支友军）：被俘概率-5%，生还+5%
  骑兵将领：生还概率+10%（可以快速逃离）
  铁人模式：阵亡概率+30%（永久死亡更常见）

受伤恢复时间：
  轻伤：恢复时间 = 2 + 伤势等级 场战斗
  重伤：恢复时间 = 4 + 伤势等级×2 场战斗
  
  将领在恢复期间：
    - 不可出战
    - 好感度自然增长暂停
    - 学科经验获取暂停
```

## 十、特殊战斗类型

### 10.1 攻城战

#### 攻城战概述

攻城战是最复杂的战斗类型，涉及城墙、城门、攻城器械等多层机制。

#### 城防设施

| 设施 | HP | 防御效果 | 破坏条件 |
|------|:--:|---------|---------|
| **城墙（小城市）** | 200 | 防御方全员减伤+20%，攻方不能直接进入 | 围城炮攻击3-5次 |
| **城墙（大城市）** | 400 | 防御方全员减伤+25%，攻方不能直接进入 | 围城炮攻击6-10次 |
| **城门** | 150/250 | 攻方近战单位可通过城门格进入 | 围城炮/重骑兵攻击 |
| **街垒** | 80 | 城市内防线，减伤+10% | 任意攻击 |
| **箭塔** | 100 | 每回合对攻方最近单位进行一次自由射击（30%伤害） | 炮兵攻击 |

#### 攻城方特殊规则

```
攻城方规则：
  ① 攻方从城市外围部署，必须先破墙/破门
  ② 破墙后，城墙格变为可通过（但移动消耗+2）
  ③ 城门被破坏后，近战单位可通过城门格
  ④ 攻方可以使用"云梯"（消耗1回合搭建）：
     - 云梯允许步兵直接攀墙（移动消耗=3）
     - 云梯被守方攻击时有50%概率被推倒
  ⑤ 攻方可以使用"攻城锤"（如果有）：
     - 对城门伤害+100%
     - 攻城锤移动力1，HP200
```

#### 攻城战胜利条件

```
攻方胜利：占领城市中心格（通常为城市最内部的格子）
守方胜利：坚守N回合（由关卡设定，通常10-20回合）
或：攻方全灭
```

### 10.2 伏击战

#### 伏击战规则

```
伏击方优势：
  ① 伏击方先手（第一回合完全行动）
  ② 伏击方首回合所有攻击伤害+30%（突袭加成）
  ③ 被伏击方首回合所有单位士气-15
  ④ 被伏击方首回合无法移动（只能防御/反击）
  ⑤ 伏击方隐蔽单位首回合攻击无视ZOC
  
伏击发动条件：
  - 伏击方必须在战前处于隐蔽状态（森林/山地/迷雾中）
  - 被伏击方进入伏击区域（关卡设定的触发范围）
  - 伏击方≥50%的编队处于隐蔽状态
  
被发现概率（伏击失败）：
  基础发现率 = 30%
  被伏击方有轻骑兵：+20%
  被伏击方将领有"警觉"技能：+15%
  伏击方在雾天：-15%
  伏击方在夜间：-10%
  被伏击方侦察到伏击方（视野覆盖伏击区域）：+30%
  
  发现概率≥70% → 伏击失败，变为遭遇战
  发现概率<70% → 伏击成功
```

### 10.3 遭遇战

```
遭遇战规则：
  ① 双方同时部署（不分攻守）
  ② 先手权随机（50%概率）
  ③ 双方初始士气均为60（无伏击加成/惩罚）
  ④ 部署区域由关卡配置（通常各占一侧）
  ⑤ 遭遇战通常规模较小（3-8个编队）
  
遭遇战触发场景：
  - 大地图上行军时遭遇敌军
  - 侦察时遭遇敌方巡逻队
  - 剧情触发的突发战斗
```

### 10.4 防守战

```
防守战规则：
  ① 防守方先手
  ② 防守方预先部署在指定区域内
  ③ 防守方初始士气+10（阵地优势）
  ④ 防守方在有防御加成的地形上额外+5%减伤
  ⑤ 攻方分波次增援（不是一次性全部出现）
  
防守方特殊指令：
  - "预设阵地"：战斗开始前，防守方可以选择在哪些格子上建造临时工事（栅栏/掩体）
  - 预设工事数量 = 防守方编队数
  
防守战胜利条件：
  - 坚守N回合不被敌方占领目标格
  - 或歼灭所有敌方增援
```

### 10.5 夜战

```
夜战规则（详见天气系统13文档，此处汇总）：
  ① 时段为夜晚，视野大幅降低（基础2格）
  ② 远程攻击精度-20%
  ③ 移动力-1
  ④ 攻击力-10%
  ⑤ 防御力+5%（伏击方+15%）
  ⑥ 每回合士气-2
  ⑦ 燧发枪哑火率+5%
  ⑧ 可发动夜袭
  ⑨ 友军误伤率8%（远程）
  ⑩ 混乱概率增加（详见天气系统）
```

### 10.6 其他特殊战斗类型

#### 模拟战/考试

```
模拟战规则（军校关卡特有）：
  ① 不会造成真实伤亡（角色不会阵亡）
  ② 失败不影响剧情（只影响评价和经验值）
  ③ 通常有特殊规则（如限用某兵种、限制回合数等）
  ④ 评价影响学科经验值
```

#### 多关连续战

```
连续战规则（毕业演习等）：
  ① 连续进行2-4场战斗，中间只有短暂准备时间
  ② 编队HP/士气在战斗间保留（不自动恢复）
  ③ 补给值保留
  ④ 中间准备阶段可以选择：
     - 简短休整（士气+10，HP恢复20%）
     - 调整部署（更换将领/调整编队）
     - 不设休整直接开始下一场
  ⑤ 最终评价 = 各场评价的加权平均
```

## 十一、将领系统

### 11.1 将领在战斗中的作用

```
将领是编队的核心——每个编队必须有一位将领指挥。

将领的作用：
  ① 属性加成：将领军衔/学科/技能影响编队战斗力
  ② 士气影响：将领军衔提供士气光环
  ③ 技能提供：将领携带4个被动技能
  ④ AI指挥：将领的角色类型影响AI行为（勇将/智将/防守/激进/保守）
  ⑤ 好感度互动：战场上与好感度相关的特殊行为
  ⑥ 存亡影响：将领阵亡会导致编队士气崩溃
```

### 11.2 将领属性对战斗的影响

### 11.4 将领成长

```
将领成长途径：
  ① 军衔晋升：战斗经验累积 → 军衔提升 → 解锁更多技能槽/士气光环范围
  ② 学科修炼：养成阶段学习 → 学科星级提升 → 对应兵种加成提升
  ③ 技能解锁：达成特定条件 → 解锁新被动技能 → Build丰富化
  ④ 好感度提升：与特定角色互动 → 好感度达标 → 解锁专属被动/剧情技能
  
将领成长速度：
  军衔经验 = 战斗经验 × 0.5
  每场战斗后，所有参战将领获得军衔经验
  
  军衔升级所需经验：
    士→少尉：50
    少尉→中尉：100
    中尉→上尉：250
    上尉→少校：500
    少校→中校：800
    中校→上校：1200
    上校→少将：2000
    少将→中将：3000
    中将→上将：5000
    上将→元帅：8000
```

### 11.5 将领伤亡

```
将领伤亡规则（详见9.7角色伤亡处理）：

关键规则汇总：
  - 主角阵亡 = 任务失败（非铁人模式下可重试）
  - NPC将领阵亡 = 永久死亡（从可用角色列表中移除）
  - 铁人模式下：所有角色永久死亡
  - 非铁人模式：可消耗资源/时间"复活"（解释为之前是重伤昏迷）
  
将领受伤对编队的影响：
  - 将领轻伤：编队士气-5，将领属性不降
  - 将领重伤：编队士气-15，将领某项属性临时-1（恢复后恢复）
  - 将领被俘：编队士气-25，需要救援
  - 将领阵亡：编队士气崩溃（进入崩溃状态），编队战斗力大幅下降
```

## 十三、战斗AI设计

### 13.1 AI决策流程

详细AI决策逻辑参见03_AI设计文档，此处汇总核心流程：

```
每回合每个AI单位执行决策：

  [优先级1] 生存危机检测
  ├── 被包围 → 突围/投降
  ├── HP≤阈值 → 撤退
  └── 士气崩溃 → 溃退
  
  [优先级2] 命令遵从
  ├── 有上级指令 → 执行命令
  └── 无指令 → 继续
  
  [优先级3] 好感度驱动
  ├── 死敌在攻击范围 → 追击
  ├── 挚友被攻击 → 保护
  └── 无触发 → 继续
  
  [优先级4] 常规作战
  ├── 有可击杀目标 → 收割
  ├── 有攻击目标 → 选择最优目标（TVS评分）
  ├── 无目标 → 移动决策（PVS评分）
  └── 无法行动 → 待机/防御
  
  [优先级5] 后处理
  ├── 击杀 → 追击判定
  ├── 受伤 → 重新评估
  └── 回合结束 → 更新威胁表
```

### 13.2 AI优先级

```
目标选择优先级（TVS, Target Value Score）：

TVS = 基础分(100) × 角色类型修正 × 好感度修正 × 地形修正 × 状态修正

各修正项详见03_AI设计文档。

AI选择TVS最高的目标。
多个目标TVS差距≤10%时，选择距离最近者。
```

### 13.3 AI对不同兵种的使用策略

| AI兵种 | AI使用策略 | 优先级 |
|--------|-----------|--------|
| **步兵** | 组成战线，互相支援，利用地形防御 | 扛线/防守 |
| **来复枪兵** | 保持距离射击，避免近战 | 远程输出 |
| **近卫军/禁军** | 前排坚守，保护将领和炮兵 | 核心前排 |
| **轻骑兵** | 侦察侧翼，追击溃兵，突袭炮兵 | 骚扰/追击 |
| **重骑兵** | 等待步兵打开缺口，侧翼冲击 | 突破/收割 |
| **骠骑兵** | 高速迂回，打击敌方后排 | 迂回/斩首 |
| **轻火炮** | 跟随步兵推进，提供火力支援 | 机动火力 |
| **重火炮/加农炮** | 部署在后方高地，远程轰击 | 远程压制 |
| **榴弹炮** | 射击密集区域，面杀伤 | 面杀伤 |
| **围城炮** | 优先攻击城墙/城防设施 | 攻城 |

### 13.4 AI难度差异化

| AI维度 | 休闲 | 普通 | 困难 | 噩梦 |
|--------|:----:|:----:|:----:|:----:|
| 目标选择 | 随机/30%选最酷目标 | 按角色类型最优 | 最优+预判1回合 | 全局最优+预判2回合 |
| 移动效率 | 30%走错方向 | 正常10%次优 | 最优路径 | 完美路径+协同 |
| 集火协同 | 无协同 | 2人集火50% | 3-4人集火 | 全军精确协同 |
| 撤退判断 | 永不撤退 | 按角色类型 | 提前1回合 | 完美时机 |
| 资源管理 | 不补给 | 基础补给 | 主动补给+轮换 | 精确分配 |
| 情报获取 | 仅视野内 | 同休闲 | 推断隐藏位置 | 完全情报 |
| 决策错误率 | 20% | 10% | 3% | 0% |

### 13.5 AI作弊机制（高难度）

```
困难模式AI特殊能力：
  ① 可推断隐藏单位大致位置（基于上回合侦察）
  ② 主动保护高好感友军
  ③ 利用好感差设伏
  
噩梦模式AI特殊能力：
  ① 完全情报（等同玩家视野），知道所有精确属性
  ② 利用好感系统诱敌深入
  ③ 操纵叛徒型AI时机
  ④ 精确计算所需伤害，不浪费输出
  ⑤ 敌方属性加成：攻击+10%，HP+15%，士气+10，移动+1，命中+10%

作弊限制（公平性保障）：
  ❌ AI不会"穿墙"——必须遵循移动规则
  ❌ AI不会"透视"——休闲/普通模式仍受视野限制
  ❌ AI不会无限增援——增援由关卡配置决定
  ✅ AI可以获得"情报优势"——高难度下的信息不对称
  ✅ AI可以获得"属性加成"——数值层面的挑战提升
```
