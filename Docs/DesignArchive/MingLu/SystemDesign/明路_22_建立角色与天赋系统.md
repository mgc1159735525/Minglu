# 第一章：建立角色界面流程

---

## 1.1 总体设计理念

角色创建是玩家与《明路》世界的第一次深度交互。它不能是一组干巴巴的数值选择——它必须是一段**叙事体验**，让玩家在"创造角色"的过程中自然地理解世界观、建立情感联系、做出第一个有意义的抉择。

**核心设计原则：**

| 原则 | 说明 |
|------|------|
| **叙事包装** | 每一步选择都嵌入剧情片段，玩家不是在"选属性"而是在"经历人生" |
| **代价真实** | 每个选择都有明确收益和明确牺牲，不存在"最优解" |
| **预览透明** | 选择后立刻展示影响，让玩家知情决策 |
| **快速可跳** | 提供"随机生成"和"跳过剧情"选项，尊重老玩家 |
| **重玩差异** | 不同创建路径在序章就产生可感知的剧情分支 |

### 叙事内容

开场序幕为5段水墨动画旁白，每段5-8秒，依次展示：
1. 郑和船队东渡的想象画面
2. 郑氏在美洲建立王朝的概览
3. 1760年的世界格局（郑明/西班牙/英国/法国/印第安部落）
4. 主角家族简介（伯爵之家，父亲被软禁的前兆暗示）
5. 新京军事学院远景——"你的故事从这里开始"

**关键接口：** 第5段旁白末尾出现一个选择——"你望向学院大门时，心中涌起的是……"
- A.「光复之志」→ 民族轴-3，返乡团初始好感+5
- B.「求学报国」→ 训练学科经验+10
- C.「证明自己」→ 管理学科经验+10
- D.「迷茫不安」→ 初始心情+8，解锁"东渡密档"线索碎片×1

这个选择极轻微（仅影响初始值），但奠定了叙事基调。

### 选择范围与规则

| 项目 | 规则 | 默认值 | 说明 |
|------|------|--------|------|
| 姓 | 百家姓 + 5个稀有姓（含印第安音译姓） | 郑 | 主角固定姓"郑"，此为可选是否改为母姓 |
| 名 | 自由输入（2-3字），字库限制中文 | 随机生成 | 系统提供随机名字生成器 |
| 字 | 自由输入（2字），可选填 | 空 | 字在正式场合和结局中出现 |
| 眉目 | 4选1 | 英挺 | 纯视觉 |
| 肤色 | 4选1 | 小麦 | 选"深褐"时，印第安乡党初始好感+3 |
| 体态 | 4选1 | 匀称 | 纯视觉 |
| 发式 | 4选1 | 束冠 | 选"编发"时，印第安乡党初始好感+3 |

**数值影响极小：** 此步骤几乎不影响数值，仅有肤色/发式的印第安亲和力修正（总计最多+6好感），目的是让玩家自由表达角色形象。

**特殊彩蛋：** 若玩家输入姓名为"郑和"，系统弹出提示：「这是太祖皇帝的名讳，你确定要僭越吗？」——选择"是"则民族轴-5，选择"否"则返回修改。

### 3组情景题详述

### 性格特质系统

3组选择结束后，玩家获得一个**核心特质**标签。核心特质由选择组合决定：

| 特质 | 获取条件 | 效果 |
|------|----------|------|
| 审慎 | 往事选A ≥ 2 | 战斗开始时视野+1格 |
| 仁厚 | 往事选B ≥ 2 | 初始全派系好感+3 |
| 果决 | 往事1A + 往事2A | 首回合全军移动力+1 |
| 善感 | 往事1B + 往事3B | 心情下限+10，好感度获取+2% |
| 隐忍 | 往事3A + 任意A | 东渡密档线索获取速度+1 |
| 激进 | 往事2B + 往事3B | 立场轴变动幅度×1.15 |

核心特质是主角的第一个永久增益，不可更改，不可被移除。

### 天赋选择规则

| 规则 | 说明 |
|------|------|
| 出身天赋池 | 每个出身提供4个候选天赋，玩家从中选1个 |

## 2.1 设计原则

6个出身背景必须满足：
1. **与5大派系深度绑定**：每个出身至少与2个派系有显著关系

# 第三章：主角天赋系统

## 3.1 系统定位

### 主角天赋 vs NPC天赋的关系

| 维度 | NPC天赋（天赋槽） | 主角天赋系统 |
|------|-------------------|-------------|
| 数量 | 每角色1个固定天赋 | 主角最多持有8个天赋（含初始2个） |
| 获取 | 角色自带，不可更换 | 初始选2个，后续通过成长/觉醒解锁 |
| 定位 | 角色标识，差异化设计 | 玩家成长路径，Build构筑核心 |
| 叠加 | 天赋槽独占，不与通用技能冲突 | 与NPC天赋完全独立，不冲突 |
| 战斗表现 | NPC被派遣时生效 | 主角亲自上阵时生效 |

**核心区别：** NPC天赋是"他是谁"，主角天赋是"你成为了谁"。NPC天赋是固定的身份标识，主角天赋是可成长的Build路径。

## 3.2 天赋分类体系

主角天赋分为**5大类**，对应5种战斗/叙事风格：

| 类别 | 核心影响 | 关键词 | 天赋数量 | 对应学科 |
|------|----------|--------|----------|----------|
| **武勇类** | 攻击伤害/近战/突破 | 破阵/斩将/突击 | 10个 | 步兵适性/骑兵适性 |
| **谋略类** | 情报/视野/计策 | 洞察/暗算/先手 | 10个 | 管理/训练 |
| **统率类** | 光环/士气/指挥 | 号令/激励/同袍 | 10个 | 管理/训练 |
| **坚韧类** | 防御/生存/士气抵抗 | 铁壁/不屈/苦行 | 10个 | 后勤/训练 |
| **通达类** | 外交/情报/跨文化 | 通译/商路/斡旋 | 10个 | 管理/后勤 |

**总计50个天赋。**

## 3.3 天赋分层

每个天赋分为3层，形成"天赋成长路径"：

| 层级 | 名称 | 效果强度 | 获取方式 | 数量 |
|------|------|----------|----------|------|
| T1 | 初始天赋 | 基础效果（5%-12%） | 角色创建时选择 | 每类4个可选 |
| T2 | 成长天赋 | 中等效果（12%-25%） | 学科达标/战斗积累/好感度解锁 | 每类3个 |
| T3 | 觉醒天赋 | 强力效果（25%+）或机制改变 | 特定条件触发"觉醒事件" | 每类3个 |

**天赋点系统：**

| 阶段 | 可持有天赋上限 | 累计天赋点数 |
|------|---------------|-------------|
| 创建完成 | 2 | 2 |
| 一年级末（第52周） | 3 | +1 = 3 |
| 二年级末（第104周） | 5 | +2 = 5 |
| 毕业时（第156周） | 6 | +1 = 6 |
| 内战阶段 | 8 | +2 = 8 |

**天赋点获取途径：**
- 军衔晋升：每晋升一个大阶（士→少尉→中尉→…），获得1天赋点
- 学科达标：任一学科达到3星/4星/5星时，各获得1天赋点
- 觉醒事件：特定剧情节点触发（与好感度、立场、密档相关）
- 总计可获取天赋点约12-15个，但上限8个——意味着玩家需要"取舍"

## 3.4 天赋获取机制

### 3.4.1 创建时

- 从出身天赋池中选1个（T1层）
- 性格特质自动解锁1个（T1层）
- 合计初始2个天赋

### 3.4.2 游戏中解锁

| 途径 | 条件示例 | 解锁类型 |
|------|----------|----------|
| 学科达标 | 步兵适性≥3星 | 解锁武勇类T2天赋候选 |
| 战斗积累 | 累计击杀100敌方编队 | 解锁武勇类T2天赋候选 |
| 好感度 | 与某NPC好感≥70 | 解锁该NPC关联的通达类天赋候选 |
| 立场偏移 | 民族轴达到±30 | 解锁对应立场天赋候选 |
| 觉醒事件 | 完成特定剧情 | 解锁T3觉醒天赋 |
| 派系认同 | 某派系3人好感≥50 | 解锁派系专属天赋候选 |

### 3.4.4 天赋树

天赋不设传统"天赋树"，而采用**天赋池+候选**机制：

```
┌───────────────────────────────────────────────┐
│              主角天赋池                         │
│                                                │
│  武勇类    谋略类    统率类    坚韧类    通达类 │
│  ┌────┐   ┌────┐   ┌────┐   ┌────┐   ┌────┐ │
│  │T1×2│   │T1×1│   │T1×1│   │T1×1│   │T1×1│ │
│  │T2×2│   │T2×2│   │T2×1│   │T2×1│   │T2×1│ │
│  │T3×1│   │T3×1│   │T3×1│   │T3×1│   │T3×1│ │
│  └────┘   └────┘   └────┘   └────┘   └────┘ │
│                                                │
│  已解锁 = 灰显可选  已装备 = 高亮  未解锁 = 锁 │
│                                                │
│  当前装备: [天赋1] [天赋2] ... [天赋N/8]       │
│  天赋点剩余: X                                 │
└───────────────────────────────────────────────┘
```

- 满足条件的天赋自动进入"候选池"
- 玩家从候选池中消耗天赋点装备
- 已装备的天赋可以卸下（退还天赋点），但不能换给NPC

## 3.5 天赋与现有技能系统的接口

### 3.5.1 与4个技能槽位的关系

| 槽位 | 与天赋的关系 | 说明 |
|------|-------------|------|
| 天赋槽（主角） | 主角天赋系统**替代**了主角的天赋槽 | NPC的天赋槽 = 固定1个天赋被动；主角的天赋槽 = 可成长的天赋系统（最多8个） |
| 学识槽 | 学识槽技能效果受天赋加成 | 若装备了"博学"类天赋，学识槽技能效果提升 |
| 经验槽 | 经验槽技能与天赋独立叠加 | 天赋走独立系统，不与经验槽冲突 |
| 指挥槽 | 统率类天赋可视为"增强版指挥" | 天赋中的光环效果与指挥槽光环叠加 |

### 3.5.2 叠加规则

| 组合 | 叠加方式 |
|------|----------|
| 主角天赋 + 主角天赋 | 同类效果取最高值（百分比类），固定值加算 |
| 主角天赋 + NPC天赋 | 完全叠加（独立来源） |
| 主角天赋 + 通用被动技能 | 完全叠加（独立系统） |
| 主角天赋 + 部队被动 | 完全叠加 |

### 3.5.3 与伤害公式的具体接口

## 6.6 天赋与现有119个被动技能的关系

### 6.6.1 独立性原则

主角天赋系统和NPC的119个被动技能（含84个通用被动+35个角色专属）**完全独立**：

| 维度 | 主角天赋 | NPC被动技能 |
|------|----------|------------|
| 载体 | 主角自身 | NPC将领 |
| 获取 | 创建选择+成长解锁 | 角色自带/好感度解锁 |
| 装备位置 | 独立天赋栏（最多8个） | 天赋槽（固定1个） |
| 是否可换 | 可卸下/重装 | 不可更换 |
| 叠加 | 与NPC被动完全叠加 | 与主角天赋完全叠加 |

### 6.6.2 不冲突的保证
