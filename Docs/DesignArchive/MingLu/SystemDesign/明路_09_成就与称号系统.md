# 明路 - 成就与称号系统

> 独立于结局成就（E1-E11）之外的全局成就体系

## 一、系统概述

### 1.1 设计理念

成就系统是《明路》的长期驱动力，激励玩家在多周目中探索不同玩法路线。成就分为**六大类**，每类对应不同的游戏维度，难度从铜到白金逐级递增。

### 1.2 成就难度分级

| 等级 | 图标 | 颜色 | 设计原则 |
|------|------|------|---------|
| 🥉 铜 | 铜盾 | #CD7F32 | 正常游玩即可获得，引导玩家接触系统 |
| 🥈 银 | 银盾 | #C0C0C0 | 需要一定规划或技巧，约30%玩家能获得 |
| 金 | 金盾 | #FFD700 | 需要刻意追求或极致操作，约10%玩家能获得 |
| 💎 白金 | 钻石 | #B9F2FF | 极限挑战/极端条件，约1%玩家能获得 |

### 1.3 成就奖励类型

| 奖励类型 | 说明 |
|---------|------|
| 称号 | 显示在角色名旁，装备后提供微小加成 |
| 技能点 | 可用于六学科经验值加成 |
| 战场加成 | 永久微调（如士气+1、攻击+1%等） |
| 物品 | 特殊装备/道具 |
| 成就点数 | 累计解锁里程碑奖励 |
