# 明路 - 战场AI设计

## 一、AI决策框架

### 1.1 决策优先级树（每回合每个AI单位执行一次）

AI的决策采用**自上而下的优先级树**结构，每个回合按优先级从高到低依次判断，命中即执行，不再检查后续节点。

```
优先级1：生存危机检测
├── 被包围（相邻3格以上有敌军）→ 执行【突围/投降判定】
├── 血量≤15% 且 无友军相邻 → 执行【强制撤退】
└── 士气崩溃（士气≤10）→ 执行【溃退】

优先级2：命令遵从检测
├── 存在上级指令（玩家/友军AI上级下达的战略目标）→ 进入【命令执行子树】
└── 无上级指令 → 继续

优先级3：好感度驱动的特殊行为
├── 死敌在攻击范围内 → 执行【追击死敌】（无视其他目标选择）
├── 莫逆之交在3格内且被攻击 → 执行【保护挚友】（移动到可反击敌军的位置）
├── 己方将领在2格内且受威胁 → 执行【护驾】（仅防守型/保守型）
└── 无特殊好感触发 → 继续

优先级4：常规作战决策
├── 攻击范围内有可击杀目标 → 执行【收割】（选择价值最高的目标）
├── 攻击范围内有目标 → 执行【目标选择】（按角色类型的优先级选目标）
├── 攻击范围内无目标 → 执行【移动决策】
└── 无法移动也无可攻击目标 → 执行【待机/防御姿态】

优先级5：战斗结算后处理
├── 击杀敌人 → 检查是否触发【乘胜追击】
├── 被反击受伤 → 重新评估【生存危机】
└── 回合结束 → 更新威胁评估表
```

### 1.2 目标选择逻辑

AI选择攻击目标时，对范围内每个可选目标计算**目标价值分（TVS, Target Value Score）**：

```
TVS = 基础分 × 角色类型修正 × 好感度修正 × 地形修正 × 状态修正

基础分 = 100

角色类型修正：
  勇将型：对低血量目标 +50%，对高血量目标 -20%
  智将型：对高威胁目标 +40%，对低威胁目标 -10%
  防守型：对近身目标 +30%，对远程目标 -20%
  激进型：对将领单位 +80%，对普通单位 -30%
  保守型：对近身己方单位的威胁源 +20%，其他 -10%

好感度修正：
  死敌（-91~-100）：+100%
  仇视（-71~-90）：+60%
  敌对（-31~-70）：+30%
  莫逆之交（敌方，90~100）：-80%（留手）
  亲密（敌方，75~89）：-50%（留手）
  朋友（敌方，50~74）：-20%（留手）

地形修正：
  目标在有利地形（山地/掩体/壕沟）：-20%（不想硬啃）
  目标在不利地形（平原无掩护）：+15%

状态修正：
  目标血量≤30%：+40%（收割优先）
  目标士气低落：+20%
  目标已被其他友军攻击：+25%（集火）
  目标刚击杀己方单位：+60%（复仇）
```

最终选择TVS最高的目标作为攻击对象。若多个目标TVS差距≤10%，则选择距离最近者。

### 1.3 移动逻辑

移动决策采用**格点评分制**，对每个可到达的六边形格子计算**位置价值分（PVS, Position Value Score）**：

```
PVS = 威胁规避分 + 攻击机会分 + 地形价值分 + 编队协同分 + 命令偏移分

威胁规避分（权重按角色类型调整）：
  基础分 = 0
  每有1个敌军在攻击范围内：-15
  每有1个敌军在移动范围内：-5
  每有1个友军在相邻格：+8
  保守型/防守型：威胁规避权重×1.5
  激进型/勇将型：威胁规避权重×0.6

攻击机会分：
  移动后攻击范围内有敌军数量 × 12
  其中可击杀目标额外 × 20
  勇将型/激进型：攻击机会权重×1.4
  防守型：攻击机会权重×0.7

地形价值分：
  参照地形抗性表：
    有防御加成的地形（山地/掩体/壕沟/栅栏）：+20
    城市地形：+10（有掩体效果）
    平原：+0
    沿河（移动消耗高）：-10
  炮兵特殊：偏好高地/+15，厌恶森林/-20
  骑兵特殊：偏好平原/+10，厌恶山地/-30，厌恶森林/-25
  步兵特殊：所有地形中性，森林+5

编队协同分：
  移动后与同编队友军相邻：+15
  移动后能形成夹击（2个以上友军可攻击同一目标）：+25
  移动后孤立无援（3格内无友军）：-20

命令偏移分（当存在上级指令时）：
  移动后更接近指令目标区域：+30
  移动后远离指令目标区域：-25
  保守型/防守型：命令偏移权重×1.3
  激进型：命令偏移权重×0.5
```

### 1.4 撤退逻辑

撤退不是简单的"逃跑"，而是一个包含判断、路线规划和条件触发的完整子系统。

**撤退触发条件（满足任一即触发评估）：**
```
条件A：单位血量 ≤ 阈值（按角色类型不同）
  勇将型：≤ 10%
  智将型：≤ 20%
  防守型：≤ 25%
  激进型：≤ 15%
  保守型：≤ 30%

条件B：周围威胁度过高
  威胁度 = 攻击范围内敌军总战力 / 自身战力
  勇将型/激进型：威胁度 ≥ 3.0 触发
  智将型：威胁度 ≥ 2.0 触发
  防守型/保守型：威胁度 ≥ 1.5 触发

条件C：战略目标已失败
  防守目标点已被占领
  保护目标已死亡
  友军全灭且自身孤立
```

**撤退路线选择：**
```
撤退路线评分 = 安全分 + 接近友军分 + 地形防御分

安全分：
  每远离最近敌军1格：+10
  路线上无敌军控制区域：+20

接近友军分：
  移动后更接近己方将领：+15
  移动后更接近友军主力：+10

地形防御分：
  撤退目的地有防御地形：+15

特殊规则：
  勇将型：除非满足条件A且血量≤5%，否则不撤退
  激进型：永不主动撤退（除非血量≤5%或全军覆没）
  智将型：撤退时会优先选择能反击的位置
```

**连锁撤退：** 当一支部队撤退时，相邻格友军士气检定（士气-10），若检定失败则触发连锁撤退。将领单位撤退时，周围5格内友军士气-15。

## 二、AI角色类型

### 2.1 勇将型

**代表角色**：张猛、冯铁山、王铁柱、阿黑·雷鸟

**核心特征**：冲锋在前，以战养战，越战越勇

**决策权重修正：**
| 决策维度 | 权重修正 |
|---------|---------|
| 威胁规避 | ×0.6 |
| 攻击机会 | ×1.4 |
| 撤退倾向 | ×0.3 |
| 集火协同 | ×0.8 |
| 追击倾向 | ×1.5 |

**目标选择偏好（优先级从高到低）：**
1. 血量≤30%的任意敌军（收割机会）
2. 血量最低的敌军单位
3. 无防御地形加成的敌军
4. 等级低于自身的敌军
5. 距离最近的敌军

**特殊行为规则：**
- **越战越勇**：每击杀一个单位，本回合剩余移动力+1（鼓励连续作战）
- **藐视弱者**：对等级≤自身等级-2的目标，攻击伤害+10%
- **拒绝撤退**：除非血量≤5%或被包围，否则不触发撤退判定
- **挑衅**：若回合内未找到目标，向最近敌军方向移动最大距离

**弱点**：容易孤军深入，被集火围歼；不善保护将领侧翼

### 2.2 智将型

**代表角色**：沈沧海、杨守边、灰鹰·草灵、陆启明

**核心特征**：统筹全局，精准打击，善用技能

**决策权重修正：**
| 决策维度 | 权重修正 |
|---------|---------|
| 威胁规避 | ×1.0 |
| 攻击机会 | ×1.2 |
| 撤退倾向 | ×1.0 |
| 集火协同 | ×1.5 |
| 技能使用 | ×2.0 |

**目标选择偏好（优先级从高到低）：**
1. 对己方威胁最大的敌军（TVS中"威胁度"权重最高）
2. 敌方将领（如果可击杀或可重创）
3. 敌方炮兵（高优先消除远程威胁）
4. 正在攻击己方薄弱单位的敌军（围魏救赵）
5. 已被友军攻击的目标（集火）

**特殊行为规则：**
- **精准计算**：能"看到"玩家隐藏信息（困难以上难度），如敌方精确血量、技能冷却
- **技能优先**：当技能可以造成比普攻多30%以上伤害时，优先使用技能
- **战场调度**：若自身不在攻击范围内，会移动到能为最多友军创造攻击机会的位置
- **弹性撤退**：撤退时选择可以下回合反击的位置，而非单纯远离
- **集火指挥**：若3格内有其他友军AI且目标相同，触发【协同攻击】（双方伤害+10%）

**弱点**：自身战斗力不突出；若被快速近身且无友军支援，容易陷入困境

### 2.3 防守型

**代表角色**：魏连长、铜皮·双血、蒋军法、石·地灵

**核心特征**：稳如磐石，寸土必争，保护同袍

**决策权重修正：**
| 决策维度 | 权重修正 |
|---------|---------|
| 威胁规避 | ×1.5 |
| 攻击机会 | ×0.7 |
| 撤退倾向 | ×0.7 |
| 地形利用 | ×2.0 |
| 保护行为 | ×1.8 |

**目标选择偏好（优先级从高到低）：**
1. 正在攻击己方将领的敌军
2. 正在攻击相邻友军的敌军（反击解围）
3. 逼近己方防守位置的敌军
4. 进入己方有利地形的敌军（不让敌人占地）
5. 距离最近的敌军

**特殊行为规则：**
- **据守**：当处于有防御加成的地形时，不主动离开，除非目标进入攻击范围
- **盾墙**：若保护的将领/重要单位在2格内，移动到将领与最大威胁之间
- **不退**：防守型AI在防守任务点被攻占前，血量阈值提高到≤5%才撤退
- **地形大师**：在防守地形上，防御力额外+10%
- **掩护射击**：若无法攻击但友军正在撤退，对最近敌军执行"阻滞射击"（伤害-50%，但迫使敌军下回合移动力-1）

**弱点**：机动性差，不擅追击；若防守目标被绕过，效率大降

### 2.4 激进型

**代表角色**：刘炮生、张猛（部分场景）、独眼·鹰扬、王大胆

**核心特征**：斩首行动，不顾一切，直取敌将

**决策权重修正：**
| 决策维度 | 权重修正 |
|---------|---------|
| 威胁规避 | ×0.4 |
| 攻击机会 | ×1.6 |
| 撤退倾向 | ×0.2 |
| 追击敌将 | ×3.0 |
| 自损容忍 | ×2.5 |

**目标选择偏好（优先级从高到低）：**
1. 敌方将领（无论距离、无论地形）
2. 敌方将领护卫部队（清除障碍）
3. 距离敌方将领最近的位置（逼近）
4. 任何其他敌军（仅当完全无法接近敌将时）

**特殊行为规则：**
- **斩首冲锋**：即使攻击敌方将领会导致自身被反击致死，仍然执行攻击
- **无视杂兵**：对非将领单位的TVS额外-50%
- **不死不休**：对敌方将领的好感度修正无效（即使好感度高也全力攻击）
- **突破**：移动时如果路径上有敌军ZOC（控制区域），不退避而是强行通过（受到机会攻击但移动不中断）
- **士气打击**：成功攻击敌方将领后，全场敌军士气-5

**弱点**：极易阵亡；可能被敌方利用作为诱饵设伏；忽视战场其他威胁

### 2.5 保守型

**代表角色**：许医官、花·鹿灵、何清风、贾善贾

**核心特征**：保全实力，远离危险，辅助为主

**决策权重修正：**
| 决策维度 | 权重修正 |
|---------|---------|
| 威胁规避 | ×1.8 |
| 攻击机会 | ×0.5 |
| 撤退倾向 | ×1.5 |
| 保护将领 | ×2.0 |
| 治疗/辅助 | ×2.5 |

**目标选择偏好（优先级从高到低）：**
1. 攻击己方将领的敌军（仅当将领血量≤50%时）
2. 能安全攻击（攻击后不会被反击/反击伤害<自身血量30%）的最近敌军
3. 不攻击，移动到将领身边保护
4. 不攻击，移动到友军主力附近

**特殊行为规则：**
- **明哲保身**：每回合开始前先检查自身安全，若2格内有敌军则优先远离
- **惜兵如金**：不执行"必败攻击"（预计自身会被反击致死的攻击）
- **随军医生**：若有治疗技能，优先治疗血量最低的友军（尤其是将领）
- **战略撤退**：当友军开始撤退时，保守型AI最先撤退（不等待命令）
- **保存实力**：若己方总兵力劣势>2:1，主动后撤到安全距离

**弱点**：输出极低，几乎不造成有效杀伤；过早撤退可能导致防线出现缺口

### 2.6 隐藏AI类型：叛徒型

**触发条件**：仅限特定剧情（如内战中的摇摆角色），好感度在-30~-10之间的友军

**核心特征**：表面友军，实则暗中破坏

**特殊行为规则：**
```
每回合开始时进行【忠诚检定】：
  忠诚值 = 50 + 当前好感度 + 己方战场优势比
  己方优势比：己方兵力/敌方兵力 × 30
  
  忠诚值 ≥ 70：正常执行友军AI行为
  忠诚值 40~69：消极作战（移动慢1格、不主动攻击、不使用技能）
  忠诚值 20~39：故意挡路（站在友军移动路径上）、误伤友军（攻击时故意偏斜）
  忠诚值 < 20：叛变（变为敌方单位，保留原有属性）
```

## 三、好感度与AI行为

### 3.1 好感度等级与战场行为详表

| 好感区间 | 等级 | 友军行为 | 敌军行为 | 特殊规则 |
|---------|------|---------|---------|---------|
| 90~100 | 莫逆之交 | 7格内主动保护；替挡伤害；协同攻击+20% | 低于40%血停攻；尝试劝降 | 同生共死 |
| 75~89 | 亲密 | 7格内主动保护；优先集火同一目标 | 低于20%血停攻；可能劝降 | 心有灵犀 |
| 50~74 | 朋友 | 5格内主动保护；不主动争夺战利 | 低于10%血停攻；放走 | 袍泽之情 |
| 10~49 | 熟人 | 无特殊保护 | 无特殊留手 | 点头之交 |
| -30~9 | 冷漠 | 无特殊保护 | 无特殊追击 | 形同陌路 |
| -70~-31 | 敌对 | 无特殊 | 主动追击4格内；优先攻击 | 新仇旧恨 |
| -90~-71 | 仇视 | 无特殊 | 主动追击5格内；无视其他目标 | 刻骨仇恨 |
| -100~-91 | 死敌 | 无特殊 | 主动追击6格内；无视命令追击 | 不共戴天 |

### 3.2 莫逆之交（90~100）特殊协同系统

莫逆之交是游戏中最深厚的人际关系，在战场上表现为高度默契的配合。

**协同攻击（Coordinated Strike）：**
```
条件：两个莫逆之交关系单位相邻，且目标在同一攻击范围内
效果：
  - 先攻击的一方伤害+20%
  - 后攻击的一方伤害+20%
  - 若两人都选择了同一目标，该目标防御-15%（被两面夹击）
AI行为：莫逆之交AI会主动尝试移动到可以对同一目标发起协同攻击的位置
```

**替挡伤害（Intercept）：**
```
条件：莫逆之交关系单位在攻击路径上（相邻格），且该攻击会命中挚友
效果：
  - 30%概率替挡（受到50%伤害代替挚友受全额伤害）
  - 若替挡者血量≤30%，概率提升到60%（拼死护友）
  - 替挡后自身血量≤0%时，挚友获得【悲愤】buff（攻击+30%，持续2回合）
AI行为：莫逆之交AI在决策时，若挚友受到威胁，将【保护挚友】优先级提升到最高
```

**战场感应（Battle Sense）：**
```
条件：两个莫逆之交单位在5格内
效果：
  - 双方暴击率+10%
  - 一方被攻击时，另一方立即获得反击机会（即使不在攻击范围内）
  - 一方士气不会低于另一方当前士气（互相鼓舞）
```

**同生共死（Bond of Death）：**
```
条件：莫逆之交一方阵亡
效果：
  - 另一方立即获得【悲愤】状态：攻击+30%、防御-20%、永不撤退（持续到战斗结束或击杀杀害挚友的单位）
  - 若击杀了杀害挚友的敌人，【悲愤】转为【释然】：恢复正常但士气永久+10
  - 若悲愤状态下一方也阵亡，标记为【壮烈殉国】，影响结局和后续剧情
```

### 3.3 死敌（-91~-100）特殊行为系统

**无视命令（Berserk Pursuit）：**
```
规则：
  - 死敌型AI将【追击死敌】优先级设为最高（高于生存危机）
  - 即使上级下达了撤退/防守命令，死敌型AI仍会追击
  - 追击过程中无视其他任何目标（即使有更好的攻击机会）
  - 若死敌脱离视野（超过6格），每回合有20%概率恢复理智，回到正常AI逻辑
  
玩家干预：
  - 玩家可以强制命令死敌型AI停止追击（消耗1个指挥点）
  - 但下一回合仍有50%概率再次失控追击
  - 若玩家连续3回合成功命令，该角色好感度+5（被玩家的人格魅力折服）
```

**私人恩怨（Personal Vendetta）：**
```
规则：
  - 对死敌的攻击伤害+20%（愤怒加持）
  - 对死敌的攻击不考虑地形优势（无视防守地形减成）
  - 若死敌投降，10%概率拒绝接受（直接击杀）
  - 击杀死敌后，自身士气+20，但好感度相关的其他敌人好感度-10（兔死狐悲）
```

**宿敌对决（Duel of Fates）：**
```
触发条件：玩家角色与某角色好感度≤-90，且在战场上相遇（4格内）
效果：
  - 双方强制进入【对决】状态（持续3回合或一方死亡）
  - 对决期间：双方攻击+25%，防御-15%，无法被其他单位攻击（其他AI回避）
  - 对决结束后：胜者对败者（若败者未死）好感度额外-10
  - 若玩家获胜：可以尝试【饶恕】（好感度提升到-50~-30区间），影响结局走向
```

### 3.4 好感度动态变化（战斗中）

好感度不是静态的，战斗中的行为会实时改变好感度：

| 战场事件 | 好感度变化 | 影响对象 |
|---------|-----------|---------|
| 为友军挡下致命攻击 | +8 | 被保护者→保护者 |
| 协同击杀同一目标 | +3 | 参与者之间 |
| 友军阵亡而未能救援 | -5 | 阵亡者的亲友→未能救援者 |
| 抢夺友军击杀 | -3 | 被抢者→抢功者 |
| 治疗友军 | +2 | 被治疗者→治疗者 |
| 撤退时抛弃受伤友军 | -8 | 被抛弃者→抛弃者及其友军 |
| 击杀与某人有高好感的敌军 | -5 | 相关友人→击杀者 |
| 放过与某人有高好感的敌军 | +3（对放走者）/-5（对敌军阵营）| 相关方 |
| 为死敌留活路 | +5（对留手者）/-3（对己方）| 相关方 |

### 3.5 同窗好感度特殊规则

同学之间的关系在战场上有额外表现：

```
同窗基础加成：所有同学之间初始好感度≥30（熟人）

同窗对决特殊规则（内战中同窗相遇）：
  好感度≥50时：
    - 首次遭遇不主动攻击（犹豫1回合）
    - 攻击伤害-15%（留手）
    - 击杀后士气-20（内疚）
    - 被击杀后，凶手获得【同窗之殇】debuff（全属性-10%，持续3回合）
  
  好感度≤-31时（已决裂的同窗）：
    - 攻击伤害+10%（化悲愤为力量）
    - 击杀后士气+5（了断恩怨）但心情永久-10
    - 被击杀后触发【故人之痛】，玩家选择：悲愤或释然

  好感度-30~49之间（关系微妙的同窗）：
    - 遭遇时会对话（根据具体角色有不同的台词）
    - 对话后可能临时提升或降低好感度（±5）
    - 攻击时掷骰判定：30%概率留手（伤害-30%）
```

## 四、难度分级与AI

### 4.1 难度总览

| 维度 | 简单 | 普通 | 困难 | 噩梦 |
|------|------|------|------|------|
| 目标选择 | 随机选择范围内目标 | 按角色类型最优选择 | 最优选择+预判1回合 | 全局最优+预判2回合 |
| 移动效率 | 可能走错方向(30%) | 正常执行移动逻辑 | 移动路径最优 | 完美移动+占据最优地形 |
| 技能使用 | 不使用技能 | 基础技能使用 | 技能组合使用 | 技能组合+精确计算冷却 |
| 集火协同 | 无协同 | 2人集火 | 3-4人集火 | 全军协同集火 |
| 撤退判断 | 不撤退 | 按角色类型阈值 | 提前1回合预警撤退 | 完美撤退时机+殿后 |
| 资源管理 | 不补给不恢复 | 基础补给 | 主动补给+轮换 | 精确资源分配 |
| 情报获取 | 只能看到视野内 | 同简单 | 可以推断隐藏单位位置 | 完全情报（等同玩家视野） |
| 好感利用 | 不利用好感系统 | 基础好感行为 | 主动保护高好感友军 | 利用好感系统设伏/诱敌 |
| 错误率 | 20%执行错误决策 | 10% | 3% | 0%（完美执行） |

### 4.2 各难度详细设计

#### 简单难度（面向剧情体验玩家）

**设计理念**：让玩家轻松体验剧情，AI以"表演"为主

```
目标选择：
  - 在攻击范围内的目标中随机选择（不计算TVS）
  - 30%概率选择"看起来最酷"的目标（动画效果最炫的技能/攻击方式）
  - 不会主动集火

移动逻辑：
  - 30%概率走错方向（向错误方向移动1格）
  - 不会主动占据有利地形
  - 不计算ZOC（控制区域）

撤退逻辑：
  - 永不主动撤退
  - 即使血量很低也继续战斗（给玩家收割的快感）

技能使用：
  - 不使用任何主动技能
  - 被动技能正常触发

特殊照顾：
  - 敌方AI对玩家角色的攻击伤害-15%
  - 友军AI保护范围扩大到10格
  - 敌方AI命中率-10%
```

#### 普通难度（标准体验）

**设计理念**：有挑战但不刁难，AI按角色类型正常表现

```
目标选择：
  - 正常计算TVS并按角色类型选择目标
  - 10%概率做出次优选择（模拟判断失误）
  - 2个以上友军AI可攻击同一目标时，有50%概率集火

移动逻辑：
  - 正常执行PVS计算
  - 10%概率未选到最优格点（选择PVS第二高的位置）

撤退逻辑：
  - 按角色类型阈值正常触发
  - 不会执行"完美撤退"（不考虑下回合反击位）

技能使用：
  - 使用基础主动技能
  - 不会使用复杂的技能组合

情报：
  - 只能看到视野内的单位（战争迷雾正常生效）
```

#### 困难难度（面向核心战棋玩家）

**设计理念**：AI会思考、会配合、会利用玩家失误

```
目标选择：
  - TVS计算增加"预判1回合"：考虑目标下回合可能的移动方向
  - 优先选择"杀死后能打断玩家战术布局"的目标
  - 主动集火（3-4个AI单位攻击同一目标）
  - 会优先消除对己方将领的威胁

移动逻辑：
  - 最优路径选择
  - 主动占据有利地形（尤其是防御地形）
  - 会计算ZOC并避免不必要的机会攻击
  - 会尝试包围/夹击玩家薄弱单位

撤退逻辑：
  - 提前1回合预判是否需要撤退
  - 撤退路线考虑下回合的反击位置
  - 会安排殿后部队

技能使用：
  - 主动使用技能组合
  - 会利用控制技能（眩晕/减速）为队友创造输出机会
  - 会在合适的时机使用buff/debuff技能

情报：
  - 可以推断隐藏单位的大致位置（基于上一回合的侦察信息）
  - 能预判玩家可能的攻击路线

额外策略：
  - 会利用地形伏击（在森林/城市中埋伏）
  - 会分兵骚扰玩家后方
  - 会保护己方炮兵不被骑兵突袭
```

#### 噩梦难度（面向极限挑战玩家）

**设计理念**：AI完美执行，任何失误都会被惩罚

```
目标选择：
  - TVS计算增加"预判2回合"
  - 全局最优解（考虑全军所有单位的联合行动效果）
  - 完美集火（精确计算需要的伤害量，不多不少，避免浪费输出）
  - 会针对玩家阵容弱点定制策略

移动逻辑：
  - 完美路径选择+完美地形利用
  - 全军协同移动（不是各单位独立决策，而是整体最优）
  - 会创造"杀伤区域"（诱使玩家进入多个单位的联合攻击范围）

撤退逻辑：
  - 完美时机判断（不早不晚）
  - 交替掩护撤退（A撤B掩护，B撤C掩护）
  - 撤退后重新编队立即反扑

技能使用：
  - 精确计算技能冷却与伤害
  - 会在最关键的时机使用决定性的技能
  - 技能组合达到最大化效果

情报：
  - 完全情报（等同玩家视野）
  - 知道玩家所有单位的精确属性

特殊规则：
  - AI单位获得+10%全属性加成（弥补回合制先手劣势）
  - AI援军会在最佳时机出现（玩家最虚弱的时候）
  - AI会记忆玩家的战术习惯并做出针对性调整（同一关卡重试时策略变化）
```

### 4.3 难度动态调整（隐式）

游戏有一个隐式的动态难度系统（不告知玩家），根据玩家表现微调：

```
每3个战斗关卡评估一次：
  玩家表现分 = 己方损失比 × 0.4 + 通关回合数/标准回合数 × 0.3 + 将领存活率 × 0.3

  表现分 ≤ 0.3（表现很差）：
    - 下一个战斗关卡AI自动降低半个难度等级
    - 友军AI更积极地保护玩家

  表现分 ≥ 0.8（表现很好）：
    - 下一个战斗关卡AI提升半个难度等级
    - 敌方AI获得额外的战术选择

  注意：实际难度不会超过玩家选择的难度等级（即选了普通，最多升到困难，不会跳到噩梦）
```

## 五、剧情特殊AI

### 5.1 同窗对决

**触发场景**：内战爆发后，五大派系的同窗在不同阵营相遇

**AI行为修改器：**
```
基础规则覆盖：
  1. 同窗相遇时（4格内），双方AI暂停常规决策1回合
  2. 触发【对话事件】（根据具体角色和好感度播放不同对话）
  3. 对话结束后：
     a. 好感度≥50：双方攻击伤害-15%，持续本场战斗
     b. 好感度-30~49：正常战斗，但首次攻击伤害-10%
     c. 好感度≤-31：正常战斗，但击杀后触发特殊剧情

特殊场景 - "最后一课"：
  触发条件：玩家角色在内战中遇到教授/老师角色（如程夫子、许书院）
  AI行为：
    - 老师方AI：前3回合不主动攻击学生，防御+20%（以守代攻）
    - 老师方AI：若学生先攻击，第4回合开始正常战斗，但伤害-10%
    - 学生方（玩家/AI）：攻击老师角色时，所有参战学生士气-5
    - 击杀老师：所有学生永久心情-20，但获得【觉悟】buff（攻击+15%持续3回合）
    - 若学生选择不攻击（等待3回合），老师好感度+15，可能触发劝降剧情
```

### 5.2 内战派系AI特性

内战是游戏的核心冲突，不同派系的AI有不同的战略倾向。

#### 返乡团AI特性
```
战略倾向：稳扎稳打，步步为营
  - 防守型AI占比最高（40%为防守型）
  - 重视阵线完整性，不轻易突破
  - 会优先保护补给线

特殊规则 - "光复信念"：
  - 在朝家乡方向进攻时，全军士气+5
  - 若占领了关键城市（剧情标记的城市），全军防御+10%（"终于站上了故土"）
  - 老兵单位（等级≥4）永不撤退

友军协同：
  - 派系内部单位之间的集火协同+10%
  - 郑怀远作为将领时，周围5格友军攻击+5%
```

#### 干城派AI特性
```
战略倾向：猛烈进攻，以攻代守
  - 勇将型和激进型AI占比最高（50%）
  - 重视前线突破，不重视后方防守
  - 炮兵使用激进（经常前推炮兵阵地）

特殊规则 - "大陆军魂"：
  - 全军攻击+5%（前线的骄傲）
  - 当战线推进到敌方半场时，额外攻击+5%
  - 炮兵在进攻时伤害+10%

友军协同：
  - 不善于防守协同（保护行为范围-2格）
  - 但进攻协同时伤害额外+5%（一起冲锋的默契）
```

#### 印第安乡党AI特性
```
战略倾向：游击战术，地形利用
  - 智将型和防守型为主
  - 极度重视地形利用（森林/山地战斗效率最高）
  - 轻步兵/来复枪兵比例高

特殊规则 - "故土之灵"：
  - 在森林/山地地形上，全军防御+15%
  - 在平原地形上，全军防御-10%（离开了熟悉的地形）
  - 归化军团（与汉人混编）不受平原减益
  
特殊机动：
  - 印第安单位在森林/山地中移动消耗-1
  - 可以在敌方ZOC中"潜行"（不触发机会攻击，但移动力消耗正常）

友军协同：
  - 在熟悉地形上，协同效率+15%
  -  tribal warfare传统：同部落单位3格内时，暴击率+10%
```

#### 自由派/鼎新派AI特性
```
战略倾向：灵活机动，善于外交
  - 智将型为主，配合少量保守型
  - 善于利用战场道具/事件（如谈判、劝降）
  - 重视情报战

特殊规则 - "思想之光"：
  - 每回合可以尝试劝降一个敌军（好感度>-30的目标）
  - 劝降成功率 = 10% + 目标好感度/5 + 己方战场优势 × 15%
  - 被劝降单位变为"中立"（不攻击任何一方，持续2回合）

友军协同：
  - 可以与其他派系临时结盟（联合作战时协同效率不降低）
  - 擅长"换防"（与友军AI交换位置，优化阵型）
```

#### 法治派AI特性
```
战略倾向：纪律严明，阵型整齐
  - 防守型和保守型为主
  - 编队效率最高（编队系数额外+0.5）
  - 军纪最好（不追击、不贪功）

特殊规则 - "法度森严"：
  - 全军士气不会低于30（最低阈值提高）
  - 溃败概率-50%
  - 友军AI严格执行命令（命令遵从度+20%）
  - 但灵活性差：切换战术的响应慢1回合

友军协同：
  - 编队协同时防御额外+10%（铁壁阵型）
  - 阵型保持度最高（不会为了追击而散开）
```

### 5.3 最终决战AI

**最终决战**是游戏结局前的决战，AI行为根据玩家选择的路线和最终对手不同而有独特设计。

```
通用最终决战规则：
  - 敌方将领（最终Boss）拥有独特AI逻辑（非通用模板）
  - 最终Boss有两个阶段，每个阶段有不同的AI行为

阶段一：常规对抗
  - Boss正常指挥全军
  - 但会优先保护自身（不像玩家控制时那样冲锋）
  - 每消灭玩家一个单位，Boss全军士气+3

阶段二：觉醒/背水一战（Boss方血量≤30%或友军全灭时触发）
  - Boss进入【破釜沉舟】状态：
    - 攻击+30%、防御-20%
    - 不再保护自身，转为激进型AI
    - 所有技能无冷却（可以每回合使用）
    - 全军获得【最后一搏】buff：攻击+15%
  - 持续5回合后，若玩家仍未获胜，Boss自动撤退（留待续作/结局分支）
```

**各路线最终Boss特殊AI：**

```
路线E1（政治家）- 对手：返乡团元老郑怀远
  郑怀远AI：
    - 阶段一：防守型，优先保护朝中重臣，不主动进攻
    - 台词触发："老夫一生为光复大业，岂能毁于你手！"（防御+20%持续2回合）
    - 阶段二：转为智将型，尝试使用"政治手段"（劝降玩家部分友军）

路线E2（大将军）- 对手：干城派领袖张猛
  张猛AI：
    - 阶段一：激进型，直冲玩家将领位置
    - 台词触发："来！让我看看你这几年学到了什么！"（全军攻击+10%）
    - 阶段二：越战越勇，每回合移动力+1，永不撤退

路线E5（称帝/大总统）- 对手：法治派+返乡团联合
  联合AI：
    - 两派AI分别执行各自派系逻辑
    - 但当两派将领相邻时，触发"争权"（互相争夺指挥权，2格内友军指挥混乱1回合）
    - 玩家可以利用这一点，分化打击
```

## 六、友军协同AI

### 6.1 编队协同规则

友军AI遵循严格的编队体系，编队内部有明确的协同规则。

**编队AI行为框架：**
```
编队组成：
  - 每个编队有一个"核心单位"（通常是编队中等级最高/军衔最高的）
  - 核心单位决定编队的整体行为模式
  - 其他编队成员以核心单位为中心行动

编队移动：
  - 编队移动时，非核心单位尽量保持与核心单位相邻（1格内）
  - 若编队成员脱离编队（被攻击/追击等原因），会在安全后尝试回归
  - 编队整体移动速度 = 编队中最慢单位的移动力

编队战斗：
  - 同一编队的单位攻击同一目标时，触发【编队协同攻击】
    单编(系数5)：额外伤害+5%
    双编(系数6)：额外伤害+10%
    三编(系数7)：额外伤害+15%
  - 编队成员被攻击时，相邻编队友军自动支援（反击时伤害+10%）

编队防御：
  - 编队核心单位决定阵型：
    勇将型核心：进攻阵型（成员向前展开，攻击范围最大化）
    防守型核心：防御阵型（成员围绕核心紧密排列，防御最大化）
    智将型核心：灵活阵型（根据战场情况动态调整）
```

### 6.2 上级指令系统

玩家和高级友军AI可以对低级友军AI下达指令。

**指令类型：**

| 指令类型 | 描述 | AI行为变化 | 指挥点消耗 |
|---------|------|-----------|-----------|
| 攻击目标 | 指定一个目标优先攻击 | 该目标TVS+100%，持续3回合 | 1 |
| 防守位置 | 指定防守一个格点/区域 | 防守型AI优先移动到指定位置，不主动出击 | 1 |
| 移动路线 | 指定移动路径 | AI沿指定路径移动，但遇到敌人仍会战斗 | 1 |
| 撤退集合 | 指定撤退集合点 | 所有受令单位向集合点撤退，途中避免战斗 | 2 |
| 自由行动 | 取消之前指令 | AI恢复自主决策 | 0 |
| 护卫任务 | 保护指定单位 | 防守型行为，但保护目标变为指定单位 | 1 |
| 佯攻 | 吸引敌方注意力 | 移动到敌方视野内但不攻击，为友军创造侧翼机会 | 1 |

**指令优先级：**
```
1. 玩家直接指令（最高优先级）
2. 友军AI上级（军衔更高者）指令
3. 编队核心单位指令
4. 自身角色类型默认行为（最低优先级）

例外：
  - 当执行指令会导致单位必死（血量≤10%且目标战力>自身3倍）时，AI拒绝执行
  - 激进型AI拒绝执行"撤退"和"防守"指令（除非好感度>50的上级下达）
  - 死敌追击状态下，只有玩家指令可以中断（友军AI指令无效）
```

### 6.3 玩家战略目标机制

玩家可以在战略层面给友军AI设定总体目标，影响整场战斗的AI行为倾向。

**战略目标设定界面（战斗开始前）：**
```
战略目标选项：
  1. 全力进攻 - 全军AI转为激进型，攻击权重×2.0，防御权重×0.5
  2. 稳扎稳打 - 全军AI保持角色类型默认，编队协同+10%
  3. 重点防守 - 全军AI防御权重×1.5，攻击权重×0.7
  4. 保护将领 - 所有友军AI转为保守型，保护玩家角色
  5. 集中突破 - 选择一个方向，全军向该方向集中进攻
  6. 分兵牵制 - 分为两组，一组进攻一组迂回
  7. 保存实力 - 全军AI保守，优先避免损失（适合以少打多的关卡）
```

**战略目标对AI的具体影响：**
```
全力进攻：
  - 所有友军AI的TVS中"攻击机会"权重×2
  - 撤退阈值降低到血量的50%（更晚撤退）
  - 友军AI会主动寻找最优攻击位置
  - 风险：容易被反击/伏击

稳扎稳打：
  - 友军AI正常执行角色类型逻辑
  - 编队协同攻击伤害额外+10%
  - 不会脱离编队单独行动
  - 适合正面硬刚的关卡

重点防守：
  - 友军AI优先占据防御地形
  - 不主动追击撤退的敌军
  - 被攻击时才反击
  - 适合防守关卡/等待援军

保护将领：
  - 7格内的友军AI全部转为保护行为
  - 玩家角色周围始终保持2-3个护卫
  - 但其他区域可能防守空虚

集中突破：
  - 玩家选择一个方向（上下左右/6个六边形方向之一）
  - 友军AI向该方向集中，形成攻击矛头
  - 矛头位置的单位攻击+15%
  - 侧翼和后方相对薄弱

分兵牵制：
  - 玩家指定主力和偏师
  - 主力正面进攻（吸引敌方注意）
  - 偏师从侧翼/后方迂回
  - 偏师AI会尽量避免战斗，绕到敌后
  - 成功迂回后，敌后攻击伤害+30%

保存实力：
  - 友军AI不执行必败攻击
  - 受伤单位自动后撤治疗
  - 不追击残血敌军
  - 适合以少打多、需要多关连续作战的场景
```

### 6.4 友军AI自主决策（无指令时）

当玩家没有给友军AI下达具体指令时，友军AI根据自身类型和战场情况自主决策：

```
友军AI自主决策优先级：
  1. 保护己方将领（防守型/保守型优先）
  2. 消灭对己方威胁最大的目标
  3. 占据有利地形
  4. 保持编队完整性
  5. 协助受伤的友军

自主决策的局限性：
  - 友军AI不会执行复杂的战术（如佯攻、伏击）
  - 友军AI不会主动改变战略目标
  - 友军AI可能对突发情况反应迟钝（如敌方突袭后方）
  - 智将型友军AI的自主决策质量最高（最接近玩家水平）
```

### 6.5 AI通信系统（友军之间的信息共享）

```
视野共享规则：
  - 同一编队内共享视野
  - 5格内的友军共享视野（简单难度3格，噩梦难度8格）
  - 将领单位的视野共享范围+3格
  
信息延迟：
  - 简单难度：信息延迟2回合（敌军位置更新慢）
  - 普通难度：信息延迟1回合
  - 困难难度：无延迟
  - 噩梦难度：无延迟 + 可推断敌军上一回合的移动方向

通信中断：
  - 若友军被包围（所有相邻格有敌军），与其他友军的信息共享中断
  - 被包围的友军AI进入"独立作战"模式（只考虑自身视野内的信息）
  - 通信中断的友军AI可能做出错误决策（如向已有敌军的区域移动）
```

## 七、AI行为示例

### 示例一：勇将型AI的回合决策

**场景**：张猛（勇将型，重骑兵，血量60%，士气70）在平原上，左侧3格有一个敌方来复枪兵（血量40%），右侧2格有一个敌方轻骑兵（血量90%），后方4格有己方将领。

**决策过程**：
```
优先级1 - 生存危机检测：
  血量60% > 10%（勇将型阈值）→ 不触发
  周围2个敌军，未被包围 → 不触发

优先级2 - 命令遵从：
  无上级指令 → 跳过

优先级3 - 好感度驱动：
  检查各目标好感度... 无特殊触发 → 跳过

优先级4 - 常规作战决策：
  攻击范围内有目标吗？
  - 重骑兵移动力6格，攻击范围2格
  - 来复枪兵在3格（移动后可进入攻击范围）
  - 轻骑兵在2格（已在攻击范围内）
  → 有可攻击目标，进入目标选择

目标选择（TVS计算）：
  来复枪兵：
    基础100 × 勇将型对低血量+50% = 150
    × 血量≤30%? 否(40%) = 150（不触发收割加成的条件≤30%）
    × 平地无防御 = 150
    = 150
  
  轻骑兵：
    基础100 × 勇将型对高血量-20% = 80
    × 平地无防御 = 80
    = 80

  → 选择来复枪兵（TVS 150 > 80）

移动决策：
  从来复枪兵方向选择最优攻击位置
  → 移动3格到来复枪兵相邻格

攻击执行：
  攻击来复枪兵
  → 击杀！（来复枪兵血量40%扛不住重骑兵冲锋）

优先级5 - 战后处理：
  击杀敌人 → 越战越勇触发，剩余移动力+1
  → 张猛还有2格移动力（6-3=3，攻击不消耗移动力，但越战越勇+1=4）
  → 检查是否还有其他目标在范围内
  → 轻骑兵现在在攻击范围内
  → 继续攻击轻骑兵！（勇将型就是停不下来）
```

### 示例二：智将型AI的协同决策

**场景**：沈沧海（智将型，来复枪兵，血量80%）与两个友军（线列步兵A和火炮B）在场。敌方有一个重骑兵（高威胁，正在逼近己方将领）和三个民兵。

**决策过程**：
```
优先级1 - 生存危机：无危险 → 跳过

优先级4 - 常规作战：
  攻击范围内有目标 → 计算TVS

  重骑兵（威胁值极高，正在逼近己方将领）：
    基础100 × 智将型对高威胁+40% = 140
    × 正在威胁己方将领+60% = 224
    → TVS = 224
  
  民兵×3（低威胁）：
    基础100 × 智将型对低威胁-10% = 90
    → TVS = 90

  → 选择重骑兵

  但沈沧海评估自身能否击杀重骑兵：
  → 计算伤害... 不足以一击杀
  → 检查友军位置：线列步兵A在4格外，火炮B在6格外

  智将型的【战场调度】触发：
  → 沈沧海不直接攻击
  → 而是移动到能为最多友军创造攻击机会的位置
  → 移动到可以同时看到重骑兵且线列步兵A也能攻击到的位置
  → 使用技能【精确射击】（降低重骑兵防御15%，持续2回合）
  
  同时：
  → 线列步兵A（防守型）被AI逻辑引导到重骑兵侧面
  → 火炮B（智将型）计算出重骑兵的预测移动路径，瞄准前方1格
  → 形成三面包围之势

  结果：
  → 下回合三个单位集火重骑兵
  → 预计可以击杀（协同攻击加成+10%）
```

### 示例三：好感度影响AI行为

**场景**：玩家角色（好感度85，亲密）与顾承恩（同学，AI控制）组队。顾承恩是防守型AI。敌方有一个来复枪兵正在攻击玩家。

**顾承恩的决策过程**：
```
优先级3 - 好感度驱动：
  检查好感度：玩家好感85 = 亲密
  玩家在5格内且正在被攻击 → 触发【保护挚友】
  
  【保护挚友】规则：
    移动到可以反击攻击玩家的敌军位置
    → 顾承恩计算：来复枪兵在玩家右侧2格
    → 顾承恩移动到玩家右侧1格（与来复枪兵相邻）
    → 反击来复枪兵！

优先级5 - 好感度动态变化：
  顾承恩成功保护了玩家
  → 玩家对顾承恩好感度+2（变为87，仍在亲密范围）
  → 顾承恩对玩家好感度+1（变为86）
```

### 示例四：死敌追击导致AI失控

**场景**：王铁柱（激进型，与刘小炮好感度-95，死敌）。刘小炮是敌方单位，血量30%，在6格之外。上级AI命令王铁柱防守桥梁。

**王铁柱的决策过程**：
```
优先级3 - 好感度驱动：
  死敌刘小炮在6格内 → 触发【追击死敌】
  → 优先级提升到最高！

  上级指令"防守桥梁"被忽略！
  → 王铁柱向刘小炮方向全力移动

  王铁柱移动了6格（骑兵移动力），现在距离刘小炮1格
  → 攻击刘小炮！
  → 刘小炮血量30%被击杀

  战后：
  → 王铁柱已经远离桥梁5格
  → 敌方趁机占领桥梁
  → 玩家防线出现缺口！

  这是死敌AI的核心风险：
  → 个人恩怨凌驾于战场纪律
  → 玩家需要提前用指挥点控制死敌型AI
  → 或者将死敌分开部署在不同战线
```

### 示例五：噩梦难度的AI联合决策

**场景**：噩梦难度下，敌方有5个AI单位：1个智将型将领、2个勇将型步兵、1个防守型炮兵、1个智将型骑兵。玩家有4个单位。

**噩梦AI的全局决策过程**：
```
阶段1 - 全局态势评估：
  分析玩家4个单位的类型、位置、可能行动
  → 预判玩家下回合最可能的攻击目标（敌方炮兵）
  
阶段2 - 联合行动计划：
  智将型将领（指挥官）制定计划：
  → 防守型炮兵后撤到掩体后方（减少被突袭风险）
  → 骑兵迂回到玩家侧翼（切断退路）
  → 两个勇将型步兵正面推进（吸引玩家注意）
  
阶段3 - 精确计算：
  → 两个步兵的攻击预计造成X点伤害
  → 若玩家反击步兵A，步兵B补位
  → 骑兵在玩家撤退路线上设置拦截
  → 炮兵在安全位置提供火力支援
  
阶段4 - 执行：
  → 所有单位协同行动
  → 玩家发现：
    - 正面被两个步兵压制
    - 侧翼被骑兵威胁
    - 想撤退发现退路被切断
    - 想先打炮兵但距离太远且被掩体保护
  → 这就是噩梦难度：AI像人类玩家一样思考

  关键差异：
  → 普通难度下这5个AI各自为战
  → 噩梦难度下它们像一个团队
  → 玩家必须找到破绽（如利用两个步兵之间的间隙突破）
```

### 示例六：内战中同窗对决的AI表现

**场景**：内战，玩家（返乡团阵营）遇到沈天佑（干城派同学，好感度55，朋友）。沈天佑AI控制。

**沈天佑的决策过程**：
```
特殊触发 - 同窗对决：
  检测到与玩家（沈天佑的同学）在4格内

  第1回合：
    → 暂停常规决策
    → 触发对话事件：
      沈天佑："没想到战场上相见……你还好吗？"
      玩家选择回应（不同选择影响好感度和后续行为）

  对话结束后，恢复AI决策：
    好感度55（≥50）：
      → 攻击伤害-15%（留手）
      → 不主动使用强力技能
      → 若玩家血量≤30%，不攻击（朋友级别的留手）
      → 但仍会防御和移动（不是站着挨打）

  特殊情况：
    → 如果玩家主动攻击沈天佑：

      第2回合：好感度-10（变为45）

      但首次攻击伤害仍-10%（同窗之情的残余）

    → 如果玩家选择不攻击（等待3回合）：
      沈天佑好感度+10（变为65）
      触发特殊剧情："战场上还有几分同学情。"

```
