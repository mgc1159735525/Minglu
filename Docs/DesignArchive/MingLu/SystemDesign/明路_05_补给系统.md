# 明路 - 补给系统设计

---

## 一、补给系统概述

### 1.1 设计理念

《明路》采用**无经济系统**设计——玩家不造建筑、不攒金币、不研究科技树。但这不意味着战争没有代价。补给系统是战斗的核心战略层：

> **弹药与粮草合并为「补给值」**。部队在战场上需要持续消耗补给来维持战斗力。补给不是钱，而是后勤线的生命力。

补给系统的核心体验：
- **战略层**：控制城市 = 控制补给节点；切断补给线 = 不战而屈人之兵
- **战术层**：每回合决策——激进推进可能断补，稳扎稳打则补给充裕
- **角色层**：后勤将领价值凸显，后勤属性从"辅助"变为"核心能力"

### 1.2 核心循环

```
控制城市/镇子 → 产出补给 → 沿补给线输送 → 前线部队消耗
     ↑                                        ↓
  夺取敌方据点 ← 敌军缺补削弱 ← 前线部队作战
```

### 1.3 适用范围

- **战役地图（战略层）**：大地图上的城市控制与补给线规划
- **战斗关卡（战术层）**：六边形战场上的补给消耗与补给线保护
- 两者共用同一套补给值系统，战役地图的补给状态会带入战斗关卡

## 二、补给值与消耗规则

### 2.1 补给值定义

每支部队拥有一个**补给值**（Supply），上限为 **100**。

- 补给值 ≠ 生命值。补给值影响战斗力，生命值影响存活性。
- 补给值降至 0 时进入「断补」状态。

### 2.2 补给消耗表

| 行动类型 | 补给消耗 | 说明 |
|---------|---------|------|
| **待机（待命）** | 2/回合 | 原地不动，最低消耗 |
| **移动** | 3/回合 | 不论移动格数，每回合固定消耗 |
| **攻击** | 5/回合 | 含移动后攻击，弹药消耗大 |
| **移动 + 攻击** | 6/回合 | 本回合既移动又攻击 |
| **围城状态** | 消耗 ×2 | 在上述基础上翻倍 |
| **围城炮开火** | 额外 +8/次 | 围城炮每次攻击额外消耗 |

### 2.3 地形对补给消耗的影响

| 地形 | 补给消耗修正 | 说明 |
|------|-----------|------|
| 平原 | ×1.0 | 标准 |
| 山丘 | ×1.0 | 标准 |
| 山地 | ×1.3 | 运输困难 |
| 森林 | ×1.2 | 道路不畅 |
| 沿河 | ×1.1 | 略有影响 |
| 村/镇/小城/大城市 | ×0.8 | 就地补给便利 |
| 超大城市 | ×0.6 | 物资丰富 |
| 栅栏/掩体/壕沟 | ×1.0 | 不影响补给消耗 |

> **计算方式**：基础消耗 × 地形修正 × 编队修正（见2.4），向下取整，最低为1。

### 2.4 编队对补给消耗的影响

| 编队类型 | 补给消耗系数 | 说明 |
|---------|-----------|------|
| 单编（系数5） | ×0.8 | 小规模部队消耗少 |
| 双编（系数6） | ×1.0 | 标准 |
| 三编（系数7） | ×1.3 | 大规模部队消耗大 |

### 2.5 兵种基础补给消耗差异

| 兵种大类 | 补给消耗修正 | 说明 |
|---------|-----------|------|
| 步兵（gun/guns） | ×1.0 | 标准 |
| 骑兵（cold） | ×1.2 | 马匹需要额外粮草 |
| 炮兵（cannon） | ×1.3 | 弹药消耗巨大 |
| 火炮类（轻/重/加农/榴弹/围城炮） | ×1.5 | 重型火炮弹药极耗 |

> **完整示例**：三编重火炮在山地攻击
> 基础消耗 5 × 地形1.3 × 编队1.3 × 兵种1.5 = 5 × 2.535 ≈ **13/回合**

## 三、补给来源与补给线

### 3.1 补给来源

#### 3.1.1 城市补给产出

每座被己方控制的城市/镇子每回合产出补给，可供给经过的补给线或驻扎部队。

| 聚落类型 | 每回合补给产出 | 驻军补给回复 | 说明 |
|---------|-------------|------------|------|
| 村子 | 5 | 3 | 仅能维持少量驻军 |
| 镇子 | 15 | 8 | 基本补给节点 |
| 小城市 | 30 | 15 | 区域补给中心 |
| 大城市 | 60 | 30 | 重要补给枢纽 |
| 超大城市 | 100 | 50 | 核心补给基地 |

- **驻军补给回复**：部队驻扎在城市中时，每回合回复的补给值。
- **补给产出**：该城市能向补给线提供的总补给量。

#### 3.1.2 就地补给

部队停留在城市/镇子时，直接消耗该城市的补给产出回复自身补给值。回复量 = 驻军补给回复值 ×（1 + 后勤将领加成）。

#### 3.1.3 后勤将领加成

拥有后勤属性的将领指挥部队时，提升所在部队补给回复效率（详见第五章）。

### 3.2 补给线机制

#### 3.2.1 补给线定义

补给线是从**己方控制的城市**到**前线部队**之间的路径。补给沿最短可用路径传输。

**补给线路径规则**：
- 补给线沿六边形格子延伸，经过的格子必须是：
  - 己方控制的格子（城市/镇子/村子）
  - 己方部队驻扎的格子
  - 无部队控制的空白格子（可传输，但脆弱）
- 补给线**不能穿过**敌方部队驻扎的格子或敌方控制的城市
- 补给线长度无上限，但每经过一个无控制空白格子，传输损耗 +5%

#### 3.2.2 补给线状态

| 状态 | 条件 | 效果 |
|------|------|------|
| **畅通** | 补给线完整连通至产出城市 | 部队正常接收补给，每回合回复 |
| **脆弱** | 补给线经过 ≥3 个无控制格子 | 补给回复量 -30% |
| **紧张** | 补给线经过 ≥6 个无控制格子 | 补给回复量 -60% |
| **切断** | 补给线被敌方部队/城市阻断 | 进入缺补状态（见第四章） |

#### 3.2.3 补给线判定顺序

每回合开始时按以下顺序判定：
1. 检查所有己方控制城市
2. 从每座友方城市向外扩展，标记所有可达的己方部队
3. 为每支部队找到**最优补给线**（产出最高 + 路径最短）
4. 计算补给传输损耗
5. 部队获得补给回复

#### 3.2.4 多源补给

当一支部队处于多座城市的补给范围内时：
- 选择**产出最高**的城市作为主补给源
- 其余城市提供 **20% 的额外补给回复**（最多叠加2个额外源）
- 只要有一条线畅通，就不算断补

## 四、缺补状态与惩罚

### 4.1 缺补阶段

当部队补给值下降时，依次进入不同缺补阶段：

| 阶段 | 补给值范围 | 攻击力 | 移动力 | 生命损耗 | 士气 | 其他效果 |
|------|----------|-------|-------|---------|------|---------|
| **充足** | 71-100 | — | — | — | — | 正常状态 |
| **轻度缺补** | 41-70 | -10% | -1 | — | — | 技能消耗 +20% |
| **中度缺补** | 16-40 | -25% | -1 | 每回合 -5% HP | 每回合 -3 | 防御力 -10% |
| **严重缺补** | 1-15 | -50% | -2 | 每回合 -10% HP | 每回合 -8 | 防御力 -20%，有概率逃兵 |
| **断补** | 0 | -60% | -2 | 每回合 -15% HP | 每回合 -15 | 无法使用技能，每回合判定溃散 |

### 4.2 溃散机制

部队处于**断补**状态时，每回合末进行溃散判定：

| 断补持续回合 | 溃散概率 | 溃散后果 |
|------------|---------|---------|
| 第1回合 | 0% | 仅惩罚，不溃散 |
| 第2回合 | 10% | 溃散后部队消失，将领生还 |
| 第3回合 | 30% | 同上 |
| 第4回合 | 50% | 同上 |
| 第5回合及以上 | 70% | 同上 |

**溃散概率修正**：
- 将领士气高（>70）：溃散概率 -10%
- 部队为精锐/禁军：溃散概率 -15%
- 部队为民兵：溃散概率 +15%
- 周围有友军（3格内 ≥2 支）：溃散概率 -10%
- 将领好感度高（>75）：溃散概率 -5%

### 4.3 逃兵机制

严重缺补阶段（补给 1-15），每回合有 **5% 概率**出现逃兵：
- 逃兵使部队当前兵力减少 10%（不影响编队等级，但降低实际战力）
- 累计逃兵 3 次后，部队自动降级一个等级
- 逃兵概率修正：
  - 民兵：+10%
  - 线列步兵/常规骑兵：±0%
  - 精锐/禁军：-5%（最低 0%）

### 4.4 补给恢复

当补给线恢复畅通后：
- 部队每回合回复量 = 补给源回复值 ×（1 + 后勤加成）- 地形传输损耗
- 补给值恢复无上限溢出（不超过100）
- 缺补状态的负面效果**立即解除**（不需要缓冲回合）
- 溃散判定从断补回合 0 重新开始计算

## 五、后勤属性详解

### 5.1 后勤属性概述

后勤是主角及NPC将领的6大学科属性之一（0-5星），直接影响部队的补给效率和持续作战能力。

### 5.2 后勤星级效果表

| 后勤星级 | 补给消耗减少 | 生命回复加成 | 补给线效果 | 特殊能力 |
|---------|-----------|-----------|----------|---------|
| **0星** | — | — | — | 无 |
| **1星** | -10% | +2%/回合 | — | 无 |
| **2星** | -20% | +4%/回合 | 补给线脆弱阈值+2格 | 无 |
| **3星** | -30% | +6%/回合 | 补给线脆弱阈值+3格 | 可分配补给优先权 |
| **4星** | -40% | +8%/回合 | 补给线紧张阈值+3格 | 可指挥补给车队，战场补给站 |
| **5星** | -50% | +10%/回合 | 所有阈值+5格 | 补给车队 ×2，移动补给站 |

### 5.3 后勤星级详细说明

#### 1星后勤
- **补给消耗 -10%**：所有行动消耗减少一成
- **生命回复 +2%**：每回合回复最大生命值的 2%（非补给值）
- 定位：基础加成，刚入门的后勤军官

#### 2星后勤
- **补给消耗 -20%**
- **生命回复 +4%**
- **补给线脆弱阈值+2格**：原本经过3个无控制格子才算脆弱，现在需要5个
- 定位：合格的后勤管理者

#### 3星后勤
- **补给消耗 -30%**
- **生命回复 +6%**
- **补给线紧张阈值+3格**：原本6格算紧张，现在9格才算
- **补给优先权分配**：可以选择让某支部队的补给优先级最高（消耗降低额外10%）
- 定位：资深后勤参谋，可以统筹区域补给

#### 4星后勤
- **补给消耗 -40%**
- **生命回复 +8%**
- **所有补给线阈值+5格**：补给线更不容易被切断
- **可指挥补给车队**：解锁补给车队单位（详见第六章）
- **战场补给站**：每场战斗可在己方区域设置1个补给站，周围3格内部队补给消耗 -20%
- 定位：后勤专家，一人顶半个辎重营

#### 5星后勤
- **补给消耗 -50%**：消耗减半，极大延长持续作战能力
- **生命回复 +10%**：每回合回复一成生命
- **所有补给线阈值+5格**：叠加3星效果，总+8格
- **补给车队 ×2**：可同时指挥2支补给车队
- **移动补给站**：补给站变为可移动单位，跟随部队推进
- 定位：后勤大师，整个军团的生命线

### 5.4 NPC将领后勤效果

NPC将领按后勤星级享有相同加成，但效果仅作用于其**直属部队**：
- 将领后勤 3 星以上时，其指挥的所有部队享受补给消耗减少
- 将领后勤 5 星时，其指挥的部队 additionally 每回合额外回复 3% HP
- 多将领协同：若多支部队在同一补给线上，取**最高后勤星级**的将领效果，其余将领效果减半叠加

### 5.5 后勤属性成长建议

| 成长阶段 | 建议星级 | 说明 |
|---------|---------|------|
| 军校期（第1年） | 0→1星 | 基础课程 |
| 军校期（第2年） | 1→2星 | 实习经历 |
| 军校期（第3年） | 2→3星 | 毕业设计/实战演习 |
| 内战初期 | 3→4星 | 实战历练 |
| 内战中后期 | 4→5星 | 大兵团作战经验 |

> 玩家可以选择主修后勤，使主角成为"后勤大师"型角色；也可以让NPC同伴补位。

## 六、补给车队

### 6.1 补给车队概述

补给车队是后勤将领（≥4星）可指挥的**特殊支援单位**，不参与战斗，专职运输补给。

### 6.2 补给车队属性

| 属性 | 数值 |
|------|------|
| HP | 80 |
| 防御力 | 5（几乎无防御） |
| 移动力 | 4格/回合 |
| 攻击力 | 0（无法攻击） |
| 补给携带量 | 200 |
| 补给释放范围 | 周围3格 |

### 6.3 补给车队功能

#### 6.3.1 运输补给
- 补给车队从后方城市装载补给（消耗城市的补给产出）
- 移动至前线部队附近，释放补给给范围内友军
- 每回合可释放补给量 = 30（基础）×（1 + 后勤将领星级 × 10%）
  - 4星后勤：30 × 1.4 = 42/回合
  - 5星后勤：30 × 1.5 = 45/回合

#### 6.3.2 延伸补给线
- 补给车队本身视为一个**移动补给节点**
- 其他部队可以从补给车队获取补给（如同从城市获取）
- 这使得补给线可以"跳跃式"延伸：城市 → 补给车队 → 前线部队

#### 6.3.3 紧急补给
- 补给车队可以执行「紧急补给」指令：一次性将携带量的50%释放给周围3格友军
- 释放后补给车队需要返回城市重新装载（消耗2回合）

### 6.4 补给车队的脆弱性

| 情况 | 后果 |
|------|------|
| 补给车队被攻击 | 敌方正常计算伤害（几乎无防御） |
| 补给车队被击毁 | 携带补给全部损失，该区域部队失去延伸补给线 |
| 补给车队被截断退路 | 无法返回装载，携带量耗尽后失效 |

### 6.5 补给车队数量限制

| 后勤星级 | 可同时指挥的补给车队数 |
|---------|-------------------|
| 0-3星 | 0（不可指挥） |
| 4星 | 1 |
| 5星 | 2 |

> 敌方也可能有后勤将领指挥补给车队。击毁敌方补给车队是切断其补给的高效战术。

## 七、特殊场景补给规则

### 7.1 围城战补给

围城是一种特殊的战斗状态，补给消耗大幅增加：

| 围城要素 | 补给规则 |
|---------|---------|
| 围城部队 | 所有行动消耗 ×2 |
| 围城炮 | 每次开火额外消耗 8 补给 |
| 围城炮持续轰击 | 若连续3回合开火，第4回合起额外消耗 +5（疲劳累积） |
| 城内守军 | 城内补给消耗 ×0.5（有储备），但城市补给产出因围城 -50% |
| 长期围困 | 每超过5回合，城内守军补给产出再 -10%（累积） |

**围城炮特殊规则**：
- 围城炮每回合开火消耗 = 基础5 + 额外8 = 13（未算地形/编队修正）
- 若补给不足，围城炮无法开火（不同于其他兵种可以降级攻击）
- 围城炮的补给消耗不受"待机减半"规则影响

### 7.2 渡河与水上补给

| 情况 | 补给规则 |
|------|---------|
| 部队渡河 | 渡河回合补给消耗 +5 |
| 补给线跨河 | 若河上有己方控制的桥梁/渡口，正常传输 |
| 无桥梁跨河 | 补给线无法跨河（需绕行至有控制点的渡口） |

### 7.3 夜战补给

| 情况 | 补给规则 |
|------|---------|
| 夜间战斗 | 所有部队补给消耗 +20%（夜间行动困难） |
| 夜间驻扎 | 补给回复量 -30%（夜间运输效率低） |
| 后勤4星以上 | 夜间消耗修正 -10%（夜间补给训练有素） |

### 7.4 伏击与补给线截断

| 情况 | 补给规则 |
|------|---------|
| 轻骑兵/骠骑兵敌后渗透 | 进入敌方补给线格子后，可「截断补给线」 |

## 附录：设计说明

### 与传统补给系统的区别

| 维度 | 传统战棋 | 《明路》补给系统 |
|------|---------|--------------|
| 资源类型 | 金币/粮食/弹药分开 | 统一"补给值" |
| 经济管理 | 造建筑、攒资源、升级 | 无经济系统，靠控制据点 |
| 补给线 | 通常不存在 | 核心机制，被切断有严重后果 |
| 后勤角色 | 辅助定位 | 战略核心，直接影响战争走向 |
| 补给车队 | 通常不存在或极简 | 重要战术单位，可被击毁 |

### 与伤害公式的联动

补给系统不直接修改伤害公式，而是通过**攻击力百分比修正**间接影响：

```
实际攻击输出 = 伤害公式计算结果 × 缺补攻击修正

其中缺补攻击修正：
- 充足：×1.0
- 轻度缺补：×0.9
- 中度缺补：×0.75
- 严重缺补：×0.5
- 断补：×0.4
```

### 平衡性考量

1. **防止滚雪球**：补给消耗确保推进越远越困难，进攻方自然减速
2. **防守方优势**：防守方靠近己方城市，补给充足；进攻方补给线拉长，逐渐削弱
3. **骑兵突袭的价值**：轻骑兵绕后切断补给线 = 战略级打击
4. **后勤将领的价值**：5星后勤 vs 0星后勤 = 部队持续作战时间翻倍
5. **围城的代价**：围城消耗巨大，不能无限围，必须速战或确保补给充足
