# 明路 - 存档系统与多周目设计

---

## 一、存档系统

### 1.1 自动存档

自动存档在以下节点**强制触发**，玩家无法跳过：

| 触发节点 | 存档标识 | 说明 |
|---------|---------|------|
| 每章结束时 | `AUTO_CH{章节号}_END` | 包含完整状态快照 |
| 关键抉择弹出前 | `AUTO_PRE_EV{事件号}` | 保存选择前的状态，允许反悔重选 |
| 战斗开始前 | `AUTO_BAT_{战役名}` | 记录战场初始部署 |
| 战斗结束后 | `AUTO_BAT_{战役名}_RESULT` | 记录战斗结算数据 |
| 每周日夜晚（校园阶段） | `AUTO_WEEKLY_SUN` | 仅保留最近3周的周日存档，滚动覆盖 |
| 内战阶段每次扎营/休整 | `AUTO_CAMP_{地名}` | 内战中的休整节点 |
| 结局确定瞬间 | `AUTO_ENDING_{结局编号}` | 结局CG播放前的最终状态，不可覆盖 |

**自动存档总数上限**：20个。超出时按FIFO策略淘汰最早的自动存档（`AUTO_ENDING_*` 永不淘汰）。

### 1.2 手动存档

| 槽位 | 标识 | 说明 |
|------|------|------|
| 手动存档 1 | `MANUAL_1` | 玩家自由保存/覆盖 |
| 手动存档 2 | `MANUAL_2` | 玩家自由保存/覆盖 |
| 手动存档 3 | `MANUAL_3` | 玩家自由保存/覆盖 |

**存档界面交互**：
- 显示存档缩略图（当前场景截图）、日期/时间、游戏内时间（年月日）、主角军衔、所在章节
- 长按存档槽位可查看详细内容（属性面板、好感度列表、立场快照）
- 支持手动删除（需二次确认）

### 1.4 存档安全与防坏档

| 机制 | 实现方式 |
|------|---------|
| **SHA256 校验** | 每个存档文件末尾附加完整数据的 SHA256 哈希值，加载时校验。校验失败则提示"存档损坏"并尝试从备份恢复 |
| **自动备份** | 每次写入存档前，将上一个版本自动复制为 `*.bak`。最多保留每个槽位1个备份 |
| **版本兼容** | 存档头部记录游戏版本号。若游戏更新导致数据结构变更，加载时自动执行迁移脚本（`migration_v1_to_v2` 等） |
| **异常保护** | 存档写入采用原子操作：先写临时文件 `.tmp`，写入成功后再重命名为正式文件。防止写入中断导致坏档 |
| **坏档恢复** | 若主存档校验失败 → 尝试读取 `.bak` → 若备份也失败 → 回退到最近的自动存档 → 若全部失败 → 提示"存档不可恢复"，保留损坏文件供调试 |
| **数值边界** | 加载时对全部数值字段进行边界检查（如好感度必须在 -100~100 之间），越界则自动裁剪到合法范围并记录警告日志 |

### 1.5 章节选择（通关后解锁）

通关任意结局后，解锁**章节选择**功能：

```
┌─────────────────────────────────────────────────┐
│               章节选择                            │
│                                                   │
│  ▶ 第一章：初入学院    （起点：新生报到日）        │
│  ▶ 第二章：同窗之谊    （起点：分班第一天）        │
│  ▶ 第三章：暗流涌动    （起点：第一次派系接触）    │
│  ▶ 第四章：寒假风波    （起点：放假前最后一课）    │
│  ▶ 第五章：立场之辩    （起点：课堂辩论事件前）    │
│  ▶ 第六章：毕业抉择    （起点：毕业考核前）        │
│  ▶ 第七章：内战烽火    （起点：阵营选择前）        │
│  ☐ 第八章：终局之路    （起点：最终战役前）        │
│    ☐ 需要完成至少1次通关解锁                       │
│                                                   │
│  [从选定章节开始]    [返回]                        │
└─────────────────────────────────────────────────┘
```

**规则**：
- 章节选择开始的游戏视为**新一周目**
- 继承本周目已解锁的成就/图鉴加成
- 属性从该章节的默认初始值开始（不从零开始）
- 第一章起始属性为角色基础值 + 周目加成

## 二、多周目机制

### 2.1 继承要素（永久保留）

#### 成就与称号

| 继承项 | 说明 |
|--------|------|
| 结局成就 | 所有已解锁的结局成就永久保留 |
| 展示称号 | 已解锁称号可自由装备（同一时间只能装备一个） |
| 一次性徽章 | 已解锁徽章永久存在于成就馆 |
| 隐藏成就 | 包括E11的延迟解锁成就，一旦解锁永久可见 |

#### 图鉴

| 继承项 | 说明 |
|--------|------|
| 结局图鉴 | 已解锁结局的详细信息永久可见 |
| 角色图鉴 | 已解锁的角色立绘、背景故事永久保留 |
| 事件图鉴 | 已触发的剧情事件永久记录 |
| CG画廊 | 已解锁的结局CG、关键事件CG永久保留 |
| 兵种图鉴 | 已遭遇/使用过的兵种信息永久保留 |
| 地形图鉴 | 已作战过的地形信息永久保留 |

#### 周目加成（基于上周目表现）

| 加成类型 | 计算方式 | 上限 |
|---------|---------|------|
| **经验加成** | 上周目最终四维属性总和 ÷ 100，向下取整 | 最高 +3 星（初始学科经验） |
| **初始心情** | 上周目平均好感度 ÷ 10，取整 | 最高 +10 初始心情值 |
| **战争记忆** | 上周目是否完成过内战：是 → 解锁"老兵直觉" | 第一章自动触发一段回忆对话 |
| **人脉积累** | 上周目好感度≥70的角色数 ÷ 5，取整 | 最高 +2 所有角色初始好感 |

**周目加成为隐藏机制**——玩家不会看到具体数字，只会在新周目开始时感受到"似乎比上一次更顺手了"。

**示例**：
- 第1周目以E3（前线军官）结局通关，武力85、统率40 → 四维总和215 → 获得 +2 星初始学科经验
- 上周目平均好感35 → 初始心情 +3
- 上周目有3名角色好感≥70 → 所有角色初始好感 +0（不足5人）

### 2.2 不继承要素

以下内容在每一周目**完全重置**，确保游戏体验的一致性：

| 重置项 | 说明 |
|--------|------|
| 六学科属性 | 回到初始值 + 周目加成（非上周目实际值） |
| 四维属性 | 由六学科重新计算 |
| 所有好感度 | 回到角色初始值 + 人脉积累加成 |
| 四大立场轴 | 全部归零（极端立场需要重新塑造） |
| 战功 / 军衔 | 完全重置 |
| 战斗数据 | 击杀数、战斗场次全部清零 |
| 事件记录 | 当前周目的事件触发状态全部重置 |
| 派系归属 | 重新选择 |
| 西班牙接触 | 重新从0开始 |
| 心情值 | 回到初始值 + 心情加成 |
| 战场状态 | 完全重置 |
| 关键抉择记录 | 全部清空（可以做出不同选择） |

### 2.3 二周目专属内容

#### 新对话选项（「记忆回响」系统）

当玩家在上周目触发过某事件的关键选择后，二周目同一事件会新增特殊对话选项：

```
┌─────────────────────────────────────────────────┐
│  EV015 · 课堂辩论                                │
│                                                   │
│  [上周目你选择了"汉人优先"，这一课你有了新的思考]  │
│                                                   │
│  A. "汉人优先"          ← 上次选择（标灰显示）    │
│  B. "多族共治"                                    │
│  C. "容我想想"                                    │
│  D. ★"我曾在另一条路上走过一次……"                  │
│     ← 二周目专属选项，触发隐藏对话                  │
│     ← 条件：上周目在此事件做过选择                 │
│                                                   │
│  选择D的效果：                                    │
│  - 程夫子沉默片刻，说"你似乎经历过大风大浪"       │
│  - 智略 +2、人望 +1（展现成熟）                   │
│  - 解锁隐藏对话"师生的课后谈话"                   │
└─────────────────────────────────────────────────┘
```

**规则**：
- 二周目专属选项以 ★ 标记
- 仅在该事件上周目已被触发过的前提下出现
- 选择★选项不会直接复制上周目结果，而是触发全新对话
- NPC对话中体现"似曾相识"的微妙感（主角的直觉/既视感）

#### 隐藏角色解锁

以下角色**仅在二周目及以后**可以遇到：

| 角色 | 身份 | 解锁条件 | 出现位置 |
|------|------|---------|---------|
| **沈万金·暗面** | 沈家隐藏的商业对手 | 上周目达成E8（经商结局） | 第三章，母族拜访事件中突然出现 |
| **独臂老海盗** | 退役海盗/现商人 | 上周目战功排名前3 | 第四章，寒假自由探索时 encountered |
| **流浪剑客** | 神秘武者 | 上周目武力≥70 | 第五章，比武大会中出现挑战者 |
| **"观察者"** | 西班牙密探头目 | 上周目接触过西班牙线（spain_contact≥1） | 第六章，毕业后主动接触主角 |
| **暮年主角** | 未来时间线的自己 | 全11个结局解锁 | 二周目第一章开头，梦境中出现 |

#### 真结局线索

二周目解锁**真结局碎片收集**机制：

- 在特定事件的★选项中，可以获取「历史碎片」——记载郑明王朝的隐藏历史
- 共 **7 块碎片**，散布在不同章节的★对话中
- 收集全部7块后，解锁隐藏事件 **EV-TRUE**："主角在父亲书房发现一封密信"
- EV-TRUE 是 E7（回归领地）和 E8（经商）被标记为"真结局"的**前置条件**
  - 一周目的 E7/E8 只是"普通战败结局"
  - 二周目集齐碎片后的 E7/E8 才是真正的"归隐"与"传承"

#### 「已知结局」特殊对话

当玩家已达成某结局后，二周目相关NPC会在特定时刻说出"预言式"台词：

| 已达成结局 | NPC | 触发时机 | 台词 |
|-----------|-----|---------|------|
| E3 前线军官 | 魏连长 | 第一次战斗前 | "我看你的眼神……像是一个已经上过战场的人。" |

| E1 政治家 | 黄道周 | 庆典事件 | "你的眼中有一种超越年龄的……通透。" |
| E6 横死 | 许医官 | 校园日常 | "你最近气色不太好……我说不清为什么，只是担心。" |
| E5 称帝/大总统 | 程夫子 | 毕业前夕 | "你将来会走到什么位置，我不敢想……" |
| E11 殖民总督 | 主角内心 | 接触西班牙线时 | "这条路……我似乎走过。上一次，我付出了什么代价？" |
| E9 困死狱中 | 蒋军法 | 军法事件 | "你要记住，铁窗之内没有人能替你思考。" |
| E7/E8 真结局 | 赵夫人 | 寒假归家 | "孩子……你有没有做过一个梦，梦见自己回到了老家？" |
