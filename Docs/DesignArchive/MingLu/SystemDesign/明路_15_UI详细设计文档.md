## 1. 全局设计规范

### 1.1 色彩体系

| 用途 | 色值 | 说明 |
|------|------|------|
| 主色（郑明金） | #C8A45C | 王朝金，用于标题/重要按钮 |
| 辅色（墨黑） | #2B2B2B | 正文文字 |
| 强调色（朱红） | #B8382E | 敌方/危险/关键操作 |
| 己方色（靛蓝） | #2E5C8A | 己方部队/正面信息 |
| 中立色（青灰） | #6B7B8D | 中性信息/第三方 |
| 背景色（宣纸） | #F5F0E1 | 主背景底色 |
| 深色背景（夜宣） | #1E1B16 | 战场模式/夜间场景 |
| 成功绿 | #4A8C5C | 升级/达成/正面反馈 |
| 警告橙 | #D4883A | 注意/资源不足 |
| 禁用灰 | #A0998A | 不可操作元素 |

### 1.2 材质与质感

- **养成模式**：宣纸底纹 + 毛笔书写感边框 + 朱砂印章装饰
- **战场模式**：羊皮纸/牛皮纸底 + 铜质铆钉边角 + 军事地图等高线纹理
- **弹窗/面板**：半透明宣纸覆盖（opacity 85-92%），底部投影 4px

### 1.3 圆角与间距

| 元素 | 圆角 | 说明 |
|------|------|------|
| 大面板 | 8px | 主内容区域 |
| 按钮 | 4px | 所有可点击按钮 |
| 卡片 | 6px | 信息卡片/角色卡 |
| 头像 | 50% | 圆形裁剪 |
| 标准间距 | 12px | 元素之间的基础间距 |
| 区块间距 | 20px | 不同功能区块之间 |

**设计说明**：
- 背景：新京城的远景水墨画，随季节/剧情变化（春/夏/秋/冬/战火）
- 标题「明路」使用书法字体，金色描边，下方小字"MING LU · 1760"
- 菜单按钮：宣纸底 + 毛笔描边，hover 时微微泛金光
- 「继续游戏」仅在有存档时显示，显示最近存档的日期和地点
- 左下角快捷音乐开关，右下角退出按钮
- 移动端：按钮纵向排列占满屏幕中央区域

**操作流程**：
1. 进入主菜单 → 自动检测存档
2. 点击「继续游戏」→ 直接载入最近存档（长按可选择其他存档）
3. 点击「新游戏」→ 进入开场动画/序章
4. 点击「载入存档」→ 进入存档界面
5. 点击「成就」→ 进入成就图鉴界面
6. 点击「图鉴」→ 进入角色/兵种/地形图鉴

```

│ │       │  │ ═══════════════════════════════ │  │
│ │       │  │ "你听说了吗？返乡团最近在朝堂上  │  │
│ │       │  │  又提了光复的事，这次似乎得到了   │  │
│ │       │  │  不少老将的支持……"              │  │
│ │       │  │                                 │  │
│ │       │  │        ▸ 回应A：支持返乡    [1]  │  │
│ │       │  │        ▸ 质疑冒进风险     [2]  │  │
│ │       │  │        ▸ 转移话题         [3]  │  │
│ │       │  └─────────────────────────────────┘  │
│ └───────┘                                        │
│                                                   │
│                    [▼ 继续] [≡ 跳过] [☰ 日志]   │
└─────────────────────────────────────────────────┘
```

**设计说明**：
- **角色立绘区**：屏幕左侧或中央，根据说话人位置自动左右切换
- **对话文本框**：底部横向展开，宣纸质感底框，毛笔描边
- **角色名**：文本框左上角，朱红色小印章样式
- **选项按钮**：
  - 最多4个选项，纵向排列
  - 选项旁标注对立立场轴的影响（用↑↓小箭头暗示，不直接显示数值）
  - 选中选项后高亮0.3秒，然后播放对话
- **控制按钮**：
  - 「继续」：推进对话（点击文本框任意位置也可推进）
  - 「跳过」：长按快进，松开恢复正常
  - 「日志」：展开历史对话回顾面板
- **移动端**：点击屏幕下半部分推进，上半部分呼出菜单

**对话选项的立场影响提示**：
```
选项旁用小图标暗示立场偏移方向：
  ↑ 民族·皇汉    ↓ 民族·共治
  ↑ 阶级·君主    ↓ 阶级·民主
  ↑ 治国·独裁    ↓ 治国·共和
  ↑ 地域·统一    ↓ 地域·分权
仅显示箭头方向，不显示具体数值，让玩家自行判断
```

**设计说明**：

**角色信息面板（左上）**：
- 头像：圆形，点击可查看完整角色卡
- 姓名/身份：书法体标题
- 六科属性：星级显示 + EXP进度条（当前EXP/升级所需）
- EXP进度条颜色：距离升级越近，颜色越亮（灰→金渐变）

**日期/心情面板（右上）**：
- 日期格式：年号 + 季节 + 第N周
- 心情值：数值 + 进度条 + 文字描述（差/一般/良好/极佳）
- 行动力：每日行动点数（平日2点，周日1点）

**学科选择区（中部）**：
- 6个学科卡片横向排列（移动端改为2×3网格）

**功能按钮栏（底部）**：
- 固定在屏幕底部
- 8个功能按钮，图标+文字
- 有新消息/可解锁内容时，按钮上显示红点提示

**操作流程**：

6. 随时可点击底部功能按钮进入子界面
