# 明路 - 技能系统设计（v2：纯被动系统）

---

## 一、系统概述

### 1.1 设计理念

《明路》的技能系统采用**纯被动设计哲学**：所有技能均为被动属性加成或条件触发效果，不存在任何需要手动释放的主动技能。这一设计基于以下核心理念：

**① 决策前置，执行纯粹**

传统主动技能系统将「何时释放技能」作为核心决策点，但这与《明路》六边形战棋的玩法本质存在冲突——战棋的乐趣在于「如何走位、如何排兵布阵」，而非「何时按下技能按钮」。将技能改为被动后，玩家的决策重心回归战棋本源：移动、站位、编队、地形利用。技能系统不再分散注意力，而是**强化战棋决策的深度**。

**② 将领差异化，而非操作差异化**

在主动技能系统中，同一套技能人人都能用，差异化取决于「用得好不好」。但在被动系统中，每位将领拥有独特的被动技能组合，差异化体现在「带了谁、怎么搭配」。这让85位角色各有价值，让玩家真正与角色建立情感联系。一个将领的强度不在于玩家会不会操作，而在于他是否「天生适合这场战斗」。

**③ 降低门槛，加深策略**

被动技能无需记忆冷却时间、不需要判断释放时机，新玩家可以专注于基础战斗。但当玩家开始理解技能之间的协同效应时，会发现深层的策略空间——这就是「易学难精」的设计目标。

**④ 战场沉浸感**

18世纪的战场上，将领不会「释放技能」，他们会「激励士气」「选择地形」「调配兵力」。被动技能系统将这些军事素养内化为数值效果，更贴合时代背景。一位善用地形的将领，在山地作战时「自动」获得加成——这才是历史模拟游戏应有的体验。

### 1.2 与主动技能系统的对比

| 维度 | 主动技能系统 | 被动技能系统（本版） |
|------|-------------|-------------------|
| 决策焦点 | 何时释放技能 | 如何选择走位和搭配 |
| 操作负担 | 需要记忆冷却/效果 | 设置后自动生效 |
| 角色差异 | 大家学同样的技能 | 每位将领独一无二 |
| 新手体验 | 容易遗漏技能/错过时机 | 设置即生效，无操作压力 |
| 深度来源 | 技能释放时机 | 技能协同与Build构筑 |
| AI实现 | 需要复杂AI决策 | 数值计算即可 |
| 重玩价值 | 低（最优操作固定） | 高（不同搭配不同体验） |
| 适合品类 | ARPG/即时战略 | 六边形战棋/回合制策略 |

### 1.3 技能系统在游戏整体循环中的位置

```
角色养成循环：
  学科修炼 → 解锁新被动技能 → 编队搭配优化 → 战斗表现提升 → 获得更多经验/好感度 → 进一步养成

战斗循环（单场）：
  选择出战将领（被动技能组合） → 根据敌方/地形调整编队 → 战斗中被动技能自动触发 → 战后复盘Build搭配

长线循环：
  推图/战斗 → 积累好感度 → 解锁角色专属被动 → 丰富Build池 → 挑战更难内容
```

技能系统是连接「角色养成」与「战斗表现」的桥梁。它不是独立系统，而是**所有系统的交汇点**——学科等级影响技能解锁、军衔影响技能槽位、好感度解锁专属技能、兵种等级决定可用技能范围。

## 二、技能框架

### 2.1 技能槽位

#### 将领技能槽

每位将领拥有 **4个被动技能槽位**：

| 槽位 | 类型 | 说明 |
|------|------|------|
| **天赋槽** | 固定 | 角色自带，不可更换。每个角色拥有独特的天赋被动技能 |
| **学识槽** | 半固定 | 由学科等级自动解锁，满足条件后从可选池中选取1个装备 |
| **经验槽** | 自由 | 通过战斗经验/好感度解锁，可自由装配已解锁的任意通用被动技能 |
| **指挥槽** | 自由 | 通过军衔/派系解锁，可自由装配已解锁的任意通用被动技能 |

**槽位解锁进度：**

| 军衔 | 可用槽位 | 说明 |
|------|----------|------|
| 士~少尉 | 天赋槽 | 仅天赋被动生效 |
| 中尉~上尉 | 天赋槽 + 学识槽 | 学科被动开始生效 |
| 少校~上校 | 天赋槽 + 学识槽 + 经验槽 | 3个槽位，Build初步成型 |
| 少将~元帅 | 全部4个槽位 | 完整Build |

#### 部队被动

部队本身不占将领槽位，但根据**兵种类型**和**部队等级**自动获得固定被动：

| 部队等级 | 自动获得的部队被动 |
|----------|-------------------|
| 0级（民兵） | 无 |
| 1级（线列步兵/轻骑/轻火炮） | 1个兵种基础被动 |
| 2级（来复枪兵/枪骑/重火炮） | 1个兵种基础被动 + 1个兵种进阶被动 |
| 3级（精锐轻步兵/重骑/加农炮） | 1个兵种基础被动 + 1个兵种进阶被动 |
| 4级（近卫军/骠骑/榴弹炮） | 2个兵种基础被动 + 1个兵种进阶被动 |
| 5级（禁军/火枪骑兵/围城炮） | 2个兵种基础被动 + 2个兵种进阶被动 |

**说明：** 部队被动是固定的，不需要玩家装配。这确保了即使不深入了解技能系统的新手，升级部队本身就能带来可感知的战力提升。

### 2.2 技能稀有度

| 稀有度 | 标识色 | 效果强度 | 获取难度 | 设计定位 |
|--------|--------|----------|----------|----------|
| **普通** | ⬜ 白色 | 基础加成（5%-15%） | 低星学科/低军衔即可获取 | 填充槽位的基石技能 |
| **精锐** | 🟦 蓝色 | 中等加成（15%-30%）或条件触发 | 高星学科/中等军衔/战斗积累 | Build核心组件 |
| **传说** | 🟨 金色 | 强力效果（30%+）或改变机制 | 角色专属/高好感度/特殊剧情 | Build核心定义技能 |

**稀有度与技能强度的平衡原则：**
- 普通技能提供稳定的数值提升，是「安全选择」
- 精锐技能需要特定条件触发，是「高风险高回报选择」
- 传说技能改变战斗机制，是「Build定义选择」

### 2.3 技能获取方式

| 获取途径 | 说明 | 典型示例 |
|----------|------|----------|
| **学科修炼** | 6学科星级达到要求后，从对应技能池中选择装备 | 步兵适性3星 → 解锁「列阵之心」可选 |
| **战斗经验** | 累计达成特定战斗条件自动解锁 | 累计击杀200个敌人 → 解锁「斩将夺旗」 |
| **好感度/剧情** | 与特定角色好感度达标后解锁其专属被动 | 与郑怀远好感≥80 → 解锁「东征遗志」 |
| **军衔晋升** | 达到特定军衔自动解锁 | 晋升上校 → 解锁「三军之气」 |
| **角色天赋** | 角色自带，不可更换 | 冯铁山自带「铁壁边防」 |
| **兵种等级** | 部队升级到特定等级自动获得 | 步兵升到3级 → 自动获得「老兵不死」 |
| **派系认同** | 阵营中多角色好感度达到阈值后解锁 | 返乡团3人好感≥60 → 解锁「光复之志」 |

### 2.4 技能与伤害公式的关系

被动技能嵌入既有伤害公式的各个位置：

```
攻击输出 = (面板输出 × 我方兵种血量系数 
         + 我方士气等级 × 我方编队系数 × 我方兵种血量系数 
         - 敌方士气等级 × 敌方编队系数 × 敌方兵种血量系数 
         + 将领对应兵种星数 × 5 × 将领血量系数 
         - 2 × 对方等级) 
         × 兵种克制系数 
         × (1 - 减伤百分比值) 
         × 技能加成减免
```

**技能作用点映射：**

| 公式中的位置 | 技能介入方式 | 示例技能 |
|-------------|-------------|----------|
| **面板输出** | 条件性提升面板数值 | 「列阵之心」（满编时面板+12%） |
| **我方士气等级** | 提升士气上限/降低士气消耗 | 「铁骨铮铮」（士气惩罚减半） |
| **敌方士气等级** | 打击敌方士气 | 「先声夺人」（开战时敌方士气-5） |
| **兵种血量系数** | 提升HP上限 | 「铜墙铁壁」（最大HP+15%） |
| **兵种克制系数** | 改变克制关系 | 「步骑双修」（骑兵克制系数从1.3降至1.1） |
| **减伤百分比值** | 增加减伤或削减敌方减伤 | 「山岳之姿」（山地减伤+15%） |
| **技能加成减免** | 乘算伤害加成 | 「连珠炮」（触发时技能加成=1.25） |
| **公式外独立效果** | 不影响公式，产生独立效果 | 「急掠如风」（击杀后重新移动） |

### 2.5 技能冲突与叠加规则

**① 同类技能叠加规则**

| 类别 | 叠加方式 | 说明 |
|------|----------|------|
| 百分比加成（如攻击+X%） | **取最高值，不叠加** | 防止多个百分比技能叠加导致数值膨胀 |
| 固定值加成（如移动+X） | **加算叠加** | 固定值叠加有上限，不会失控 |
| 条件触发效果（如X%概率暴击） | **概率独立计算，效果不叠加** | 多个暴击技能同时触发时取最高暴击伤害 |
| 光环效果 | **不同来源的光环可叠加，同名光环不叠加** | 两位将领的同名光环只生效一个 |
| 角色专属被动 | **与通用技能完全叠加** | 天赋槽独占，不与其他槽位冲突 |

**② 叠加上限**

| 效果类型 | 上限 | 说明 |
|----------|------|------|
| 总减伤 | 75% | 所有来源的减伤总计不超过75% |
| 总攻击加成 | 60% | 所有来源的攻击加成总计不超过60% |
| 移动力加成 | +4 | 超过+4的部分无效 |
| 士气加成 | +30 | 单次战斗中累计士气加成不超过+30 |
| 暴击伤害 | ×2.0 | 暴击时的最高伤害倍率 |

**③ 触发优先级**

当多个被动技能在同一事件上同时触发时：
1. 角色天赋被动优先结算
2. 传说技能次之
3. 精锐技能再次之
4. 普通技能最后
5. 同稀有度同时触发时，效果取最高值

## 三、技能分类体系

本系统共设**8个技能大类**，每个大类包含10个以上通用被动技能，覆盖各种战斗场景与策略方向：

| 序号 | 大类 | 核心影响 | 典型关键词 | 技能数量 |
|------|------|----------|-----------|----------|
| 1 | **机动力类** | 移动、地形穿越、先手 | 行军、急袭、地脉、追风 | 10 |
| 2 | **攻击类** | 伤害输出、连击、穿透 | 破阵、连击、穿杨、裂甲 | 12 |
| 3 | **防御类** | 减伤、反击、格挡 | 铁壁、磐石、反刃、金汤 | 10 |
| 4 | **士气类** | 士气变化、恢复、打击 | 军心、破胆、铁骨、鼓噪 | 10 |
| 5 | **指挥/光环类** | 周围友军加成 | 号令、军旗、同袍、督阵 | 10 |
| 6 | **生存类** | HP恢复、补给、撤退 | 回春、苦行、不死、辎重 | 10 |
| 7 | **侦察/情报类** | 视野、隐蔽、侦察 | 鹰眼、潜行、夜哨、明察 | 10 |
| 8 | **兵种特化类** | 步/骑/炮各自专属 | 列阵、奔袭、轰天、铁蹄 | 12 |

**总计：84个通用被动技能 + 30+角色专属被动 = 114+个技能**

## 四、各技能详细设计

---

### 4.1 机动力类（10个）

> 影响部队的移动能力、地形穿越效率、先手权等。核心策略价值：让部队出现在正确的位置。

#### ① 急掠如风

| 项目 | 内容 |
|------|------|
| **稀有度** | 🟦 精锐 |
| **适用兵种** | 全兵种 |
| **效果描述** | 击杀一个敌方编队后，该部队可立即再移动最多2格（不触发再次攻击） |
| **触发条件** | 本回合内击杀至少1个敌方编队 |
| **数值参数** | 额外移动力=2格；每回合最多触发2次 |
| **获取方式** | 累计击杀100个敌方编队 |
| **公式关系** | 公式外独立效果——不改变伤害计算，改变移动规则 |
| **设计意图** | 鼓励集中火力逐个击破，奖励「滚雪球」式进攻节奏 |

#### ② 行军无阻

| 项目 | 内容 |
|------|------|
| **稀有度** | 🟦 精锐 |
| **适用兵种** | 全兵种 |
| **效果描述** | 部队移动不受地形移动消耗惩罚。所有地形的移动消耗视为1（最低值） |
| **触发条件** | 永久生效 |
| **数值参数** | 地形移动消耗强制=1（沿河从3降为1，山地从2降为1） |
| **获取方式** | 后勤学科≥3星 |
| **公式关系** | 公式外独立效果——修改移动规则表 |
| **设计意图** | 极大提升战略机动性，适合迂回战术Build |

#### ③ 先发制人

| 项目 | 内容 |
|------|------|
| **稀有度** | ⬜ 普通 |
| **适用兵种** | 全兵种 |
| **效果描述** | 每场战斗首回合，己方所有部队移动力额外+1 |
| **触发条件** | 仅第1回合生效 |
| **数值参数** | 首回合移动力+1 |
| **获取方式** | 训练学科≥1星 |
| **公式关系** | 公式外独立效果——修改首回合移动规则 |
| **设计意图** | 简单实用的开局加成，强调先手抢占阵地 |

#### ④ 据险而守

| 项目 | 内容 |
|------|------|
| **稀有度** | ⬜ 普通 |
| **适用兵种** | 步兵 |
| **效果描述** | 当部队驻守在山地、森林、城市等地形（移动消耗≥2的地形）时，获得减伤加成 |
| **触发条件** | 部队本回合未移动 |
| **数值参数** | 减伤+10% |
| **获取方式** | 步兵适性≥1星 |
| **公式关系** | 作用于减伤百分比值 |
| **设计意图** | 鼓励步兵利用地形防御，与骑兵的机动性形成对比 |

#### ⑤ 败而不溃

| 项目 | 内容 |
|------|------|
| **稀有度** | ⬜ 普通 |
| **适用兵种** | 全兵种 |
| **效果描述** | 部队HP低于30%时，移动力不降低（正常低血量时移动力-1） |
| **触发条件** | HP < 30%最大HP |
| **数值参数** | 低血量移动力惩罚=0 |
| **获取方式** | 后勤学科≥1星 |
| **公式关系** | 公式外独立效果——修改低血量移动惩罚规则 |
| **设计意图** | 让残血部队仍能安全撤退，减少「被追死」的挫败感 |

#### ⑥ 长驱直入

| 项目 | 内容 |
|------|------|
| **稀有度** | 🟦 精锐 |
| **适用兵种** | 骑兵 |
| **效果描述** | 骑兵冲锋时（本回合移动3格以上后攻击），伤害随冲锋距离增加 |
| **触发条件** | 骑兵本回合移动≥3格后进行攻击 |
| **数值参数** | 每多移动1格，攻击伤害+8%（3格时+0%，4格+8%，5格+16%，6格+24%，7格+32%） |
| **获取方式** | 骑兵学科≥3星 |
| **公式关系** | 作用于技能加成减免因子（如1.32 = 增加32%伤害） |
| **设计意图** | 奖励骑兵长距离冲锋，强调骑兵的空间利用能力 |

#### ⑦ 夜行晓宿

| 项目 | 内容 |
|------|------|
| **稀有度** | ⬜ 普通 |
| **适用兵种** | 全兵种 |
| **效果描述** | 在夜间/雾天条件下（视野受限天气），部队移动力+1 |
| **触发条件** | 天气为夜间或雾天时永久生效 |
| **数值参数** | 移动力+1 |
| **获取方式** | 训练学科≥2星 |
| **公式关系** | 公式外独立效果 |
| **设计意图** | 配合天气系统，让特定天气下获得机动优势 |

#### ⑧ 铁蹄扬尘

| 项目 | 内容 |
|------|------|
| **稀有度** | 🟨 传说 |
| **适用兵种** | 骑兵 |
| **效果描述** | 骑兵移动经过敌方视野范围时，不会触发敌方的「警戒」反应（敌方不会自动转向或准备迎战），且骑兵经过后在原地留下「烟尘」效果持续1回合——经过该位置的友军移动力+1 |
| **触发条件** | 永久生效（移动时自动） |
| **数值参数** | 警戒免疫+1回合烟尘（烟尘移动+1，可叠加） |
| **获取方式** | 骑兵学科≥5星 |
| **公式关系** | 公式外独立效果——修改警戒规则和地形效果 |
| **设计意图** | 传说级机动技能，让骑兵成为真正的战场幽灵，配合迂回战术极强 |

#### ⑨ 步步为营

| 项目 | 内容 |
|------|------|

## 六、技能搭配与Build

### Build 1：铁壁防线

**核心思路：** 以步兵为核心构建不可逾越的防线，通过高减伤和士气稳定拖延战局。

| 槽位 | 技能 | 效果 |
|------|------|------|
| 天赋槽 | 冯铁山「铁壁边防」 | 山地/山丘减伤+18% |
| 学识槽 | 铁壁之心 | 减伤+8% |
| 经验槽 | 金汤之固 | 城市地形减伤+15% |
| 指挥槽 | 军旗不倒 | 3格士气打击减半 |

**部队搭配：** 三编线列步兵 × 3 + 轻火炮 × 2
**适用场景：** 防御战、城市攻防战、山地阻击战
**核心机制：**
- 山地减伤：铁壁边防18% + 铁壁之心8% + 山地地形5% = 31%基础减伤
- 城市减伤：金汤之固15% + 铁壁之心8% + 众志成城6% = 29%
- 总减伤上限75%内，配合部队被动「铜墙铁壁」的HP+15%，极难被击破
**弱点：** 机动性差，被迂回包抄时缺乏反击手段

### Build 2：闪电突袭

**核心思路：** 以骑兵为核心构建高速机动打击力量，通过快速穿插分割敌军。

| 槽位 | 技能 | 效果 |

| 指挥槽 | 侧击之锋 | 侧面攻击+18% |

**部队搭配：** 双编骠骑兵 × 3 + 轻骑兵 × 2
**适用场景：** 平原野战、追击战、迂回包抄
**核心机制：**
- 冲锋伤害：疾风知劲+20% + 长驱直入（5格=+32%） = 冲锋5格+52%伤害
- 侧面攻击：侧击之锋+18%，配合冲锋=+70%

- 配合「轻骑掠袭」的打后移动1格，形成连续的机动打击
**弱点：** 正面攻防弱，遇到高减伤步兵阵线时效率下降

**核心思路：** 以炮兵为核心构建远程火力网，通过密集炮击摧毁敌军。

## 八、技能平衡性说明

### 8.1 数值平衡原则

**① 边际递减原则**

同一维度上的加成越多，单个加成的实际价值越低。例如：
- 0%→10%减伤：实际防御力提升11.1%
- 60%→70%减伤：实际防御力提升25%（但因为75%上限，70%→75%只提升7.1%）

这意味着「堆叠同类型加成」的效率越来越低，自然引导玩家追求多样化的技能搭配。

**② 条件换强度原则**

越强的技能，触发条件越苛刻：
| 技能强度 | 典型条件 |
|----------|----------|
| ⬜ 普通（5-15%） | 永久生效或极低门槛 |
| 🟦 精锐（15-30%） | 需要特定条件（地形、HP阈值、位置关系） |
| 🟨 传说（30%+） | 需要高学科/高军衔/高好感度 + 复杂条件 |

**③ 攻守不对称原则**

攻击加成的上限（60%）低于减伤上限（75%），确保防御方有一定优势。这与战棋游戏的「先手不利」设计一致——主动进攻方需要投入更多资源才能突破防线。

**④ 兵种互补原则**

每个兵种在某些维度上有天然优势，在另一些维度上有天然劣势：
| 维度 | 步兵优势 | 骑兵优势 | 炮兵优势 |
|------|----------|----------|----------|
| 攻击 | 齐射/近战 | 冲锋/侧击 | 远程/攻城 |
| 防御 | 驻守/地形 | 闪避/脱离 | 阵地/射程 |
| 机动 | — | 高速/冲锋 | — |
| 士气 | 密集稳定 | 突击震慑 | 炮击恐吓 |

### 8.2 防止Overpower的机制
