# 明路 - 情报与间谍系统设计

> 架空1760年美洲 · 郑明王朝 · 信息即权力
> 版本：v1.0 | 关联文档：共享上下文、外交系统、战斗系统

---

## 一、情报系统概述

### 1.1 设计理念

情报系统是《明路》中**信息不对称**的核心实现。在18世纪的战场上，"知道敌人在哪"往往比"知道怎么打"更重要。情报系统不是独立模拟层，而是贯穿养成、外交、战斗、剧情的**暗线操作系统**——它在幕后运转，玩家感知到的是"情报带来的优势和意外"。

核心体验：
- **迷雾中决策**：玩家永远无法掌握全部信息，必须基于不完整情报做出判断
- **情报即资源**：获取情报需要投入人力、时间、金钱，情报本身有成本和风险
- **信息不对称的戏剧性**：虚假情报导致的灾难、间谍身份暴露的震撼、精准侦察带来的战场优势
- **养成渗透**：从军校时期就开始积累情报能力，内战时期收获回报

### 1.2 情报系统阶段划分

| 阶段 | 对应章节 | 情报特征 | 玩家能力 |
|------|---------|---------|---------|
| **萌芽期** | 序章~第二章 | 学院学习基础侦察/密码学，接触情报概念 | 基础侦察、被动情报获取 |
| **建设期** | 第三章~第四章 | 开始建立个人情报网络，接触间谍中间人 | 派遣斥候、招募低级线人 |
| **活跃期** | 第五章~第六章 | 间谍活动频繁，各方互相渗透 | 完整间谍系统可用，可策反敌方角色 |
| **战争期** | 第七章 | 情报成为胜负关键，反间谍与伪装并行 | 全面情报战，双重间谍、虚假情报 |

### 1.3 情报面板（UI概念）

主界面设"情报"按钮，打开后显示：
- **迷雾地图**：以六边形格显示，已侦察/部分侦察/未侦察区域用不同透明度标注
- **情报网络总览**：当前活跃间谍数量、位置、任务状态
- **情报档案**：已收集到的各势力/角色情报卡片，标注情报等级和时效
- **反间谍面板**：己方领地安全等级、可疑活动警报
- **情报日志**：所有情报事件的记录（含"事后发现是假情报"的标注）

## 二、战争迷雾与侦察系统

### 2.1 战争迷雾机制

战场上存在三层信息层级：

| 层级 | 名称 | 视觉表现 | 信息内容 |
|------|------|---------|---------|
| **黑色迷雾** | 未知区域 | 完全黑色覆盖 | 无任何信息，不知道有敌军存在 |
| **灰色迷雾** | 模糊侦察 | 灰褐色半透明 | 可见部队轮廓，可判断大致方向，无法确认兵种和数量 |
| **白色区域** | 精确侦察 | 完全可见 | 显示完整部队信息：兵种、数量、士气、将领、编队 |

**迷雾刷新规则**：
- 已侦察区域每过2回合退回灰色迷雾，再过2回合退回黑色迷雾
- 城市、要塞提供永久视野（白色区域，半径3格）
- 友军单位视野范围始终为白色
- 高地（山丘/山地）增加1格视野范围

### 2.2 侦察单位与能力

| 侦察方式 | 提供单位 | 视野范围 | 侦察精度 | 风险 | 特殊条件 |
|---------|---------|---------|---------|------|---------|
| **斥候侦察** | 轻骑兵编队 | 5格（直线） | 灰色→白色（1回合） | 低（被截获概率10%） | 需编入轻骑兵 |
| **骠骑突进** | 骠骑兵编队 | 7格（直线） | 灰色→白色（即时） | 中（被截获概率25%） | 需骠骑兵，移动中执行 |
| **来复枪哨兵** | 来复枪兵编队 | 4格（全向） | 灰色→白色（持续） | 低（隐蔽状态10%） | 需来复枪兵，静止执行 |
| **鹰骑高空侦察** | 雷鸟部鹰骑兵 | 8格（全向） | 白色（即时） | 极低（高空5%） | 需雷鸟部关系≥30 |
| **民间线人** | 间谍网络 | 不限距离 | 取决于间谍等级 | 中~高 | 需已建立间谍网络 |
| **外交渠道** | 外交关系 | 不限距离 | 灰色（模糊） | 低 | 需目标势力关系≥20 |

### 2.3 侦察行动

#### 2.3.1 战术侦察（战场内）

在战斗回合中执行的侦察行动：

| 行动 | 执行单位 | 成功率 | 成功效果 | 失败后果 | AP消耗 |
|------|---------|--------|---------|---------|--------|
| **快速扫视** | 任意骑兵 | 80% | 1格内灰色→精确 | 仅获模糊信息 | 1AP |
| **深入侦察** | 轻骑兵/骠骑兵 | 60% | 3格内灰色→精确 | 被截获，单位暴露位置 | 2AP |
| **夜间渗透** | 精锐轻步兵 | 45% | 5格内黑色→灰色 | 被击退，损失10%兵力 | 3AP |
| **狙击手观察** | 来复枪兵 | 70% | 4格全向精确（持续2回合） | 暴露位置，遭敌方火力 | 2AP |
| **缴获文件** | 击败敌军后 | 90% | 获得敌方部署信息 | 无（必定成功） | 0AP |

#### 2.3.2 战略侦察（战场外/养成阶段）

在大地图/养成阶段执行的侦察：

| 行动 | 前置条件 | 持续时间 | 成功率 | 成功效果 | 失败后果 | 费用 |
|------|---------|---------|--------|---------|---------|------|
| **边境巡探** | 与目标接壤 | 1回合 | 75% | 边境3格内灰色迷雾 | 斥候被驱赶 | 粮食×100 |
| **城镇渗透** | 间谍等级≥1 | 2回合 | 55% | 城镇内灰色迷雾 | 间谍被捕 | 金币×200 |
| **部队侦察** | 间谍等级≥2 | 3回合 | 40% | 获取敌方主力部署（模糊） | 间谍网暴露 | 金币×500 |
| **要塞侦察** | 间谍等级≥3 | 5回合 | 25% | 获取要塞防御完整布局 | 间谍死亡 | 金币×1000 |
| **外交情报** | 关系≥20 | 即时 | 65% | 获知对方意图（模糊） | 关系-5 | 无 |

## 三、情报等级与时效

### 3.1 情报等级体系

| 等级 | 名称 | 信息精度 | 视觉标识 | 来源 |
|------|------|---------|---------|------|
| **★☆☆☆☆** | 道听途说 | 仅知存在，不知详情。"敌军在北方" | 暗红色 | 民间传闻、商人传闻 |
| **★★☆☆☆** | 模糊 | 可知大致方向/兵种类型，数量偏差±50%。"北方有约200~600步兵" | 橙色 | 斥候远距侦察、低级线人 |
| **★★★☆☆** | 部分 | 可知兵种、大致数量（偏差±25%）、将领身份。"北方有400步兵+100骑兵，张猛指挥" | 黄色 | 近距离侦察、中级间谍 |
| **★★★★☆** | 精确 | 完整数值：兵种×数量、士气、将领、编队、补给状态 | 浅绿色 | 精锐侦察、高级间谍、内线 |
| **★★★★★** | 实时 | 精确+实时更新（每回合刷新） | 翠绿色 | 友军视野、最高级内线、双重间谍 |

### 3.2 情报时效系统

情报不是永久有效的，会随时间推移而**衰减**：

| 时效阶段 | 持续时间 | 效果 | 视觉提示 |
|---------|---------|------|---------|
| **新鲜** | 获取后1回合 | 情报完整有效 | 翠绿色文字 |
| **有效** | 获取后2~3回合 | 信息准确度-10%（数量偏差增加） | 浅绿色文字 |
| **过时** | 获取后4~5回合 | 降一级（精确→部分，部分→模糊） | 黄色文字 |
| **陈旧** | 获取后6+回合 | 再降一级，可能严重失准 | 红色文字 |
| **作废** | 获取后10+回合 | 情报自动删除，不再可信 | 灰色删除线 |

**时效加速衰减因素**：
- 敌方部队处于运动状态：衰减速度×2
- 季节变化（如冬季→春季，部队换防）：衰减速度×1.5
- 重大事件发生（如宣战、结盟）：所有相关情报立即衰减2级

### 3.3 情报可靠性判定

当玩家查看一条情报时，系统显示**可靠性评估**：

```
可靠性 = 基础精度 × 来源可靠度 × 时效系数 × 交叉验证加成

基础精度：取决于侦察方式（斥候60%、间谍75%、外交50%）
来源可靠度：间谍等级/关系深度决定（0.5~1.2）
时效系数：新鲜1.0、有效0.9、过时0.7、陈旧0.4
交叉验证加成：2个以上独立来源确认同一情报 → +0.3
```

**可靠性等级**：
| 可靠性值 | 标签 | UI颜色 | 含义 |
|---------|------|--------|------|
| ≥0.9 | 确认 | 翠绿 | 几乎可以完全信任 |
| 0.7~0.89 | 可信 | 浅绿 | 大概率准确 |
| 0.5~0.69 | 存疑 | 黄色 | 需要交叉验证 |
| 0.3~0.49 | 可疑 | 橙色 | 可能是假情报 |
| <0.3 | 不可信 | 红色 | 极可能为误导 |

## 四、间谍网络系统

### 4.1 间谍网络建设（养成阶段）

间谍网络不是突然出现的，需要玩家在养成阶段**逐步积累**：

#### 4.1.1 情报基础设施

| 设施/资源 | 解锁条件 | 效果 | 维护费用 |
|----------|---------|------|---------|
| **私人通讯录** | 序章·社交≥2星 | 可记录NPC信息，情报收集+5% | 无 |
| **信鸽笼** | 第一章·管理≥2星 | 可与已访问城镇保持联络，远程情报时效+1回合 | 粮食×50/月 |
| **密码本** | 第二章·训练≥2星 | 间谍通信加密，被发现概率-15% | 无 |
| **暗号体系** | 第二章·与独臂老海盗好感≥20 | 解锁暗号接头，间谍任务成功率+10% | 金币×30/月 |
| **商路情报网** | 第三章·与沈万金好感≥30 | 商贸城镇自动获取★☆☆☆☆情报 | 金币×100/月 |
| **海军侦察船** | 第五章·军衔≥少校 | 沿海区域侦察范围+3格 | 金币×200/回合 |
| **情报总站** | 第六章·军衔≥上校 | 解锁全部间谍行动，可培训间谍 | 金币×500/月 |

#### 4.1.2 间谍招募来源

间谍不是凭空招募的，每个间谍来源都有对应的养成线索：

| 来源 | 解锁条件 | 间谍类型 | 基础属性 | 上限 |
|------|---------|---------|---------|------|
| **退伍老兵** | 军衔≥少尉 | 外勤 | 武力70 智谋50 | 5人 |
| **学院同学** | 同学好感≥50 + 对应派系关系 | 内线/外勤 | 根据同学属性 | 3人 |
| **独臂老海盗的门徒** | 海盗好感≥40 | 外勤 | 武力60 智谋70 隐匿80 | 4人 |
| **沈万金的商队伙计** | 沈万金好感≥30 | 外勤（商贸掩护） | 武力30 智谋80 社交70 | 6人 |
| **归化印第安猎人** | 印第安乡党好感≥30 | 外勤（侦察专精） | 武力50 智谋40 隐匿90 | 4人 |
| **策反的敌方人员** | 策反成功 | 内线/双面 | 根据原角色属性 | 不限 |
| **流浪剑客** | 流浪剑客好感≥60 + 特殊事件 | 外勤（暗杀专精） | 武力95 智谋60 隐匿70 | 1人 |
| **庄谋** | 庄谋好感≥50（法治派NPC） | 内线（高层渗透） | 武力40 智谋95 社交90 | 1人 |

### 4.2 间谍类型详解

#### 4.2.1 内线间谍

**定义**：已渗透进入敌方组织/势力内部的人员

| 属性 | 说明 |
|------|------|
| **掩护身份** | 敌方官员/将领/商人/传教士的随从 |
| **活动范围** | 敌方核心区域（城市、要塞、指挥部） |
| **核心能力** | 刺探高级情报、策反、长期潜伏 |
| **风险** | 极高——被发现后基本无法逃脱 |
| **招募难度** | 高——需要对应NPC的深度关系链 |

**内线间谍等级**：

| 等级 | 名称 | 可获取情报 | 可执行任务 | 培养成本 |
|------|------|----------|----------|---------|
| 1级 | 跑腿 | ★☆☆☆☆ | 基础观察 | 金币×100 |
| 2级 | 耳目 | ★★☆☆☆ | 基础观察、传话 | 金币×300 + 2回合 |
| 3级 | 密探 | ★★★☆☆ | 刺探军情、散布谣言 | 金币×600 + 5回合 |
| 4级 | 深间 | ★★★★☆ | 全部任务 + 策反 | 金币×1200 + 10回合 |
| 5级 | 暗桩 | ★★★★★ | 全部任务 + 暗杀 + 破坏 | 金币×2500 + 15回合 |

#### 4.2.2 外勤间谍

**定义**：在敌方领地外围活动的情报人员

| 属性 | 说明 |
|------|------|
| **掩护身份** | 商人、旅行者、传教士、猎人 |
| **活动范围** | 敌方边境城镇、交通要道、前线附近 |
| **核心能力** | 侦察、干扰补给线、快速撤退 |
| **风险** | 中——被发现后可尝试撤退 |
| **招募难度** | 中——来源较广 |

**外勤间谍专精**：

| 专精 | 加成领域 | 惩罚领域 | 适合任务 |
|------|---------|---------|---------|
| **商人型** | 贸易城镇侦察、经济情报 | 军事侦察 | 经济刺探、贸易干扰 |
| **猎人型** | 地形侦察、野外部队追踪 | 城市渗透 | 战术侦察、路线勘察 |
| **社交型** | 人脉建立、谣言传播 | 武力对抗 | 散布谣言、策反接触 |
| **武力型** | 强行渗透、暗杀 | 隐蔽侦察 | 暗杀、破坏 |
| **技术型** | 密码破译、技术窃取 | 战斗 | 窃取技术、破译通信 |

#### 4.2.3 策反间谍

**定义**：原本是敌方角色/间谍，被说服转为己方效力

| 属性 | 说明 |
|------|------|
| **身份** | 原有角色身份不变，暗中为己方服务 |
| **活动范围** | 敌方内部（保持原有身份） |
| **核心能力** | 最高级情报、关键时刻倒戈 |
| **风险** | 极高——忠诚度不稳定 |
| **招募难度** | 极高——需要特定条件 |

**策反条件**：

| 策反途径 | 条件 | 成功率基础值 | 备注 |
|---------|------|-----------|------|
| **利益收买** | 目标角色好感≥-20 + 金币×500~2000 | 20% | 最直接但忠诚度最低 |
| **把柄胁迫** | 掌握目标角色弱点/秘密 | 30% | 需通过其他间谍获取把柄 |
| **理念说服** | 4大立场轴与目标角色一致度≥75% | 35% | 最稳定但条件最苛刻 |
| **人情回报** | 此前救过目标角色命/帮过大忙 | 40% | 需主线/支线事件中积累 |
| **亲属要挟** | 控制目标角色家属 | 50% | 道德代价极大，全派系-10（若暴露） |

**策反后的忠诚度**：

| 初始忠诚度 | 维持条件 | 背叛概率（每回合） |
|-----------|---------|------------------|
| 低（20~35%） | 利益收买 | 15%/回合（停止支付则立即背叛） |
| 中（35~55%） | 把柄胁迫/理念说服 | 5%/回合 |
| 高（55~80%） | 人情回报 | 2%/回合 |
| 极高（80%+） | 亲属要挟（但怨恨极大） | 1%/回合 + 可能报复 |

### 4.3 间谍任务详解

#### 4.3.1 刺探军情

| 任务等级 | 目标 | 基础成功率 | 成功效果 | 失败后果 | 执行时间 | 费用 |
|---------|------|-----------|---------|---------|---------|------|
| 初级 | 边境部队 | 70% | 获得边境部署（★★☆☆☆） | 间谍暴露位置 | 1回合 | 金币×100 |
| 中级 | 主力部队 | 50% | 获得主力部署（★★★☆☆） | 间谍被捕/被杀 | 2回合 | 金币×300 |
| 高级 | 指挥部 | 30% | 获得作战计划（★★★★☆） | 间谍死亡+网络暴露 | 3回合 | 金币×800 |
| 特级 | 最高机密 | 15% | 获得核心战略（★★★★★） | 间谍死亡+网络重创 | 5回合 | 金币×2000 |

#### 4.3.2 破坏补给

| 目标类型 | 基础成功率 | 成功效果 | 失败后果 | 执行条件 |
|---------|-----------|---------|---------|---------|
| 粮草运输队 | 60% | 目标部队补给-30%，持续2回合 | 间谍被捕 | 需知目标位置 |
| 弹药库 | 40% | 目标部队弹药-50%，持续3回合 | 间谍死亡 | 需内线/精确情报 |
| 桥梁/道路 | 55% | 目标区域移动消耗+1，持续5回合 | 间谍暴露 | 需外勤间谍 |
| 港口设施 | 35% | 目标港口停用2回合 | 间谍死亡 | 需武力型间谍 |
| 攻城器械 | 25% | 攻城器械毁坏 | 间谍死亡+敌方警觉 | 需内线+技术型 |

#### 4.3.3 暗杀

**暗杀是整个间谍系统中最戏剧性的行动**，也是风险最高的。

| 目标等级 | 基础成功率 | 需要间谍 | 成功效果 | 失败后果 | 费用 |
|---------|-----------|---------|---------|---------|------|
| 低级军官 | 55% | 外勤（武力型） | 目标死亡，部队士气-10 | 间谍死亡 | 金币×300 |
| 中级将领 | 35% | 内线（3级+） | 目标死亡，部队士气-20，指挥链断裂1回合 | 间谍死亡+暴露 | 金币×800 |
| 高级将领 | 15% | 内线（4级+）+ 流浪剑客 | 目标死亡，全军士气-30 | 间谍全部死亡 | 金币×2000 |
| 外交使节 | 20% | 外勤/内线 | 关系-30，外交事件中断 | 所有势力关系-20 | 金币×1500 |
| 派系领袖 | 5% | 极特殊条件 | 触发重大剧情事件 | 全面暴露 | 需完成前置链 |

**暗杀修正公式**：
```
暗杀成功率 = 基础成功率 × (1 + 间谍武力×0.003) × (1 + 间谍隐匿×0.004) 
           × 情报精度系数 × 掩护系数 × 目标警觉系数

情报精度系数：★★★★★=1.5, ★★★★☆=1.2, ★★★☆☆=1.0, ★★☆☆☆=0.6, ★☆☆☆☆=0.3
掩护系数：有内线接应=1.3, 目标身边无护卫=1.5, 宴会/混乱中=1.2, 正常=1.0
目标警觉系数：目标警觉=0.5, 正常=1.0, 目标松懈(如醉酒)=1.5, 目标受伤=1.3
```

**暗杀后的连锁反应**：
- 成功暗杀将领 → 该将领派系成员好感-15~-30（仇视凶手所属势力）
- 暗杀外交使节 → 触发"使节被杀"外交事件，所有势力关系变动
- 暗杀派系领袖 → 触发内战加速事件，可能改变内战格局
- 暗杀失败被追溯 → 幕后主使暴露，相关势力关系-25~-50

#### 4.3.4 散布谣言

| 谣言类型 | 基础成功率 | 成功效果 | 持续时间 | 被发现概率 |
|---------|-----------|---------|---------|-----------|
| **动摇军心** | 60% | 目标部队士气-15，持续3回合 | 3回合 | 20% |
| **离间将领** | 45% | 目标将领与主帅好感-20 | 5回合 | 30% |
| **制造恐慌** | 50% | 目标城镇民心-20，征兵效率-30% | 4回合 | 25% |
| **伪造命令** | 25% | 目标部队执行错误命令1回合 | 1回合 | 40% |
| **外交谣言** | 40% | 目标势力与第三势力关系-10 | 永久（衰减） | 35% |
| **假投降** | 20% | 诱使敌方接受虚假投降条件 | 至识破 | 50% |

**谣言传播规则**：
- 谣言效果 = 基础效果 × (1 + 社交型间谍加成×0.2) × (1 + 目标民心低时加成×0.3)
- 目标民心<30时，谣言效果+30%
- 目标民心>70时，谣言效果-30%
- 同一目标同时存在多条谣言时，后续谣言成功率-15%（民众警惕）

#### 4.3.5 策反将领

策反是间谍系统的终极任务，需要**长线经营**：

**策反流程**：

```
第一步：建立接触
├─ 需要间谍与目标将领在同一区域活动
├─ 通过社交型间谍发起初步接触（成功率60%）
├─ 或通过内线间谍安排秘密会面（成功率45%）
└─ 失败 → 目标警觉，后续策反难度+20%

第二步：培养关系（1~5回合）
├─ 每回合派遣间谍与目标互动
├─ 寻找策反切入点（利益/理念/把柄/人情）
├─ 互动中根据4大立场轴匹配度决定切入点
└─ 每次互动有20%被发现的概率

第三步：正式策反
├─ 根据选择的策反途径计算成功率
├─ 成功率 = 基础值 × 关系培养加成 × 立场匹配度
├─ 关系培养加成：每互动1回合+5%，上限+25%
└─ 立场匹配度：75%以上+20%，90%以上+35%

第四步：维持忠诚
├─ 策反后需持续维护（支付金币/提供承诺）
├─ 忠诚度每回合自然衰减（取决于策反途径）
├─ 忠诚度降至0时，策反者可能反水
└─ 可安排关键任务在忠诚度较高时执行
```

### 5.3 反间谍发现率

```
反间谍发现率 = 基础发现率 × 措施加成 × 间谍能力修正

基础发现率：
├─ 外勤间谍：15%/回合（无措施时）
├─ 内线间谍：8%/回合（无措施时）
├─ 策反间谍：12%/回合（无措施时）
└─ 敌方间谍对玩家：10%/回合（无措施时）

措施加成（乘法叠加）：
├─ 加强巡逻：×1.3
├─ 宵禁：×1.5
├─ 通行证审查：×1.2
├─ 内部审查：×2.0（一次性，当回合）
└─ 反渗透：×3.0（一次性，当回合）

间谍能力修正：
├─ 间谍隐匿值>70：×0.6
├─ 间谍隐匿值>85：×0.4
├─ 间谍掩护身份优良：×0.7
└─ 间谍已被怀疑：×2.0
```

### 5.4 间谍被发现后的处置

间谍被发现后，根据身份不同有不同的处置选项：

| 间谍类型 | 可选处置 | 各处置效果 |
|---------|---------|-----------|
| **外勤间谍** | ①处决 | 关系-10，震慑效果（其他间谍被发现概率-10%） |

| | ③驱逐 | 关系-5，最温和 |
| **内线间谍** | ①处决 | 关系-15，但暴露己方反间谍能力 |
| | ②反向利用（双重间谍） | 需间谍技能≥3星，成功率40% → 向敌方发送假情报 |
| | ③关押 | 可作为谈判筹码 |
| **策反间谍** | ①处决 | 策反者的其他策反目标忠诚度-20 |
| | ②利用其叛变传递假情报 | 需管理≥3星，成功率50% → 高级假情报 |
| | ③重新策反 | 需再次执行策反流程，成功率×0.5 |

### 5.5 双重间谍系统

双重间谍是情报系统中最精妙的部分：

**建立双重间谍的条件**：
1. 捕获敌方间谍 且 间谍技能≥3星
2. 或己方间谍被敌方"策反"后，实际上暗中仍为己方服务（需主角提前布局）
3. 或主动将已被怀疑的间谍"叛逃"至敌方，实际仍听命于己方

**双重间谍的作用**：

| 行动 | 效果 | 风险 |
|------|------|------|
| **传递假情报** | 敌方基于假情报做出错误决策 | 若被识破，双重间谍暴露（60%概率被识破/次） |
| **获取敌方信任** | 提升敌方对双重间谍的信任度，后续假情报更可信 | 需要持续维护（金币×300/回合） |
| **关键时刻倒戈** | 在决定性战役中，双重间谍突然倒戈，造成敌方重大混乱 | 一次性，暴露后无法再用 |
| **传递真情报** | 利用双重间谍的渠道获取敌方真实情报 | 双重间谍暴露风险+30% |

**双重间谍的戏剧性**：
- 双重间谍可能在长期潜伏后**真的叛变**（每5回合10%概率真的倒向敌方）
- 敌方也可能在对玩家使用双重间谍——玩家无法100%确认
- 当双方都知道对方有双重间谍时，进入"谍中谍"状态：所有情报都可能是假的

### 8.2 间谍身份揭露的戏剧性事件

这些事件为情报系统提供**叙事高潮**：

#### IP011：叛徒的影子

```
背景：第四章，主角发现学院/部队中有敌方间谍

场景：深夜，反间谍报告发现异常——有人在泄露学院训练计划

选项：
A. 暗中调查（需管理≥2星）
   → 成功：锁定嫌疑人，触发后续选择
   → 失败：打草惊蛇，间谍转移

B. 设下圈套（需训练≥2星）
   → 用假情报引蛇出洞
   → 发现嫌疑人是……（根据派系关系随机）
   → 赵伯衡（返乡团）/ 刘小炮（干城派）/ 何小满（自由派）

C. 直接加强安保
   → 间谍暂停活动，但未被发现
   → 后续章节间谍重新活跃（更高级的间谍）

D. 向学院报告
   → 学院启动全面调查
   → 嫌疑人被带走审讯
   → 真相可能不如预期……（审讯中翻供，真凶另有其人）
```

#### IP013：双面人

```
背景：第六章，双重间谍传来矛盾情报

场景：你的双重间谍——一个你以为已经被策反的敌方情报官——
同时传来了两条互相矛盾的情报：
- 情报A：敌方主力将在北方发起进攻
- 情报B：北方进攻是假的，真正目标在南方

你不知道该相信哪条，或者……两条都是假的？

选项：
A. 相信情报A，加强北方防御
   → 50%概率正确（若正确，北方伏击成功）
   → 50%概率错误（北方空虚被突破）

B. 相信情报B，加强南方防御
   → 同上，概率反转

C. 两线平均分配兵力
   → 安全但保守，无法获得伏击加成

D. 派第三个间谍验证（需额外间谍）
   → 花费2回合确认，但敌方也完成部署
   → 获得准确情报（★★★★★）

E. 这是反间谍的好机会——利用矛盾情报反向操作
   → 需管理≥4星
   → 成功：敌方以为你上当，暴露真实部署
   → 失败：你上了双重间谍的当
```

#### IP018：忠诚的考验（隐藏事件）

```
背景：第七章，所有策反间谍面临最终考验

条件：拥有3个以上策反间谍 + 内战进行到关键时刻

场景：内战进入决战阶段，你手下的策反间谍们面临最终选择——
在关键时刻，他们是否真的会站在你这边？

系统自动计算每个策反间谍的最终忠诚度：
- 忠诚度≥60%：策反者按时执行任务
- 忠诚度30~59%：50%概率执行、50%概率叛变
- 忠诚度<30%：叛变！将你的计划告知敌方

叛变的连锁反应：
→ 你的作战计划被敌方获知
→ 伏击变成被伏击
→ 士气-30
→ 需要临时调整策略

这是长线策反经营的"考试"——前期投入越多，此刻越安全。
```

## 十、情报数值总表

### 10.1 核心公式

```
【侦察成功率】
战术侦察成功率 = 基础成功率 × (1 + 将领训练星级×0.08) × 地形系数 × 天气系数
  地形系数：平原1.0 / 森林0.8 / 山地0.6 / 城市0.5 / 夜间0.7
  天气系数：晴天1.0 / 阴天0.9 / 雨天0.7 / 雾天0.4 / 雪天0.5

战略侦察成功率 = 基础成功率 × (1 + 间谍隐匿×0.004) × (1 + 间谍等级×0.15)
              × 目标反间谍系数 × 掩护系数
  目标反间谍系数：无反间谍1.0 / 加强巡逻0.8 / 宵禁0.7 / 全面戒备0.5
  掩护系数：商人1.2 / 传教士1.1 / 旅行者1.0 / 无掩护0.6

【间谍任务成功率】
间谍成功率 = 基础成功率 × (1 + 主角管理星级×0.1) × (1 + 间谍等级×0.15)
           × 情报精度系数 × 目标防御系数

【反间谍发现率】
反间谍发现率 = 基础发现率 × 措施加成 × 间谍能力修正（详见5.3节）

【情报时效衰减】
情报衰减速度 = 基础速度 × 目标运动状态 × 事件系数
  目标运动：静止1.0 / 行军2.0 / 战斗3.0
  事件系数：无事件1.0 / 小规模冲突1.3 / 重大事件2.0
```
