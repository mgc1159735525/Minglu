# 战棋地图编辑器使用说明

这个编辑器用于快速制作、测试和共享战棋关卡。定位接近《魔兽争霸》的关卡编辑器原型：先搭地图，再摆单位，然后配置目标、AI 和触发器，最后直接进入战斗测试。

## 入口

游戏内进入 `战略地图` 后，点击底部 `工坊` 进入 `战棋工坊`。设置菜单里也保留了入口，方便从其他界面回到测试工具。

## 编辑流程

1. 在 `地图` 页设置关卡名称、作者、说明、地图行列、目标类型、回合限制、天气、敌方 AI 和双方测试强度。
2. 在 `画笔` 页选择地形、蓝方单位、红方单位、据点或擦除工具。
3. 用 `尺寸 1/2/3` 切换画笔范围。地形和擦除会直接影响区域；触发器会记录为区域触发。
4. 在 `触发` 页选择抵达剧情或击败剧情，切换剧情模板和触发动作。
5. 点击棋盘格放置触发器。尺寸 1 是单格，尺寸 2/3 会形成更大的触发区域。
6. 在 `文件` 页保存草稿、导出 JSON，或导入最近导出的 JSON。
7. 点击 `开始测试`，当前关卡会生成临时战斗，不写入正式存档和正式战绩。

## 当前功能

| 功能 | 说明 |
| --- | --- |
| 地图尺寸 | 支持在编辑器里扩大或缩小六边形地图。 |
| 地形编辑 | 支持平原、森林、山地、河流、城镇等地形。 |
| 单位摆放 | 支持摆放蓝方和红方单位，并切换不同兵种。 |
| 战争目标 | 支持占据据点、抵达据点、击溃敌军。 |
| 回合限制 | 可设置限定回合，超过后按测试失败结算。 |
| 天气规则 | 晴、雨、雾、夜会影响部分战斗参数。 |
| 敌方 AI | 可在已有 AI 风格中切换，用于测试不同敌人行为。 |
| 区域触发 | 抵达触发和击败触发支持半径区域，不再只限单格。 |
| 触发动作 | 支持仅剧情、刷红方、刷蓝方、调整士气、直接胜利、直接失败。 |
| 导出 JSON | 导出到 `Assets/Resources/Data/BattleLevels`，便于提交到 Git。 |

## 触发器规则

| 类型 | 触发条件 | 常见用途 |
| --- | --- | --- |
| 抵达剧情 | 指定阵营或兵种进入触发区域。 | 进入埋伏圈、抵达桥头、发现伏兵。 |
| 击败剧情 | 指定敌人出生格或死亡格落在触发区域。 | 击杀敌将、破坏炮位、清理据点守军。 |

触发器可以带动作。比如“抵达桥头 -> 刷红方援军”，“击败敌将 -> 直接胜利”，“进入伏击区 -> 红方士气 +1”。

## 关卡策划交付

交付一个战棋关卡时，至少写清楚：

| 项目 | 示例 |
| --- | --- |
| 关卡名称 | 东渡试炼 |
| 地图目的 | 教会玩家利用河流和桥头据点。 |
| 目标类型 | 抵达据点，12 回合内完成。 |
| 推荐 AI | 进攻型或战术型。 |
| 关键触发 | 蓝方步兵进入桥头区域后刷出红方伏兵。 |
| 失败压力 | 超过回合限制、主力被击溃或错误推进。 |
| 验收标准 | 正常打法能胜利，乱冲会触发伏兵并明显变难。 |

## 注意事项

编辑器导出的 JSON 目前是关卡设计文件，不会自动进入正式剧情链。需要成为正式关卡时，再由程序或系统策划把它接入任务、剧情或战略地图入口。
