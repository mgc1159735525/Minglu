# 《明路》剧情与任务触发重构方案

## 核心定位

剧情只负责串联和解释，不负责替玩家推进游戏。

玩家真正推进游戏的方式是：

1. 养成：课程等级、体力、心态、同窗好感。
2. 战棋：战斗胜负、击溃数、补给消耗、军功。
3. 情报：情报值、情报网、敌军可见度。
4. 任务：主线任务、角色支线、派系任务、日常任务。

主线剧情必须被这些结果触发。玩家如果条件不足，界面只提示“还差什么”，然后回到学院或战略地图继续游玩。

## 主线闸门

| 节点 | 触发条件 | 作用 |
| --- | --- | --- |
| EV005 | 完成任务「第一周整训」 | 要求玩家先完成任意课程，确认养成是核心循环。 |
| EV007 | 完成任务「训练搭档」 | 要求任意同窗好感达到30，把社交接入战棋准备。 |
| EV010 | 完成任务「兵棋资格」 | 要求任意课程达到2级，课程等级决定能否进入兵棋推演。 |
| EV013 | 完成任务「战前侦察」 | 要求情报值达到20，让情报成为战棋前置准备。 |
| EV021 | 完成任务「情报网成形」 | 要求情报网达到2级，打开战略地图与更高风险任务。 |
| EV025 | 训练进度达到120 | 用角色状态限制高压对抗，不让剧情空转。 |
| EV031 | 任意课程达到3级 | 用课程等级解锁夏季大演习。 |
| EV038 | 完成任务「首次军演胜利」 | 要求赢得一场战棋，胜利结果反推剧情。 |
| EV050 | 完成任务「毕业前整备」 | 要求情报值达到45，收束终盘前信息。 |
| EV059 | 战棋胜利2场 | 内战剧情只在玩家有实战结果后开启。 |
| EV065 | 战棋胜利3场 | 终局选择必须建立在战棋成绩上。 |

## 任务链

主线任务链按“养成 → 社交 → 课程等级 → 情报 → 情报网 → 战棋 → 连续出阵 → 终盘整备”排列：

| 任务 | 目标 | 后续用途 |
| --- | --- | --- |
| 第一周整训 | 任意课程进度25 | 解锁EV005。 |
| 训练搭档 | 任意同窗好感30 | 解锁EV007。 |
| 兵棋资格 | 任意课程等级2 | 解锁EV010。 |
| 战前侦察 | 情报值20 | 解锁EV013。 |
| 情报网成形 | 情报网2级 | 解锁EV021。 |
| 首次军演胜利 | 战棋胜利1场 | 解锁EV038。 |
| 连续出阵 | 完成战棋2场 | 铺垫毕业前整备。 |
| 毕业前整备 | 情报值45 | 解锁EV050。 |

## 日常碎片

日常事件不再讲与核心玩法无关的长支线，而是解释每个玩法为什么重要：

| 类型 | 触发来源 | 文案职责 |
| --- | --- | --- |
| 课程碎片 | 枪阵、骑训、炮算、军政、补给、体能 | 把课程等级和战棋单位、阵型、补给、伤害预判连接起来。 |
| 社交碎片 | 邀约同窗 | 把好感解释成战棋建议、任务线索和派系支持。 |
| 周末活动 | 兵棋推演、茶馆、讲座、救济 | 引导玩家按目标选择活动，而不是随机点按钮。 |
| 情报碎片 | 情报阈值10/25/50 | 解释敌军信息、补给破口和终盘风险。 |

## 导表字段

`story_events.csv` 新增以下列：

| 字段 | 说明 |
| --- | --- |
| unlockKind | 触发类型，如 quest、story、battleWins、anyCourseLevel、intelligence。 |
| unlockTarget | 目标ID，如任务ID、剧情ID、角色ID。没有目标可留空。 |
| unlockValue | 数值阈值，如战棋胜利次数、情报值、课程等级。 |
| unlockHint | 玩家未满足条件时看到的说明。 |

任务继续使用 `quests.csv` 的 `unlockKind / unlockTarget / unlockValue / targetKind / targetValue`。

## UI规则

1. 剧情目录不展示表格数量，只展示当前主线和推进条件。
2. 条件不足时弹出“剧情未触发”，提示玩家回到养成、情报、任务或战棋。
3. 剧情选项不显示数值影响，属性和好感暗中变化。
4. 选项文本必须完整显示，不能使用省略号替代核心信息。
