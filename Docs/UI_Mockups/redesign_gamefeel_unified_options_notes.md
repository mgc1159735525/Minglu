# 游戏感统一模板说明

这版修正了上一版 A/B/C 编排不一致的问题。现在三套方案使用同一个模板，只比较视觉皮肤。

## 固定模板

| 区域 | 固定内容 |
| --- | --- |
| 顶部状态栏 | 当前周、行动点、心情、体力、战功、设置。 |
| 左侧角色卡 | 主角立绘、姓名、身份、特性、状态条。 |
| 中央上方 | 章节目标、解锁说明、进度、奖励标签。 |
| 中央下方 | 上午、下午、周末三个日程槽。 |
| 右侧预览 | 主线检定、风险提示、关键属性进度、确认/重选。 |
| 底部行动 | 课程、同窗、战棋、读报、任务。 |

## 三套皮肤

| 方案 | 风格 | 适合 |
| --- | --- | --- |
| 统一A 厚重养成 | 酒红、暗金、仪式感强 | 主线、角色、学院养成主界面。 |
| 统一B 战备养成 | 深蓝灰、军令、风险感强 | 战棋、战备、情报、地图编辑器。 |
| 统一C 清爽养成 | 纸色、手账、阅读压力低 | 日常、读报、同窗、任务整理。 |

## 推荐落地方式

用统一模板作为全游戏养成主 UI 的结构。第一阶段可选 `统一A` 或 `统一C` 做学院主界面；战棋工坊和战备界面切到 `统一B` 的皮肤，但保持顶部栏、预览区和底部行动的结构不变。
