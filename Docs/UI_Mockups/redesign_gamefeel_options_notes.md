# 游戏感 UI 方案说明

本版目标是让主界面从“信息面板”变成“玩家正在玩养成游戏”。参考竞品只提炼交互结构，不复刻画面和素材。

## 参考竞品提炼

| 竞品 | 可借鉴点 |
| --- | --- |
| 《火山的女儿》 | 日程、战斗训练、关系和王国命运放在同一个养成循环里，适合强调“行动选择会改变未来”。 |
| 《美少女梦工厂》 | 长周期养成、课程安排、属性成长和多结局是核心，适合把日程和成长反馈做成界面中心。 |
| 《中国式家长》 | 学习、娱乐、交友、关键考试目标组成强游戏循环，适合用行动点、压力/体力、阶段目标来驱动选择。 |
| 《Long Live The Queen》 | 周次推进、课程选择、心态影响学习、剧情检定和死亡/失败压力，适合《明路》的任务触发和战棋风险提示。 |

## 游戏感A 日程冒险

定位：最像养成游戏主界面。

特点：
- 主角立绘常驻，右侧是章节目标和三个日程槽。
- 底部是可点击行动入口：课程、同窗、战棋、读报、任务。
- 每个日程槽显示预期收益和事件可能性。

适合：学院日常、同窗关系、剧情推进主界面。

## 游戏感B 成长棋盘

定位：最像“养成 + 战棋”的混合玩法。

特点：
- 行动被表现成棋盘路线，玩家像安排一条本周成长路线。
- 右侧有行动预览、风险提示和确认按钮。
- 战棋、情报、事件检定天然可以成为路线节点。

适合：战棋工坊、训练推演、战略地图前的战备界面。

## 游戏感C 任务手账

定位：最清楚、最容易落进现有工程。

特点：
- 左侧立绘，中央事件栏，右侧行动卡。
- 行动卡带消耗和收益，玩家能直接理解本周要做什么。
- 信息比 A/B 更稳，适合当前 Unity 原型快速翻新。

适合：当前学院界面的第一版正式落地。

## 我的建议

第一阶段落地用 `游戏感C 任务手账`，因为它最清晰、改动风险最低；战棋工坊和战备界面吸收 `游戏感B 成长棋盘`；标题栏、章节目标和奖励标签吸收 `游戏感A 日程冒险`。
