# UI 翻新方案说明

本轮只做方向演示，不替换工程运行时 UI。三张图使用同一类“学院主界面”信息，方便比较布局和美术资源语言。

## 方案A 玄金学院

适合方向：角色养成、权力感、学院仪式感。

特点：
- 中央大立绘，左右分区，第一眼明确玩家角色。
- 酒红、暗金、深木色，接近宫廷和军校气质。
- 按钮和面板厚重，适合剧情、养成、角色关系为主的体验。

风险：
- 暗色界面如果信息继续增加，会显得压迫。
- 战棋和地图界面需要另做更清晰的轻量版本。

## 方案B 军令桌案

适合方向：战棋、任务、战略地图、编辑器。

特点：
- 中央作为推演桌面，左侧任务，右侧角色与战备。
- 颜色偏军绿、铁灰、旧纸，功能性强。
- 更容易扩展到战棋地图编辑器、任务链和军团管理。

风险：
- 养成情绪感弱，角色恋爱/社交表达需要额外强化。
- 如果所有界面都用这个，会偏硬。

## 方案C 书院手账

适合方向：日常养成、读报、同窗、剧情入口。

特点：
- 轻纸色、低压布局，信息收纳感最好。
- 左侧立绘，右侧双页手账，适合把任务和行动安排拆清楚。
- 后续可做成“日程本/档案本/战备本”统一 UI 资源体系。

风险：
- 战争章节的压迫感较弱。
- 需要在战棋和战略界面加入更强的军令视觉。

## 我的建议

如果只选一个方向，我建议以方案C为主框架，吸收方案A的标题栏和按钮质感，再给战棋/战略单独使用方案B的军令桌案组件。
