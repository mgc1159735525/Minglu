# 《明路》导表说明

## 常用流程

1. 双击项目根目录的 `导出配置表.bat`。
2. 编辑 `DataTables/csv` 里的 CSV 表，或打开 `DataTables/MingLu_GameTables.xlsx` 作为总览参考。
3. 双击项目根目录的 `回写配置表.bat`。
4. 打开 Unity，等待资源重新导入，然后运行或重新构建游戏。

## 运行时读取

- 数值与系统文案：`Assets/Resources/Data/MingLuGameConfig.json`
- 剧情文本：`Assets/Resources/MingLuStoryData.json`
- 美术素材索引：`Assets/Resources/Art/Manifests/art_manifest.json`

## 已导出的表

- `ui_texts`：全部可配置 UI 文案、按钮文案、日志模板。
- `player_defaults`：玩家初始数值。
- `calendar`：校历、考试周、假期周。
- `traits`：创角特性及战斗/社交/养成加成。
- `news`：报纸文章。
- `campus_activities`：周末活动。
- `courses`：课程按钮和经验目标。
- `mood_rules`：心情等级与学习收益。
- `academy_levels`：属性等级和经验进度。
- `academy_core`：学院学习、休息、邀约、假期、考试等核心数值。
- `exam_rewards`：校考分数段奖励。
- `ranks`：军衔、战功门槛、指挥上限。
- `relationship_levels`：好感等级、词条解锁等级。
- `belief_levels`：立场强度等级。
- `factions`：势力显示名。
- `ideology_axes`：立场轴名称与两端文案。
- `politics_options`：时事讲座选项及立场/属性影响。
- `relationships`：初始同窗关系。
- `stances`：初始派系立场。
- `provinces`：战略省份。
- `armies`：战略军团。
- `battle_roles`：战棋兵种。
- `common_units`：常见战棋单位，包含名称、关键词、兵种与序列帧资源路径。
- `terrain_rules`：地形抗性、移动消耗、颜色。
- `battle_unit_spawns`：战斗开始时双方单位出场配置。
- `battle_terrain_tiles`：7x9 战斗地图每格地形。
- `battle_role_damage_rules`：兵种克制与伤害修正。
- `health_factors`：兵力比例影响伤害的系数。
- `battle_core`：棋盘、据点、伤害公式、升级、补给、AI、胜负奖励、俘虏概率等核心战斗参数。
- `story_characters`：剧情角色。
- `story_events`：剧情事件主表。
- `story_lines`：剧情对白。
- `story_choices`：剧情选项与效果。

## 注意

- CSV 使用 UTF-8 编码。
- 多值字段用英文分号 `;` 分隔，例如省份道路 `xinjing;hegu`。
- 回写前建议先备份或使用版本管理。
- Excel 总表是查看/编辑参考；真正回写读取的是 `DataTables/csv`。
- 常见战棋棋子位于 `Assets/Resources/Art/BattleUnits`，每个单位包含 `idle_*`、`move_*`、`attack_*`、`hit_*` 序列帧。
