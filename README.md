# 明路 Unity 原型

这是按《明路》设计文档和 UrhoX/Lua 需求移植出的 Unity 单机原型项目。当前版本用 Unity 原生 UI 运行时生成界面，不依赖外部美术素材。

## 已实现

- 标题界面、开发团队、退出
- 学院养成：六门课程、闲逛、周日活动、剧情选择
- 人物好感度和政治立场
- 战略地图：省份、道路、军团、行军、攻击、结束回合、敌军 AI
- 六边形战棋：单位选择、移动范围、攻击范围、移动、攻击、反击、敌军 AI、胜负结算
- 战功、经验、等级、经验条
- 鼠标/触摸优先：Unity UI 点击和自定义点击去重
- 存档/读档

## 打开方式

用 Unity Hub 打开本目录 `MingLuUnity`，进入后直接点击 Play。脚本会在空场景中自动生成游戏界面。
